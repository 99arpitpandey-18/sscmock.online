1. Introduction to Spreadsheet

Spreadsheet का basic concept

What is a Spreadsheet?

🇬🇧 ENGLISH

A spreadsheet is an application software used to organize, calculate, analyze and present data in tabular form using rows and columns.

🇮🇳 हिंदी

Spreadsheet एक application software है जिसका उपयोग data को rows और columns के रूप में व्यवस्थित, calculate, analyze और present करने के लिए किया जाता है।

📌 Exam Definition

Spreadsheet is a software application that allows users to enter data into cells and perform calculations using formulas and functions.

📚

2. Workbook & Worksheet

Spreadsheet file structure

📘

Workbook

A spreadsheet file that can contain one or more worksheets.

📄

Worksheet

A worksheet is a grid of rows and columns where data is entered and processed.

📦

Cell

The intersection of a row and a column is called a cell.

➡️

Row

Rows run horizontally and are generally identified by numbers.

⬇️

Column

Columns run vertically and are generally identified by letters.

🎯

Active Cell

The currently selected cell in which data can be entered or edited.

Workbook vs Worksheet

🇬🇧 ENGLISH

A workbook is the complete spreadsheet file, while a worksheet is an individual sheet inside that workbook.

🇮🇳 हिंदी

Workbook पूरी spreadsheet file होती है, जबकि worksheet उस workbook के अंदर मौजूद individual sheet होती है।

🔲

3. Rows, Columns & Cells

Spreadsheet grid structure

Cell Address / Cell Reference

🇬🇧 ENGLISH

A cell reference identifies a cell by combining its column letter and row number. For example, A1, B5 and C10.

🇮🇳 हिंदी

Cell reference किसी cell की पहचान करता है। इसमें column letter और row number शामिल होते हैं, जैसे A1, B5 और C10।

⭐ IMPORTANT

A1 का अर्थ है Column A और Row 1 का intersection. इसी प्रकार C7 का अर्थ Column C और Row 7 है।

6. Formulas

Spreadsheet calculations

What is a Formula?

🇬🇧 ENGLISH

A formula is an expression used to perform calculations in a spreadsheet. A formula normally begins with an equal sign (=).

🇮🇳 हिंदी

Formula spreadsheet में calculation करने के लिए उपयोग किया जाने वाला expression है। Formula सामान्यतः equal sign (=) से शुरू होता है।

=A1+B1
=A2*B2
=C5-D5
=D10/E10

+ Addition • - Subtraction • * Multiplication • / Division

🎯 EXAM POINT

Spreadsheet formula की पहचान के लिए सबसे महत्वपूर्ण बात है कि formula सामान्यतः "=" sign से शुरू होता है।

7. Important Functions

Frequently used spreadsheet functions

Function Purpose हिंदी अर्थ Example
SUM() Adds values जोड़ना =SUM(A1:A5)
AVERAGE() Calculates average औसत निकालना =AVERAGE(A1:A5)
MAX() Finds largest value सबसे बड़ी value =MAX(A1:A5)
MIN() Finds smallest value सबसे छोटी value =MIN(A1:A5)
COUNT() Counts numeric cells संख्या वाले cells गिनना =COUNT(A1:A5)
IF() Performs logical test शर्त की जाँच =IF(A1>=40,"Pass","Fail")
=SUM(A1:A10)
=AVERAGE(B1:B10)
=MAX(C1:C10)
=MIN(D1:D10)
=COUNT(E1:E10)

8. Charts

Graphical representation of data

📊

Column Chart

Uses vertical columns to compare different categories or values.

📉

Bar Chart

Uses horizontal bars to compare categories or values.

🥧

Pie Chart

Represents parts of a whole using circular sectors.

📈

Line Chart

Useful for showing trends and changes over a sequence.

🎯

Chart Title

Describes the subject or information represented by the chart.

🏷️

Data Labels

Display values or information directly on chart elements.

Why are Charts Used?

🇬🇧 ENGLISH

Charts make numerical data easier to understand, compare and analyze visually.

🇮🇳 हिंदी

Charts numerical data को visually समझने, compare करने और analyze करने को आसान बनाते हैं।

9. Data Tools

Sorting, filtering and organizing data

Sorting

🇬🇧 ENGLISH

Sorting arranges data in a particular order, such as ascending or descending order.

🇮🇳 हिंदी

Sorting data को किसी विशेष क्रम में arrange करता है, जैसे ascending या descending order।

Filtering

🇬🇧 ENGLISH

Filtering displays only the records that satisfy a specified condition.

🇮🇳 हिंदी

Filtering केवल उन records को दिखाता है जो दी गई condition को satisfy करते हैं।

⭐ REMEMBER

Sorting = Data का order बदलना।
Filtering = केवल required data दिखाना।

Important Exam Points

  • The intersection of a row and column is called a cell.
  • Columns are generally identified by letters.
  • Rows are generally identified by numbers.
  • A1 is an example of a cell reference.
  • A workbook can contain multiple worksheets.
  • A formula generally starts with = sign.
  • SUM() is used to add values.
  • AVERAGE() calculates the average.
  • MAX() returns the largest value.
  • MIN() returns the smallest value.
  • COUNT() counts numeric values.
  • Charts provide graphical representation of data.
  • Sorting arranges data in a specified order.
  • Filtering displays records according to a condition.
