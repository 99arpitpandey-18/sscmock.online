Introduction to Computer

Computer fundamentals

What is a Computer?

A computer is an electronic device that accepts data as input, processes it according to a set of instructions, stores data when required and produces meaningful information as output.

Easy Formula: Input → Processing → Output → Storage

Data

Data means raw facts and figures that have not yet been processed. Examples include numbers, names, marks and dates.

Information

Information is processed and meaningful data that can be used for decision making.

Basic Working Cycle

  • Input: Data is entered into the computer.
  • Processing: CPU processes the data.
  • Output: Result is produced.
  • Storage: Data or information can be stored for future use.

Programs and instructions

Software is a collection of programs and instructions that tell the computer hardware what to do.

🛠️

📱

Central Processing Unit — CPU

Brain of the computer

What is CPU?

CPU stands for Central Processing Unit. It is responsible for executing instructions and processing data. It is commonly called the brain of the computer.

➗

ALU

Arithmetic Logic Unit performs arithmetic operations and logical comparisons.

🎛️

Control Unit

Controls and coordinates the activities of different parts of the computer.

📦

Registers

Very fast small storage locations inside the processor used during processing.

CPU = ALU + Control Unit + Registers
💾

Computer Memory

Primary and secondary memory

Primary Memory

Primary memory is directly accessible by the CPU and is used during the execution of programs.

Memory Full Form Main Feature
RAM Random Access Memory Volatile memory
ROM Read Only Memory Non-volatile memory

RAM

RAM temporarily stores data and programs that are currently being used by the computer. It is volatile, meaning its contents are generally lost when power is removed.

ROM

ROM is non-volatile memory that retains its contents even when the power is turned off.

Exam Point: RAM = Volatile | ROM = Non-Volatile

Quick Comparisons

Frequently asked differences

Hardware vs Software

Hardware is the physical part of a computer system, while software consists of programs and instructions. Hardware can be touched; software cannot be physically touched.

RAM vs ROM

RAM is volatile and mainly used for temporary working data. ROM is non-volatile and retains its stored contents without continuous power.

HDD vs SSD

HDD uses rotating magnetic disks and mechanical components. SSD uses flash memory and has no moving mechanical parts.

Input vs Output

Input devices send data or instructions to the computer. Output devices present processed information to the user.
