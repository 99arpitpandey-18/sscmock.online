🌐 1. Basic Concept of IP Address

There are two major types of IP addresses used in networking: Public IP Address and Private IP Address.

Networking में मुख्य रूप से IP Address के दो प्रकार समझे जाते हैं: Public IP Address और Private IP Address।

🌍

Public IP Address

Used for communication over the Internet. It is globally reachable, subject to network/firewall rules.

Internet पर communication के लिए उपयोग होता है। यह globally reachable हो सकता है, हालांकि firewall और network rules लागू हो सकते हैं।


Example: 203.0.113.10
🏠

Private IP Address

Used inside a local/private network such as a home or office LAN. It is not directly routable on the public Internet.

Home या office जैसे local/private network के अंदर उपयोग होता है। यह public Internet पर directly routable नहीं होता।


Example: 192.168.1.20

👥 6. Shared IP Address

In shared addressing, multiple customers or devices may appear on the Internet through the same public IP address. NAT or carrier-grade NAT can be used to separate their traffic.

Shared addressing में कई customers या devices Internet पर एक ही public IP address के माध्यम से दिखाई दे सकते हैं। उनके traffic को अलग रखने के लिए NAT या carrier-grade NAT का उपयोग हो सकता है।

🔄 7. NAT — Network Address Translation

NAT क्या करता है?

NAT translates addresses between a private/internal network and another network, commonly between private IPv4 addresses and public Internet-facing addresses.

NAT private/internal network के addresses को दूसरे network के लिए translate करता है। आम तौर पर private IPv4 addresses और Internet-facing public addresses के बीच translation किया जाता है।

🧮 13. IPv4 Address Classes

In traditional classful IPv4 addressing, the first octet determines the class. Modern networks generally use CIDR rather than relying on classful addressing.

Traditional classful IPv4 addressing में first octet के आधार पर class निर्धारित की जाती थी। Modern networks में सामान्यतः CIDR का उपयोग किया जाता है।

Class First Octet Range Default Subnet Mask Traditional Use
A 0 – 127 255.0.0.0 Large networks
B 128 – 191 255.255.0.0 Medium networks
C 192 – 223 255.255.255.0 Smaller networks
D 224 – 239 Not applicable Multicast
E 240 – 255 Not applicable Experimental / reserved
⚠️ Exam Correction:

Class D = 224–239
Class E = 240–255

इसलिए यदि किसी पुराने note में D = 224–247 और E = 248–255 लिखा है, तो उसे correct करके पढ़ें।

🧠 IP Classes Memory Trick

A → 0–127
B → 128–191
C → 192–223
D → 224–239
E → 240–255

Q1. Which type of IP address is generally used inside a local network?
A. Public IP
B. Private IP
C. Broadcast-only IP
D. Multicast-only IP
✅ Answer: B. Private IP

A. 8.8.8.8
B. 192.168.1.25
C. 1.1.1.1
D. 203.0.113.10
✅ Answer: B. 192.168.1.25

A. 10.0.0.0 – 10.255.255.255
B. 11.0.0.0 – 11.255.255.255
C. 100.0.0.0 – 100.255.255.255
D. 200.0.0.0 – 200.255.255.255
✅ Answer: A. 10.0.0.0 – 10.255.255.255
Q4. What does NAT stand for?
A. Network Access Transfer
B. Network Address Translation
C. Network Application Technology

✅ Answer: B. Network Address Translation

D. Random
✅ Answer: B. Static

A. Static
B. Dynamic
C. Dedicated
