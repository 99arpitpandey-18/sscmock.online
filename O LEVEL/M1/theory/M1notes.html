Chapter 1

Introduction to Computer

Computer एक Electronic machine है, जो हमारे दिए गए निर्देशों पर कार्य करती है। Computer Hardware और Software से मिलकर बना है, यह एक सार्वभौमिक मशीन है। Computer शब्द की उत्पत्ति कंप्यूट (Compute) शब्द से हुई है, जिसका अर्थ है गणना करना। Computer को हिंदी में संगणक कहते हैं, जो तेज गति से Arithmetic and Logical operation करता है।

Computer विभिन्न कार्यों को करता है:

  • यह Input के रूप में Data या Instructions को Accept करता है।
  • यह Data और Instructions को Store करता है।
  • यह Instructions के अनुसार Data को Processed करता है।
  • यह Computer के अंदर होने वाले सभी operations को Control करता है।
  • यह Output के रूप में Result देता है।

Computer Terms

  • Data — Row Facts and Figure जिन्हें Processed करने की आवश्यकता होती है।
  • Information — Meaningful Data जो Processed और Organized होता है, जिसे पढ़कर समझा जा सकता है।
  • Instruction — Command जो Computer को बताता है, क्या करना है।
  • Processing — Data पर Order में किए गए Works को Processing कहते हैं, जो Data को Information में Convert करने का कार्य करती है।
  • Hardware — Computer के Physical Component को Hardware कहते हैं।
  • Program — Program एक प्रकार का निर्देशों का समूह होता है, जो Computer को Sequential या Non Sequential order में बताता है कि उसे क्या करना है।
  • Software — Program के समूह को Software कहते हैं, जिसके द्वारा Computer किसी विशेष प्रकार के कार्य को करता है।

Computer के प्रमुख घटक

  • Central Processing Unit (CPU)
  • Memory Unit
  • Input Device
  • Output Device
Block Diagram of Computer:
Input Unit → Memory Unit → CPU (Control Unit + ALU) → Output Unit
Secondary Storage (connected to Memory Unit)

Central Processing Unit (CPU)

CPU का पूरा नाम Central Processing Unit है। यह Computer का दिमाग होता है। CPU का काम निर्देशों या प्रोग्रामों को Execute करना होता है। CPU निम्न Unit से मिलकर बना होता है:

  • CU (Control Unit) — पूरे Computer System के सभी कार्यों को नियंत्रित करता है।
  • ALU (Arithmetic Logical Unit) — Computer में सभी Arithmetic एवं Logical कार्य किए जाते हैं।
  • General Purpose Registers (MU) — Processing के समय Data को Store करने का काम करती है, Computer की सबसे Fast Memory।

Classification of Computer

Computer को दो तरीकों से Classified किया गया है:

  • कार्य करने के आधार पर (On the basis of work)
  • आकार के आधार पर (On the basis of size)

Type of Computer Basis on Work

  • Analog Computer — भौतिक मात्राओं को मापने का कार्य करते हैं (ताप, दबाव, लंबाई, चौड़ाई आदि)।
  • Digital Computer — Calculations and Logical Operations करते हैं। Data को 0,1 में परिवर्तित करके Electronic रूप में लेता है।
  • Hybrid Computer — Analog और Digital Computer दोनों का कार्य करते हैं (जैसे Petrol Pump)।

Type of Computer Base on Size

  • Micro Computer — आकार में छोटे, Microprocessor का उपयोग, घरों और छोटे व्यवसायों में उपयोग। (Desktop, Laptop, Palmtop, Notebook, Tablet)
  • Mini Computer — कंपनियों और सरकारी ऑफिस में Server Computer के कार्य के लिए। PDP-8 First Mini Computer (1965)।
  • Mainframe Computer — बड़ी कंपनियों और सरकारी ऑफिस में Server Computer के कार्य के लिए।
  • Super Computer — विशेष कार्य के लिए निर्मित, दुनिया के सबसे तेज़ और बड़े Computer। भारत का पहला Super Computer PARAM 8000।

Computer की विशेषताएँ

  • Speed (गति) — बहुत तीव्र गति से कार्य करता है, Processor की Speed को Hertz में मापा जाता है।
  • Accuracy (शुद्धता) — कार्य को बहुत शुद्धता के साथ करता है।
  • Multitalented (सार्वभौमिकता) — एक Multifunctional Machine है।
  • Memory — याद रखने की क्षमता बहुत अधिक है, आवश्यकतानुसार बढ़ाई या घटाई जा सकती है।
  • Diligence (परिश्रमशीलता) — बिना थके कई दिनों तक कार्य करने की क्षमता।
  • Honest (ईमानदारी) — कार्य को ईमानदारी के साथ करता है।
  • User-Friendly — चलाना सरल है।

Weakness (कमियाँ)

  • No IQ — सोचने-समझने की क्षमता नहीं है।
  • No Feeling — भावना नहीं है।

History of Computer

  • Abacus — 16वीं शताब्दी में चीन में, Addition/Subtraction के लिए।
  • Pascal's Calculator — 1642 में Blaise Pascal (France) द्वारा, Addition, Subtraction, Multiplication, Division।
  • Charles Babbage's Difference Engine — 1822 में, Charles Babbage (Modern Computer के पिता)।
  • Analytical Engine (1833) — Input, Storage, Process, Output — आधुनिक Computer का प्रारूप।
  • Tabulating Machine — 1880 में Herman Hollerith, Punched Cards।
  • Mark-1 — 1930 में Howard Aiken, पहली Electromechanical Calculator।
  • ENIAC — 1946 में Eckert & Mauchly, दुनिया का पहला Electronic Computer।
  • EDSAC — 1949 में Maurice Wilkes।

Generations of Computer

  • First Generation (1940–1956) — Vacuum Tube, Machine Language, ENIAC, UNIVAC-1।
  • Second Generation (1956–1963) — Transistor, High Level Language, IBM 1620, UNIVAC 1108।
  • Third Generation (1964–1971) — Integrated Circuit (IC), Multi Programming OS, IBM-360 series।
  • Fourth Generation (1972–2010) — LSI/VLSI, Microprocessor, GUI, MS-DOS, Windows, C, C++।
  • Fifth Generation (2010–continued) — ULSI, Artificial Intelligence, 64-bit Microprocessor, Desktop, Laptop, Notebook।

IT Gadgets and Their Applications

IT Device Information and Communication Technology के लिए उपयोग किया जाता है। जैसे — TV, Mobile, Laptop, Tablet, Desktop, PDA, GPS, Telephone।

Use of Computers in Different Fields

  • दैनिक जीवन में — Internet, Email, Games, Office कार्य।
  • शिक्षा में — Smart Classroom, e-classroom, Report Card, Online परीक्षा।
  • चिकित्सा में — बीमारी का निदान, Hospital Management, रिकॉर्ड रखना।
  • बैंकिंग में — Account Information, ATM, Transaction Tracking।
  • व्यापार में — Product Development, Marketing, Distribution।
  • मनोरंजन में — Movies, Online Games, Music।
  • रक्षा और सैन्य में — Missile Tracking, GPS, Simulation Training।
  • विज्ञान और अनुसंधान में — Data Processing, Weather, Earthquake।

Basics of Hardware and Software

Hardware — Computer के भौतिक भाग (जिन्हें Touch कर सकते हैं) — Microprocessor, Hard Disk, Monitor, Keyboard, Printer, etc.

Software — Program का समूह — System Software, Application Software, Utility Software।

Input Device

  • Keyboard — Standard 101–105 keys, Wired/Wireless, Multimedia keyboard।
  • Mouse — Optical, Wired, Wireless, Touchpad, Mechanical।
  • Scanner — Hard Copy को Soft Copy में बदलता है।
  • OMR — Optical Mark Reader, OMR Sheet को चेक करता है।
  • OCR — Optical Character Recognition, Image/PDF को Edit करने योग्य Data में बदलता है।
  • MICR — Magnetic Ink Character Recognition, Cheque checking in Banks।
  • Light Pen — Screen पर चित्र बनाने के लिए, CAD में उपयोग।
  • Joystick — Games खेलने और Robot Control के लिए।
  • Trackball — Pointing Input Device।
  • Touch Screen — उंगलियों से Input, Mobile में उपयोग।
  • Digitizing Tablet — Drawing Table।
  • Bar Code Reader — Barcode पढ़ने के लिए, Product Price/Date।

Output Device

  • Monitor — Visual Display Unit — CRT, LCD, LED।
  • Printer — Impact (Dot Matrix, Daisy Wheel, Line) और Non-Impact (Inkjet, Thermal, Laser, 3D Printer)।
  • Plotter — चित्र और Graph Print करने के लिए (Drum pen, Flatbed)।

Computer Memory and Storage

Primary Memory — Main Memory (RAM, ROM, Cache Memory)।

  • RAM — Volatile, Temporary, SRAM (Static) और DRAM (Dynamic)।
  • ROM — Non-Volatile, Permanent, PROM, EPROM, EEPROM।
  • Cache Memory — CPU और RAM के बीच, L1, L2, L3।

Secondary Memory — Storage Device (Magnetic Tape, Hard Disk, Floppy Disk, CD, DVD, Blu-ray Disc)।

Virtual Memory — CPU द्वारा Temporary Storage, Main Memory की Capacity बढ़ाता है।

Software — Types

  • System Software — Operating System, Assembler, Compiler, Interpreter, Utility Software।
  • Application Software — Horizontal (MS Office, Photoshop), Vertical (Finacle), Shareware, Freeware, Open Source, Commercial, Nagware।

Mobile Apps

  • Native Apps — एक specific OS/Device के लिए (जैसे iPhone App)।
  • Web-Based Apps — HTML, CSS, JavaScript, Web Browser से Access।
  • Hybrid Apps — Multi Device Compatible।

Example: WhatsApp, Facebook, Gmail, Snapchat, Instagram, Twitter, YouTube, Chrome।

📌 Chapter 1 — Important Questions

Q1. What is the difference between primary memory and secondary memory? Briefly explain various types of primary and secondary memory.

Primary memory — Internal, expensive, fast, volatile, less storage. (RAM, ROM, Cache)

Secondary memory — External, cheap, slow, non-volatile, more storage. (Hard Disk, CD, DVD, Magnetic Tape)

Q2. Explain the functions of Compiler, Interpreter and Assembler?

Compiler: High Level Language → Machine Language (entire program at once).

Interpreter: High Level Language → Machine Language (line by line, slower).

Assembler: Assembly Language ↔ Machine Language.

Q3. Draw an Internal Diagram of computer system and explain in brief the application of various components?

CPU (Brain) — CU, ALU, MU.
Memory Unit — Primary & Secondary.
Input Device — Keyboard, Mouse, Scanner, etc.
Output Device — Monitor, Printer, Plotter, etc.

Q4. Explain briefly System Software, Application and Utility Software?

System Software: Controls Hardware (OS, Compiler, Interpreter).
Application Software: Specific tasks (MS Word, Photoshop).
Utility Software: System maintenance (Antivirus, Disk Cleaner).

Q5. Explain the concept of Virtual memory? And describe volatile and non-volatile memory?

Virtual Memory: Temporary storage by CPU, increases Main Memory capacity.
Volatile: Loses data when power off (RAM).
Non-Volatile: Retains data when power off (Hard Disk, ROM).

Introduction to Operating System

Operating System किसी भी Computer का एक अहम हिस्सा होता है, जो Computer में Software के रूप में Store रहता है। Operating System Computer के सभी हिस्सों — Memory, Input, Output तथा Computer से जुड़े सभी Hardware Components को नियंत्रित करता है। Operating System एक System Software होता है।

Main Functions of Operating System

  • Processing Management — सभी Programs/Processes की स्थिति पर नजर रखना और संसाधन उपलब्ध कराना।
  • Memory Management — Primary memory को Manage करना, प्रत्येक Location का Record रखना।
  • Input Output Device Management — Device Communication का प्रबंधन।
  • File Management — File System को Directory में व्यवस्थित करना।
  • Protection and Security — Password security, Unauthorized access को रोकना।

Popular Operating System

Windows, Android, Macintosh, Unix, Linux। (Windows — Microsoft Corporation)

Types of Operating System (Based On Technology)

  • Single User OS (CUI Based) — एक User (MS-DOS, Windows)।
  • Multiuser OS (GUI Based) — कई Users (Unix, Linux)।
  • Single Tasking OS — एक समय में एक Task (MS-DOS)।
  • Multi Tasking OS — एक समय में कई Tasks (Windows, Unix, Linux)।
  • Real Time OS — Real-time Applications के लिए।

Operating Systems for Desktop and Laptop

Windows 10, Apple Mac OS, Linux (Open Source, Free)।

Operating Systems for Mobile Phones and Tablet

  • Android OS
  • IOS (Apple)
  • BlackBerry OS
  • Kai OS

User Interface for Desktop and Laptop

  • CUI (Character User Interface) — Commands type करके (MS-DOS, UNIX)।
  • GUI (Graphical User Interface) — Icons पर Click (Windows OS)।

Desktop

Desktop Computer का Primary User Interface है। Desktop Background, Wallpaper, Files, Folders, Icons।

Task Bar

Desktop पर सबसे नीचे की पट्टी। Left Side — Start Menu, Right Side — Notification Area।

Icons and Shortcuts

  • System Icon — My Computer, My Documents, Recycle Bin, Control Panel।
  • Shortcut Icon — Link to Program/Folder/File, Extension .lnk, Arrow mark।
  • Program Icon — Application Program का Icon।

Running an Application / Close Apps

Double Click या Right Click → Open। Close — Close Button या Alt + F4।

Operating System Simple Setting

  • Control Panel — Hardware और Software से संबंधित सभी Settings।
  • Mouse Properties — Control Panel → Mouse → Buttons, Pointers, Pointer Options।
  • System Date and Time — Task Bar Right Side → Right Click → Adjust Date/Time।
  • Display Properties — Desktop Right Click → Display Settings।
  • Add or Remove Programs — Control Panel → Programs and Features।
  • Adding, Removing and Sharing Printers — Control Panel → Devices and Printers → Add Printer / Remove Device।

File and Folder Management

File — Object जो Data, Information या Commands को Store करती है।

File Extension — File के नाम के अंत में Dot (.) के बाद, बताता है कि किस प्रकार की File है।

📌 Chapter 2 — Important Questions

Q1. What is an Operating System? Explain the Functions of Operating Systems.

OS: System Software जो User और Hardware के बीच संवाद स्थापित करता है, Application Software को Platform प्रदान करता है और Hardware को Control करता है।

Functions: Processing Management, Memory Management, I/O Device Management, File Management, Protection & Security.

Q2. What is Ubuntu Operating System? What are the Difference between Ubuntu and Windows Operating System?

Ubuntu: Linux-based Open Source OS for Personal Computer, Smart Phone, Server.

Differences: Ubuntu — Linux based, Open Source, Free, Server popular; Windows — DOS based, Closed Source, Paid, easier to use.

Q3. Explain following terms in the context of Linux operating system? (i) Kernel (ii) System Library (iii) Shell

Kernel: Core component, interacts directly with Hardware.
System Library: Special functions/programs that access Kernel features.
Shell: Interface to Kernel, takes commands and executes Kernel functions.

Q4. What do you mean by type of file extension?

File Extension: Identifier at the end of file name after dot (.), indicates file type. Example: .bmp (Image), .mp3 (Audio), .mp4 (Video), .docx (MS Word).

Q5. Describe the user interface for Desktop and Laptop?

CUI — Character User Interface, commands typed (MS-DOS, UNIX).
GUI — Graphical User Interface, icons clicked (Windows).

Word Processing

Word Processing Software एक Application Software है, जो User को Text Type, Edit और Text Manipulate करने में Help करता है। मुख्य रूप से Office में उपयोग किया जाता है।

Word Processing की विशेषताएँ

  • Spelling की गलतियों को ठीक किया जा सकता है।

Chapter 6

Introduction to Internet and WWW

Internet एक सबसे बड़ा Computer Network है, जिसमें Personal और Public दोनों प्रकार के Network आपस में जुड़े होते हैं। Internet एक Public Network है, जिसका कोई Owner नहीं होता। Internet से जुड़े सभी Device का अपना एक Unique IP Address होता है। Internet पर Information Send and Receive करने के लिए TCP/IP Protocol का Use होता है।

Internet की शुरुआत 1970 और 1980 के दशक में हुई। Internet ARPANET (Advance Research Projects Agency Network) के नाम से Defense Department द्वारा शुरू किया गया था। 1974 में Local Area Network ARPANET से TCP/IP के माध्यम से Connect किए जाते थे। India में Internet सेवा का पहला उपयोग 15 August 1995 को Videsh Sanchar Nigam Limited द्वारा किया गया। Internet के जनक Vint Cerf हैं।

Basics of Computer Networks

Computer Network दो या दो से अधिक Computer का एक Collection है, जो Information को Share करने के लिए एक दूसरे से जुड़े होते हैं।

Components of Computer Network

  • Network Adapter
  • Transmission Media
  • Servers
  • Clients
  • Protocols
  • Resources
  • User

Types of Communication Medium

  • Guided Media (Wired) — Coaxial Cable, Fiber-Optic Cable, Twisted Pair।
  • Unguided Media (Wireless) — Radio Waves, Microwave, Satellite।

Types of Network

  • LAN (Local Area Network) — 1 km तक, Private, High Speed।
  • MAN (Metropolitan Area Network) — Town/City, LAN से बड़ा, WAN से छोटा।
  • WAN (Wide Area Network) — Cities, Countries, Continents (Internet), Speed 10x slower than LAN।

Network Topology

  • Bus Topology — Single Cable (Back-bone), Terminator, Cheap, Small Network।
  • Ring Topology — Circular, Unidirectional, Sequential, Repeater।
  • Star Topology — Hub/Switch से जुड़े, Central Device Server की तरह।
  • Mesh Topology — All Nodes Directly Connected, Most Reliable, Expensive।
  • Tree Topology — Star + Bus Combination, Tree-like structure।

Networking Device

  • Repeater — Signal Regenerate and Replicate, Physical Layer।
  • Hub — Multiple Computers Connect, Physical Layer।
  • Switch — Multiport Bridge, Data Link Layer।
  • Bridge — Two LAN Segments Connect, Data Link Layer।
  • Router — Two or more Networks Connect, Network Layer।
  • Gateway — Two Different Networks Connect, Transport Layer।
  • NIC (Network Interface Card) — Parallel ↔ Serial Data Stream, Data Link & Physical Layer।
  • Modem — Analog ↔ Digital Signal, Internet Connect।

Applications of Internet

  • Communication
  • Education
  • Business
  • Entertainment
  • Medicine
  • Shopping

URL (Uniform Resource Locator): Website का Address। Example: SSC MOCK

Types of URL

  • Absolute URL — Protocol, Host-name, Folder-name, File-name (Complete)।
  • Relative URL — Only Folder-name and File-name (same server)।

World Wide Web (WWW)

WWW Internet का वह हिस्सा है जिसमें Website और Web-page शामिल हैं। 1989 में Tim Berners-Lee द्वारा CERN, Switzerland में आविष्कार। HTML, Hyperlink, URL।

  • Dynamic Website — Content changes per User, HTML + Programming + Database।

Introduction to IP Address

IP Address एक Number है जो Internet पर Computer/Device की पहचान करता है।

Types of IP Address

  • IPv4 — 32 Bit, 4 parts (0–255), ~4.3 Billion Addresses। Example: 172.16.254.1
  • IPv6 — 128 Bit, 8 groups of 4 Hex Digits। Example: 2001:0db8:0000:0042:0000:8a2e:0370:7334

ISP and Role of ISP

ISP (Internet Service Provider): Company जो Customers/Users को Internet Service Provide करती है।

  • Tier1 — High Level, Underwater Cables, connects World Wide Web corners।
  • Tier2 — Connects Tier1 and Tier3, Peering Agreements।
  • Tier3 — Last mile, provides to End Users।

Role of ISP

  • Provide Internet Connection
  • Provide Modem
  • Connect Information Service
  • E-mail Services
  • Antivirus Security
  • Web Hosting, Domain Management

Internet Protocol

  • TCP — Connection Oriented, End-to-End Delivery, works with IP।
  • IP — Routing and Addressing of Data Packets।
  • HTTP — Hyper Text Transfer, Port 80; HTTPS — Secure, Port 443।
  • FTP — File Transfer, Port 21, Faster than HTTP।
  • POP3 — Download Mail from Server, Port 110।
  • SMTP — Send Mail, Port 25।
  • Ethernet — LAN Communication।
  • UDP — Connection Free, no delivery check।
  • PPP — Data Link Layer, Direct Connection।
  • Telnet — Remote Login, Port 23।

Modes of Connecting Internet

  • Hotspot — Virtual Router, Wi-Fi based।
  • Wi-Fi — Wireless Fidelity, Radio Waves, High Speed।
  • LAN Cable — Ethernet Port, Cable Modem।
  • Broadband — High-Speed, Wide Frequency, Coaxial/Fiber।
  • USB Tethering — Mobile Data Share via USB Cable।

Identifying and Uses of IP/MAC/IMEI

  • IP Address — Network Device की पहचान।
  • MAC Address — Media Access Control, Physical/Hardware Address, 12 Digit Hex (6 Bytes), Unique।
  • IMEI — International Mobile Equipment Identity, 15/17 Digit Code, Phone की पहचान, *#06# से देखें।

Digital Financial Tools and Applications

वर्तमान में दुनिया Digitalization की ओर बहुत तेजी से आगे बढ़ रही है। Computer, Internet और Smartphone के आविष्कार ने Financial Services पर बहुत अधिक प्रभाव डाला है। अब कोई भी Person अपने Bank Account तक पहुँच सकता है, 24*7 Account Details, Money Transaction, Pay Bills, Ticket Booking कर सकता है।

Understanding OTP and QR Code

  • OTP (One Time Password) — एक Login Session या एक Transaction के लिए Valid, 6 Digit Code, Time Limit 10 Minute, Registered Mobile/E-mail पर भेजा जाता है।
  • QR Code (Quick Response Code) — Matrix Bar Code, 2D Bar Code, 1994 में Denso Wave (Japan) द्वारा Design, QR Scanner/Mobile Camera से Scan, Static & Dynamic।

UPI (Unified Payment Interface)

NPCI द्वारा Developed Instant Payment System, 11 April 2016 को Mumbai में RBI Governor Dr. Raghuram Ji Rajan द्वारा Launch। कई Bank Accounts को एक Mobile Application में Combine करता है। OTP की आवश्यकता नहीं।

Requirement for UPI

  • Bank Account
  • Debit Card for MPIN
  • Smart Phone with Internet
  • Mobile Number Linked with Bank Account

AEPS (Aadhaar Enable Payment System)

Aadhaar Authentication के माध्यम से Basic Banking Services (Balance Enquiry, Cash Withdrawal) — MicroATM/BankMitra, Bio-metrics Verification।

USSD (Unstructured Supplementary Service Data)

NPCI द्वारा Nov 2012, GSM Protocol, *99# Dial, Basic Feature Mobile पर Mobile Banking, Internet Data की आवश्यकता नहीं।

Card (Credit / Debit)

  • Credit Card — 1946 में John Biggins, Pre-defined Credit Limit, Credit Score और Monthly Income पर Based।
  • Debit Card — Savings/Current Account से Linked, ATM और POS Terminal पर Use, केवल Account में Available Money तक Limit।

E-Wallet

Online Prepaid Account, Digital रूप में Money Store, Instant & Secure Transactions — PayTM, PhonePe, PayZapp, MobiKwik, Google Pay।

Types of e-Wallet

  • Closed e-Wallet — केवल एक Special Site के लिए Use।
  • Semi-Closed e-Wallet — Related Sites पर भी Use, Cash Withdrawal नहीं।
  • Open e-Wallet — Banking Wallet, Bank Account से Connect, Cash Withdrawal भी।

PoS (Point of Sale)

Retail Store पर Use होने वाला System, 1879 में James Ritty, Hardware + Software, Thermal Printer for Bill।

Internet Banking

24*7 Financial & Non-Financial Transactions, User ID + Password, Features — Account Statement, Transaction Info, e-Commerce, Fund Transfer, Bill Payment, Mobile Recharge।

NEFT (National Electronic Fund Transfer)

Nov 2005, RBI, Batch-wise Transactions, 16 Dec 2019 से 24*7, No Upper/Lower Limit, Requires Beneficiary Name, Account Number, IFSC Code।

RTGS (Real Time Gross Settlement)

Mar 2004, RBI, Real Time, Monday–Saturday (8:00 AM – 6:00 PM), Minimum 2 Lakh, No Upper Limit।

IMPS (Immediate Payment Service)

22 Nov 2010, NPCI, 24*7, Real Time, Two ways — (1) Beneficiary Name + Account + IFSC, (2) MMID + Mobile Number।

Online Bill Payment

Utility Payment Online — Light Bill, Mobile Bill, Water Bill, Insurance Payment etc. via Internet Banking, Mobile Banking, Credit/Debit Card, e-Wallet।

📌 Chapter 9 — Important Questions

Q1. Describe Cloud Computing with Advantage of Cloud Computing?

Cloud Computing: Internet के माध्यम से Services — Data Storage, Servers, Database, Networking, Software। Advantages — Cost, Speed, Scalability, Security, Reliability।

Q2. Explain the Artificial Intelligence? What are the Applications of Artificial Intelligence?

AI: Technology जिसमें Machine को Program किया जाता है ताकि Intelligent Work कर सके। John McCarthy — AI के जनक। Applications — Gaming, NLP, Vision System, Expert System, Speech Recognition, Intelligent Robots।

Q3. What is Virtual Reality (VR)?

VR: Computer के माध्यम से ऐसी चीज़ों का अनुभव जो Actually में मौजूद नहीं हैं। 3D Environment, High Visual Multimedia।

Q4. Explain Robotics Process Automation (RPA) and Advantage of RPA?

RPA: Automated Software Tool, Software Robots बनाने के लिए, Advanced Technology। Advantages — Accuracy Increased, Tasks Completed Rapidly, Cost of Manpower Saved, Productivity Increased।

Q5. What is Blockchain Technology? How it Works?

Blockchain: Distributed Database, Transactions/Digital Events का Record, Bitcoin की Backbone Technology। Satoshi Nakamoto, 2008। Works — Digital Signature के माध्यम से Secure Transactions।
