1. Computer Network

Basic concept of computer networking

What is a Computer Network?

🇬🇧 ENGLISH

A computer network is a group of two or more computers or devices connected together to communicate and share resources such as files, printers and Internet connections.

🇮🇳 हिंदी

Computer network दो या दो से अधिक computers या devices का ऐसा समूह है जो communication और resources जैसे files, printers तथा Internet connection को share करने के लिए connected होते हैं।

📌 EXAM DEFINITION

Network = Connected devices + Communication + Resource Sharing.

🔗

2. LAN, WAN & Network Types

Important network classifications

🏢

LAN

Local Area Network covers a relatively small geographical area such as a room, office, school or building.

🌍

WAN

Wide Area Network covers a large geographical area and can connect networks across cities or countries.

🏙️

MAN

Metropolitan Area Network generally covers an area larger than LAN but smaller than a WAN.

Network Full Form Area Example
LAN Local Area Network Small Area School / Office
MAN Metropolitan Area Network City / Metro Area City Network
WAN Wide Area Network Large Area Internet
🔵

3. Network Topology

Arrangement of devices in a network

What is Network Topology?

🇬🇧 ENGLISH

Network topology refers to the physical or logical arrangement of computers, devices and communication links in a network.

🇮🇳 हिंदी

Network topology network में computers, devices और communication links की physical या logical arrangement को कहते हैं।

⭐

Star Topology

All devices are connected to a central device such as a switch or hub.

➖

Bus Topology

Devices share a common communication backbone or cable.

🔄

Ring Topology

Devices are connected in a circular arrangement.

🌳

Tree Topology

A hierarchical structure that combines characteristics of multiple topologies.

🕸️

Mesh Topology

Devices have multiple interconnections, providing alternative communication paths.

🔗

Hybrid Topology

Combination of two or more different network topologies.

🌍

4. Internet

Global network of interconnected networks

What is Internet?

🇬🇧 ENGLISH

The Internet is a worldwide system of interconnected computer networks that communicate using standard protocols.

🇮🇳 हिंदी

Internet interconnected computer networks का एक worldwide system है जो standard communication protocols का उपयोग करके information exchange करता है।

Applications of Internet

  • Information and research
  • Online education
  • E-mail communication
  • Online shopping
  • Online banking
  • Video and audio communication
  • Government services
  • Social networking
🕸️

5. World Wide Web (WWW)

Web and Internet relationship

What is WWW?

🇬🇧 ENGLISH

World Wide Web (WWW) is a system of interconnected web pages and resources accessed through the Internet using web browsers.

🇮🇳 हिंदी

World Wide Web (WWW) interconnected web pages और resources का system है जिसे Internet के माध्यम से web browser द्वारा access किया जाता है।

⭐ INTERNET vs WWW

Internet एक global network infrastructure है, जबकि WWW Internet पर उपलब्ध interconnected web pages और web resources की service है।

🔗

6. Website Address & URL

Uniform Resource Locator

URL — Uniform Resource Locator

🇬🇧 ENGLISH

URL is the address used to locate a resource on the Internet or World Wide Web.

🇮🇳 हिंदी

URL Internet या World Wide Web पर किसी resource को locate करने के लिए उपयोग किया जाने वाला address है।

📌 Example

https://www.example.com/index.html

Common URL Components

  • Protocol — https
  • Domain / Host — www.example.com
  • Path — /index.html
🆔

7. IP Address

Internet Protocol Address

What is an IP Address?

🇬🇧 ENGLISH

An IP Address is a numerical address used to identify and communicate with a device on an IP network.

🇮🇳 हिंदी

IP Address एक numerical address है जिसका उपयोग IP network पर किसी device को identify और communicate करने के लिए किया जाता है।

Version Full Form Example
IPv4 Internet Protocol Version 4 192.168.1.10
IPv6 Internet Protocol Version 6 2001:db8::1
📡

8. ISP & Internet Protocol

Internet Service Provider and protocols

ISP — Internet Service Provider

🇬🇧 ENGLISH

An ISP is an organization or company that provides users with access to the Internet and related services.

🇮🇳 हिंदी

ISP ऐसी organization या company है जो users को Internet access और related services प्रदान करती है।

📌 EXAM POINT

ISP = Internet Service Provider. इसका मुख्य role users को Internet connectivity प्रदान करना है।

Common Internet Protocols

Protocol Meaning / Use
HTTP Hypertext Transfer Protocol
HTTPS HTTP with secure encrypted communication
FTP File Transfer Protocol
TCP/IP Core protocol suite used for Internet communication
DNS Domain Name System

9. Modes of Connecting to Internet

Common Internet connectivity methods

📱

Mobile Hotspot

A mobile device can share its Internet connection with other devices through hotspot functionality.

📶

Wi-Fi

Wireless networking technology used to connect devices to a network or Internet.

🔌

LAN Cable

Wired Ethernet connection can provide network and Internet access.

🌐

Broadband

High-speed Internet access delivered through suitable wired or wireless technologies.

🔗

USB Tethering

A phone can share its mobile Internet connection with another device through USB.

📡

Wireless Connection

Data communication without a physical network cable.

🆔

10. IP, MAC & IMEI

Device identification concepts

Term Full Form Basic Use
IP Internet Protocol Address Identifies/address a device on an IP network
MAC Media Access Control Network interface hardware address
IMEI International Mobile Equipment Identity Identifies a mobile equipment/device

🧠 EASY TRICK

IP → Network Address
MAC → Network Interface Address
IMEI → Mobile Equipment Identity

11. Web Browsers

Software used to access websites

🌈

Google Chrome

Popular web browser used for accessing websites and web applications.

🦊

Mozilla Firefox

A popular web browser used for browsing websites and Internet resources.

🔵

Microsoft Edge

Microsoft's modern web browser for browsing the Internet.

🔴

Opera

Web browser offering browsing and various built-in features.

📌 Browser vs Search Engine

Browser = Website access करने वाला software.

Search Engine = Internet पर information/websites खोजने वाली online service.

🔍

12. Search Engines

Searching information on the Internet

What is a Search Engine?

🇬🇧 ENGLISH

A search engine is an online service that helps users find information and web pages on the Internet using search queries.

🇮🇳 हिंदी

Search engine एक online service है जो search query के आधार पर Internet पर information और web pages खोजने में मदद करती है।

Searching Tips

  • Use specific keywords.
  • Avoid unnecessarily long queries.
  • Use quotation marks for exact phrases when supported.
  • Check reliable sources before trusting information.
  • Compare information from multiple sources.
🏄

13. Exploring & Surfing the Web

Basic web browsing process

Web Surfing

🇬🇧 ENGLISH

Web surfing means navigating from one webpage or website to another using links, search results and browser controls.

🇮🇳 हिंदी

Web surfing का अर्थ links, search results और browser controls की सहायता से एक webpage या website से दूसरे webpage तक जाना है।

Basic Browser Actions

  • Open a website
  • Enter a URL
  • Search information
  • Open hyperlinks
  • Go Back / Forward
  • Refresh webpage
  • Download available files
  • Print webpage
📥

14. Downloading & Printing Web Pages

Useful Internet operations

Downloading

🇬🇧 ENGLISH

Downloading means transferring a file or resource from a remote server to your local device.

🇮🇳 हिंदी

Downloading का अर्थ किसी remote server से file या resource को अपने local device में transfer करना है।

Printing

A webpage can generally be printed using the browser's Print option or the keyboard shortcut Ctrl + P.

Important Comparisons

Frequently confused concepts

Concept 1 Concept 2 Difference
Internet WWW Internet is the network infrastructure; WWW is a web service running over the Internet.
Browser Search Engine Browser accesses websites; search engine helps find web information.
LAN WAN LAN covers a smaller area; WAN covers a much larger geographical area.
IP MAC IP is used for IP network addressing; MAC identifies a network interface.
Download Upload Download transfers data to your device; upload transfers data from your device to a remote system.
