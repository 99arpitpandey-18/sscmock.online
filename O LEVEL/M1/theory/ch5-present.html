1. Introduction to Presentation

Basic concept of presentation software

What is a Presentation?

🇬🇧 ENGLISH

A presentation is a collection of slides used to communicate information, ideas, facts or concepts to an audience.

🇮🇳 हिंदी

Presentation slides का एक collection है जिसका उपयोग information, ideas, facts या concepts को audience तक पहुँचाने के लिए किया जाता है।

📌 Exam Definition

Presentation software is application software used to create, edit and display information in the form of slides.

3. Creating a Presentation

Basic workflow

Basic Steps

🇬🇧 ENGLISH
  • Open LibreOffice Impress.
  • Select a presentation type or template.
  • Choose a suitable slide layout.
  • Add title and content.
  • Insert required objects.
  • Apply formatting and design.
  • Add transitions or animations where required.
  • Save the presentation.
  • Start the slide show.

  • LibreOffice Impress खोलें।

Presentation का basic building block

What is a Slide?

🇬🇧 ENGLISH

A slide is an individual page or screen of a presentation. A presentation normally consists of multiple slides.

9. Slide Transition & Animation

Visual effects in presentation

Slide Transition

🇬🇧 ENGLISH

A slide transition is a visual effect used when moving from one slide to another during a slide show.

🇮🇳 हिंदी

Slide transition वह visual effect है जो slide show के दौरान एक slide से दूसरी slide पर जाते समय दिखाई देता है।

⭐ EXAM POINT

Transition is applied to the change between slides.

Animation

🇬🇧 ENGLISH

Animation effects are applied to objects or elements within a slide.

🇮🇳 हिंदी

Animation effects slide के अंदर मौजूद objects या elements पर apply किए जाते हैं।

▶️

10. Slide Show

Presenting slides to an audience

Slide Show Basics

  • Slide Show displays the presentation to the audience.
  • F5 starts the slide show from the first slide.
  • Esc is used to stop/exit the slide show.
  • Home can be used to jump to the first slide.
  • Page Down moves toward the next slide.
  • Page Up moves toward the previous slide.

🎯 HIGH PRIORITY

Remember: F5 = Start Slide Show and Esc = Exit Slide Show.

Important Exam Points

Quick MCQ revision

  • LibreOffice Impress is a Presentation program.
  • Presentation consists of multiple slides.
  • Impress uses .odp as its OpenDocument presentation format.
  • Ctrl + M is used to insert a new slide.
  • Normal View is the main editing view.
  • Outline View displays the text structure of a presentation.
  • Slide Sorter is useful for arranging slides.
  • Notes View is used for speaker notes.
  • Master Slide helps maintain consistent design.
  • Transition is an effect between slides.
  • Animation is generally applied to objects within a slide.
  • F5 starts the slide show.
  • Esc exits the slide show.
  • Ctrl + P is used for printing.
  • Ctrl + S is used for saving.
🔥

Transition vs Animation

Very important conceptual difference

Point Transition Animation
Applied To Slide change Objects / elements
When visible While moving between slides While displaying objects on a slide
Purpose Make slide change visually interesting Control how objects appear or move
Easy Trick Slide → Slide Object → Object
