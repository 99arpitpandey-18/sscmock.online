1. Introduction to Word Processing

Basic concept and purpose

What is Word Processing?

🇬🇧 ENGLISH

Word processing is the use of computer software to create, edit, format, save and print text-based documents.

🇮🇳 हिंदी

Word Processing computer software की सहायता से text documents को create, edit, format, save और print करने की प्रक्रिया है।

📌 EXAM DEFINITION

A word processor is application software used for creating and manipulating text documents.

⚡

Important functions and capabilities

✏️

3. Creating and Managing Documents

Basic document operations

Common Document Operations

🇬🇧 ENGLISH
  • New — Create a new document
  • Open — Open an existing document
  • Save — Store the document
  • Save As — Save with another name/location

🇮🇳 हिंदी

  • Save — document सुरक्षित करना

4. Editing a Document

Modify and organize document content

Important Editing Operations

  • Insert text — नया text जोड़ना
  • Delete text — text हटाना
  • Select text — text का चयन करना
  • Cut — selected content को हटाकर clipboard में रखना
  • Copy — content की duplicate copy बनाना
  • Paste — clipboard content को document में डालना
  • Undo — पिछली action को वापस करना
  • Redo — undone action को फिर से करना

⭐ EXAM POINT

Cut, Copy और Paste operations के लिए Clipboard का concept बहुत important है।

8. Working with Tables

Rows, columns and cells

What is a Table?

🇬🇧 ENGLISH

A table organizes information into rows and columns. The intersection of a row and column forms a cell.

🇮🇳 हिंदी

Table information को rows और columns में व्यवस्थित करता है। Row और column के intersection को cell कहते हैं।

Common Table Operations

  • Insert Table — table जोड़ना
  • Insert Row — नई row जोड़ना
  • Insert Column — नया column जोड़ना
  • Delete Row — row हटाना
  • Delete Column — column हटाना
  • Merge Cells — cells को जोड़ना
  • Split Cells — cell को विभाजित करना

10. Header, Footer and Page Number

Useful document elements

🇬🇧 ENGLISH

A header appears at the top of a page, while a footer appears at the bottom. Page numbers can be inserted into documents for easy navigation.

11. Find and Replace

Search and modify text quickly

🇬🇧 ENGLISH

Find is used to search for specific text in a document. Replace is used to replace the found text with new text.

🇮🇳 हिंदी

Find का उपयोग document में किसी specific text को खोजने के लिए किया जाता है। Replace उस text को दूसरे text से बदलता है।

⭐ EXAM FACT

Find and Replace is especially useful when the same word or phrase appears many times in a document.

13. Mail Merge

Important examination topic

What is Mail Merge?

🇬🇧 ENGLISH

Mail Merge is a feature used to create multiple personalized documents from one main document and a data source.

🇮🇳 हिंदी

Mail Merge एक ऐसी सुविधा है जिससे एक main document और data source की सहायता से कई personalized documents बनाए जा सकते हैं।

Main Components

  • Main Document — मुख्य document
  • Data Source — recipients/data की जानकारी
  • Merge Fields — data के लिए fields
  • Final Merged Document — तैयार personalized document

⭐ VERY IMPORTANT

Example: एक ही invitation letter को अलग-अलग लोगों के नाम और addresses के साथ generate करना Mail Merge का common use है।

Quick Differences

Important comparison-based questions

Concept Difference
Cut vs Copy Cut removes selected content from its original position; Copy keeps the original content.
Header vs Footer Header appears at the top; Footer appears at the bottom of a page.
Bullets vs Numbering Bullets generally represent unordered lists; numbering represents ordered lists.
Portrait vs Landscape Portrait is vertically oriented; Landscape is horizontally oriented.
Save vs Save As Save updates the current document; Save As allows saving with a different name/location.
