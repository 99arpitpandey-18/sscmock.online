CHAPTER 01 • M1-R5.1

🖥 Introduction to Computer

Computer fundamentals, characteristics, generations, hardware, software, memory, input/output devices and basic concepts.

💡

1.1 What is a Computer?

Basic definition

Computer Definition

🇬🇧 ENGLISH

A computer is an electronic programmable device that accepts data as input, processes it according to instructions, stores it and produces meaningful output.

🇮🇳 हिंदी

Computer एक electronic programmable device है जो data को input के रूप में स्वीकार करता है, instructions के अनुसार process करता है, उसे store करता है और meaningful output देता है।

📌 Exam Definition

Input → Processing → Output → Storage computer के basic working cycle को समझाने का आसान तरीका है।

⭐

1.2 Characteristics of Computer

Important properties

⚡

Speed

Computer बहुत तेजी से calculations और instructions execute कर सकता है।

🎯

Accuracy

सही instructions और data मिलने पर computer highly accurate results देता है।

💾

Storage

Computer बड़ी मात्रा में data को store और retrieve कर सकता है।

🔄

Automation

Program और instructions मिलने के बाद computer automatically tasks perform कर सकता है।

♾️

Diligence

Computer बिना थके repetitive operations लगातार perform कर सकता है।

🌐

Versatility

Computer education, banking, business, science और communication में उपयोग होता है।

🧩

1.3 Hardware & Software

Two fundamental parts

🧱 Hardware

English: Physical components of a computer that can be seen and touched. Examples: keyboard, mouse, monitor, CPU, printer and hard disk.

हिंदी: Computer के वे physical parts जिन्हें हम देख और छू सकते हैं hardware कहलाते हैं।

💿 Software

English: A collection of programs and instructions used to operate a computer.

हिंदी: Programs और instructions का collection software कहलाता है।

🧠

1.4 Types of Software

Exam important classification

⚙️

System Software

Computer hardware को manage और control करने वाला software. Example: Operating System.

📱

Application Software

User के specific tasks के लिए बनाया गया software. Example: Word processor, spreadsheet.

🛠️

Utility Software

System maintenance और management के लिए उपयोग होने वाले programs.

💾

1.5 Memory

Primary and secondary memory

🇬🇧 ENGLISH
  • RAM is temporary / volatile memory.
  • ROM is generally non-volatile memory.
  • Primary memory is directly accessible by CPU.
  • Secondary storage is used for long-term storage.
🇮🇳 हिंदी
  • RAM temporary या volatile memory है।
  • ROM generally non-volatile memory है।
  • Primary memory CPU द्वारा directly access की जाती है।
  • Secondary storage long-term data storage के लिए होती है।
Unit Meaning Hindi
Bit Binary Digit बाइनरी अंक
Byte 8 Bits 8 बिट
KB Kilobyte किलोबाइट
MB Megabyte मेगाबाइट
GB Gigabyte गीगाबाइट
TB Terabyte टेराबाइट
⌨️

1.6 Input & Output Devices

Must remember examples

Device Type Use
Keyboard Input Typing data
Mouse Input Pointing and selection
Scanner Input Converts physical document to digital form
Monitor Output Displays information
Printer Output Produces hard copy
Speaker Output Produces sound

🎯 CHAPTER 1 EXAM POINTS

Computer = Input + Processing + Output + Storage. Hardware physical होता है, software instructions/programs का collection होता है. RAM volatile होती है जबकि ROM generally non-volatile होती है. Keyboard, mouse और scanner input devices हैं जबकि monitor, printer और speaker output devices हैं।

Definition and role

🇬🇧 ENGLISH

4.1 Spreadsheet क्या है?

Basic concept

🇬🇧 ENGLISH

A spreadsheet is an application used to organize, calculate, analyze and present data in rows and columns.

🇮🇳 हिंदी

Spreadsheet एक application है जिसका उपयोग data को rows और columns में organize, calculate, analyze और present करने के लिए किया जाता है।

📄

↔️

Row

4.3 Formula

Calculation in spreadsheet

🇬🇧 ENGLISH

A formula is an expression used to perform calculations in a spreadsheet. Formulas generally begin with an equal sign (=).

🇮🇳 हिंदी

Formula spreadsheet में calculation करने के लिए use किया जाने वाला expression है। सामान्यतः formula equal sign (=) से शुरू होता है।

Formula Purpose
=A1+B1 Addition
=A1-B1 Subtraction
=A1*B1 Multiplication
=A1/B1 Division
🧮

4.4 Important Functions

Very important for objective questions

Function Purpose Example
