2. Artificial Intelligence (AI)

Introduction to intelligent systems

Artificial Intelligence

🇬🇧 ENGLISH

Artificial Intelligence is a branch of computer science that focuses on creating systems capable of performing tasks that normally require human intelligence.

🇮🇳 हिंदी

Artificial Intelligence computer science की एक branch है जिसमें ऐसे systems बनाए जाते हैं जो सामान्यतः human intelligence की आवश्यकता वाले tasks कर सकते हैं।

Common Applications of AI

  • Voice Assistants — Voice based interaction
  • Recommendation Systems — Content/product recommendations
  • Image Recognition — पहचान और classification
  • Natural Language Processing — Human language processing
  • Chatbots — Automated conversation systems
  • Medical and scientific data analysis

⭐ IMPORTANT FOR EXAM

3. Internet of Things (IoT)

Connected smart devices

Internet of Things

🇬🇧 ENGLISH

IoT refers to a network of physical objects or devices connected to the Internet that can collect, send and exchange data.

🇮🇳 हिंदी

IoT physical objects या devices के ऐसे network को कहा जाता है जो Internet से connected होते हैं और data collect तथा exchange कर सकते हैं।

Examples of IoT Devices

  • Smart Watches
  • Smart Home Devices
  • Smart Sensors
  • Connected Vehicles
  • Smart Agriculture Systems
  • Industrial Monitoring Devices
📌 Remember

IoT = Devices + Sensors + Network + Data Exchange.

4. Cloud Computing

Computing services over the Internet

Cloud Computing

🇬🇧 ENGLISH

Cloud computing is the delivery of computing resources such as storage, servers, databases, networking and software through the Internet.

🇮🇳 हिंदी

Cloud Computing Internet के माध्यम से storage, servers, databases, networking और software जैसी computing resources उपलब्ध कराने की technology है।

Major Cloud Service Models

Model Full Form Meaning हिंदी
IaaS Infrastructure as a Service Virtual infrastructure resources Infrastructure उपलब्ध कराना
PaaS Platform as a Service Platform for application development Development platform उपलब्ध कराना
SaaS Software as a Service Software delivered through Internet Internet के माध्यम से software

⭐ EXAM TRICK

IaaS → Infrastructure, PaaS → Platform, SaaS → Software.

5. Big Data

Large and complex datasets

Big Data

🇬🇧 ENGLISH

Big Data refers to extremely large, rapidly generated and complex datasets that traditional data processing methods may not efficiently handle.

🇮🇳 हिंदी

Big Data बहुत बड़े, तेजी से generate होने वाले और complex datasets को कहा जाता है जिन्हें traditional methods से efficiently process करना कठिन हो सकता है।

V Meaning हिंदी

Variety Different forms of data Data के विभिन्न प्रकार

6. Blockchain Technology

Distributed digital ledger

Blockchain

🇬🇧 ENGLISH

Blockchain is a distributed digital ledger in which records are stored in linked blocks and shared across a network.

🇮🇳 हिंदी

Blockchain एक distributed digital ledger है जिसमें records linked blocks में store किए जाते हैं और network में share किए जाते हैं।

Important Features

  • Distributed — Data multiple network participants के पास हो सकता है।
  • Transparency — Transactions को verify किया जा सकता है।
  • Security — Cryptographic techniques का उपयोग किया जाता है।
  • Immutability — Recorded information को बदलना कठिन बनाया जाता है।
  • Decentralization — एक single central authority पर निर्भरता कम होती है।

7. Cyber Security

Protection of digital systems and information

What is Cyber Security?

🇬🇧 ENGLISH

Cyber Security is the practice of protecting computers, networks, applications, devices and data from unauthorized access, attacks, damage or disruption.

🇮🇳 हिंदी

Cyber Security computers, networks, applications, devices और data को unauthorized access, attacks, damage या disruption से protect करने की practice है।

📌 CIA Triad

Cyber Security में CIA का अर्थ है: Confidentiality, Integrity और Availability.

🔐

Confidentiality

Information should be accessible only to authorized persons.

🧩

Integrity

Data should remain accurate, complete and protected from unauthorized modification.

⚡

Availability

Authorized users should be able to access required information and services when needed.

🦠

8. Malware & Cyber Threats

Common types of malicious software

Malware

🇬🇧 ENGLISH

Malware is malicious software designed to damage systems, steal information, disrupt operations or gain unauthorized access.

🇮🇳 हिंदी

Malware ऐसा malicious software है जिसे system को नुकसान पहुँचाने, information चोरी करने, operations को disrupt करने या unauthorized access प्राप्त करने के लिए बनाया जाता है।

Types of Malware

Type English हिंदी
Virus Malicious code that can attach to files/programs and spread when executed. Malicious code जो files/programs से जुड़कर फैल सकता है।
Worm Malware that can self-replicate and spread across networks. स्वयं की copies बनाकर network में फैल सकता है।
Trojan Malicious software disguised as legitimate software. Legitimate software जैसा दिखाई देने वाला malicious program।
Spyware Software that secretly monitors or collects information. गुप्त रूप से information monitor या collect करने वाला software।
Ransomware Malware that can restrict access to data or systems and demand payment. Data या system access को restrict करके payment मांगने वाला malware।

9. Phishing & Social Engineering

Common methods used to trick users

Phishing

🇬🇧 ENGLISH

Phishing is a fraudulent technique in which attackers attempt to trick users into revealing sensitive information such as passwords or account details by pretending to be a trusted entity.

🇮🇳 हिंदी

Phishing एक fraudulent technique है जिसमें attacker trusted entity बनकर users को password या account details जैसी sensitive information share करने के लिए trick करता है।

Common Warning Signs

  • Unexpected messages asking for sensitive information
  • Suspicious links or attachments
  • Fake login pages
  • Urgent or threatening messages
  • Unknown sender or unusual domain
  • Offers that appear too good to be true

🚨 GOLDEN RULE

Never share passwords, OTPs, PINs or other sensitive credentials in response to unexpected messages or calls.

🔑

10. Password & Account Security

Protecting online accounts

Strong Password Practices

🇬🇧 ENGLISH
  • Use long and unique passwords.
  • Avoid easily guessable information.
  • Do not reuse the same password everywhere.
  • Use a password manager when appropriate.
  • Enable multi-factor authentication where available.
  • Never share passwords or OTPs.
🇮🇳 हिंदी
  • Long और unique passwords का उपयोग करें।
  • आसानी से guess होने वाली information avoid करें।
  • एक ही password को हर जगह reuse न करें।
  • आवश्यकता होने पर password manager का उपयोग करें।
  • उपलब्ध होने पर multi-factor authentication enable करें।
  • Password या OTP कभी share न करें।
🛡️

11. Safe Internet & Cyber Safety

Best practices for digital safety

Cyber Safety Rules

🇬🇧 ENGLISH
  • Keep operating systems and applications updated.
  • Use trusted sources for software and apps.
  • Avoid opening suspicious links and attachments.
  • Use secure network connections for sensitive activities.
  • Back up important data regularly.
  • Review privacy and security settings.
  • Log out from shared/public computers.
🇮🇳 हिंदी
  • Operating System और applications को updated रखें।
  • Software और apps trusted sources से ही लें।
  • Suspicious links और attachments को avoid करें।
  • Sensitive activities के लिए secure network का उपयोग करें।
  • Important data का regular backup रखें।
  • Privacy और security settings को check करें।
  • Shared/public computer से logout करना न भूलें।
