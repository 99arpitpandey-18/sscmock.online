Chapter 1

Introduction to Computer

Computer कंप्यूटर is derived from Latin "Computare" – to compute. It is an electronic device that processes data according to instructions.

Four basic units: Input, Storage, CPU, Output.

Classification of Computer

  • Analog Computer एनालॉग कंप्यूटर – processes continuous data (temperature, pressure).
  • Digital Computer डिजिटल कंप्यूटर – processes discrete data (binary).
  • Hybrid Computer हाइब्रिड कंप्यूटर – combines analog & digital.

Digital Computers – by size & power

  • Micro Computer माइक्रो कंप्यूटर – small, cheap, uses microprocessor. Types: Desktop, Laptop, Notebook, PDA.
  • Mini Computer मिनी कंप्यूटर – multi-user, supports 10–100 users.
  • Mainframe Computer मेनफ्रेम कंप्यूटर – powerful, supports thousands of users, used in banks, airlines.
  • Super Computer सुपर कंप्यूटर – fastest, most expensive, used in space, weather, military.

Characteristics of Computer

  • Speed गति – millions of instructions per second.
  • Accuracy सटीकता – 100% accurate.
  • Versatility बहुमुखी प्रतिभा – can do many tasks.
  • Power of remembering स्मरण शक्ति – stores large data.
  • Diligence लगन – no tiredness.
  • Storage भंडारण – primary (RAM/ROM) and secondary (hard disk, CD).

Components of Computer System

  • Input Unit इनपुट यूनिट – Keyboard, Mouse, Scanner, Joystick, Barcode Reader.
  • CPU सीपीयू – Control Unit (CU) and Arithmetic Logic Unit (ALU).
  • Memory Unit मेमोरी यूनिट – primary (RAM, ROM, Cache) and secondary (hard disk, CD, DVD, USB).
  • Output Unit आउटपुट यूनिट – Monitor, Printer, Plotter.

Processor Speed & Booting

Processor speed प्रोसेसर की गति measured in Hertz (MHz, GHz). Booting बूटिंग is the initialization process; boot loader loads the OS.

Memory Types

  • Primary Memory प्राथमिक मेमोरी – RAM (SRAM, DRAM), ROM (PROM, EPROM, EEPROM).
  • Secondary Memory द्वितीयक मेमोरी – Floppy disk, Hard disk, Optical disk (CD, DVD, Blu-ray), USB thumb drive.
  • Cache Memory कैश मेमोरी – small, fast memory between CPU and RAM.

Computer Software

  • System Software सिस्टम सॉफ्टवेयर – OS, Utility programs.
  • Application Software एप्लिकेशन सॉफ्टवेयर – MS Word, Excel, PowerPoint, etc.

Compiler, Interpreter

Compiler कंपाइलर translates entire program into machine code. Interpreter इंटरप्रेटर translates line by line.

High-level languages (COBOL, FORTRAN, C, C++, Java, PHP) are closer to human language.

📌 Important Questions – Chapter 1

Q1. What is the difference between primary and secondary memory?

Primary – internal, fast, volatile, expensive, less storage. Secondary – external, slow, non-volatile, cheap, more storage.

Q2. Explain Compiler, Interpreter, Assembler.

Compiler – whole program to machine code. Interpreter – line by line. Assembler – Assembly ↔ Machine.

Q3. Draw and explain block diagram of computer.

Input → Memory → CPU (CU & ALU) → Output. Secondary storage connected to memory.

Chapter 2

Introduction to Operating System

Operating System (OS) ऑपरेटिंग सिस्टम – system software that manages hardware, software, and provides user interface. It handles processing, memory, I/O, file management, and security.

Popular OS

  • Windows (Microsoft) – versions: 1.0, 2.0, 3.0, 95, 98, 2000, XP, Vista, 7, 8, 10, 11.
  • Linux – open source, kernel-based, supports multitasking, multi-user.
  • macOS – Apple's OS.

Basic Windows Elements

  • Window – application window, dialog box.
  • Taskbar टास्कबार – bottom bar with Start menu, notification area.
  • Icons आइकॉन – small graphics for programs.
  • Start Menu – access to programs, settings.
  • Title Bar – shows window name, includes Minimize, Maximize/Restore, Close buttons.
  • Menu Bar – contains menus (File, Edit, View, etc.).

File Management

Using Windows Explorer or My Computer – create, rename, delete, copy, move files/folders. Also view details (name, type, size).

System Tools

  • Disk Cleanup – frees space by deleting temporary files.
  • Disk Defragmenter – rearranges fragmented data for efficiency.

Accessories

  • Notepad – simple text editor.
  • WordPad – basic word processor with formatting.
  • Paint – graphics drawing program.
  • Calculator – Standard, Scientific, Programmer, Statistics modes.
  • Command Prompt – CLI for commands (dir, cd, etc.).

Linux Overview

Linux is a UNIX-like kernel developed by Linus Torvalds (1991). It is free, open-source, supports multitasking, multi-user, TCP/IP, and many file systems. It has a hierarchical file system starting from root (/).

Linux File Structure: /bin, /boot, /dev, /etc, /home, /lib, /usr, /var, /tmp, etc.

📌 Important Questions – Chapter 2

Q1. What is an OS? Explain its functions.

OS is system software managing hardware/software. Functions: Processing, Memory, I/O, File, Security management.

Q2. Difference between Ubuntu and Windows?

Ubuntu – Linux-based, open source, free. Windows – DOS-based, closed source, paid.

Q3. Explain Kernel, System Library, Shell in Linux.

Kernel – core, interacts with hardware. System Library – functions to access kernel. Shell – interface for user commands.

Chapter 3

Word Processing

Word Processing वर्ड प्रोसेसिंग – creating, editing, formatting documents. Microsoft Word is a popular word processor.

Features of MS Word

  • Create letters, resumes, reports.
  • Store electronically.
  • Edit, format text.
  • Insert tables, graphics, charts.
  • Mail merge, spell check, grammar check.

Opening, Saving, Closing

  • Open – File → Open or Ctrl+O.
  • Save – Ctrl+S (first time use Save As). File naming rules: up to 260 chars, no / \ > < * ? " : |.
  • Close – Ctrl+W or Alt+F4.

Text Selection & Editing

  • Select: double-click word, triple-click paragraph, Ctrl+A for all.
  • Edit: Copy (Ctrl+C), Cut (Ctrl+X), Paste (Ctrl+V), Undo (Ctrl+Z), Redo (Ctrl+Y).
  • Find & Replace: Ctrl+H.

Formatting

  • Character – font, size, bold (Ctrl+B), italic (Ctrl+I), underline (Ctrl+U), color.
  • Paragraph – alignment (left, center, right, justify), indentation, bullets, numbering.
  • Page Layout – margins, orientation (portrait/landscape), size.

Tables & Charts

  • Insert Table – Insert → Table, choose rows/columns.
  • Insert Chart – Insert → Chart, edit data in spreadsheet.

Mail Merge

Mailings → Start Mail Merge → Step by Step Wizard – create letters with variable data from Excel.

Spelling & Grammar

Review → Spelling & Grammar (F7). Red underline = spelling error, blue = grammar, green = contextual.

Graphics

  • Clip Art – Insert → Clip Art.
  • Pictures – Insert → Picture from file.
  • WordArt – Insert → WordArt.
  • Watermark – Page Layout → Watermark.

📌 Important Questions – Chapter 3

Q1. How to turn on/off automatic spelling check?

Review → Spelling & Grammar → Options → Proofing → check/uncheck "Check spelling as you type".

Q2. Steps to add watermark in Word?

Page Layout → Watermark → choose or custom.

Q3. Five features of word processor.

Editing, Word Wrap, Search & Replace, Copy/Cut, Headers/Footers.

Chapter 4

Spreadsheet

Spreadsheet स्प्रेडशीट – application for organizing, analyzing data in tabular form. Microsoft Excel is the most widely used.

Excel Basics

  • Workbook – file with multiple worksheets.
  • Worksheet – grid of rows (1–1,048,576) and columns (A–XFD).
  • Cell – intersection of row and column; referenced by column letter and row number (e.g., A1).
  • Formula Bar – shows/edit cell content; starts with '='.

Entering Data & Operators

  • Enter data by typing in active cell.
  • Arithmetic Operators – +, -, *, /, %.
  • Comparison Operators – =, <, >, <=, >=, <>.
  • Text Operator – & for concatenation.
  • Reference Operators – : (range), , (union).

Functions

  • Math – SUM, AVERAGE, MAX, MIN.
  • Logical – IF, AND, OR, NOT.
  • Statistical – COUNT, COUNTA, STDEV.
  • Text – LEFT, RIGHT, MID, CONCATENATE.
  • Date/Time – DATE, DAY, MONTH, YEAR.

Formatting Worksheet

  • Alignment – left, center, right, top, middle, bottom; merge & center; wrap text.
  • Number Formats – Currency, Accounting, Date, Percentage.
  • Font – type, size, style, color.

Charts

Select data → Insert → Chart (choose type). Modify via Chart Tools – Design, Layout, Format.

Printing

File → Print (Ctrl+P) – set active sheets, entire workbook, selection; adjust margins, orientation, scaling.

Import Data

  • From Text: Data → From Text → import wizard.
  • From Web: Data → From Web → enter URL → select table.

📌 Important Questions – Chapter 4

Q1. Explain elements of spreadsheet.

Workbook, Worksheet, Row, Column, Cell, Formula, Functions.

Q2. Cell referencing types.

Absolute ($A$1), Relative (A1), Mixed ($A1 or A$1).

Q3. What is Array Formula?

Formula that performs multiple calculations on one or more items.

Chapter 5

Presentation

Microsoft PowerPoint पॉवरपॉइंट – slide show presentation program. Create professional slides with text, graphics, media.

Opening & Creating

  • Start → All Programs → Microsoft Office → PowerPoint.
  • New blank presentation or use templates.

Views

  • Normal View – edit slides.
  • Slide Sorter – rearrange slides.
  • Notes Page – add speaker notes.
  • Reading View – preview presentation.

Working with Slides

  • Add new slide: Home → New Slide (Ctrl+M).
  • Rearrange: drag in Slide Sorter or Normal.
  • Delete: select and press Delete.

Text & Formatting

  • Add text: click placeholder or Insert → Text Box.
  • Format: Home tab – font, size, color, bold, italic, underline.
  • Paragraph: alignment, bullets, numbering, indent, line spacing.
  • WordArt for stylized text.

Objects & Graphics

  • Insert Table, Excel Spreadsheet, Formula (Equation).
  • Insert Clip Art, Pictures.
  • Shapes: Insert → Shapes, format via Drawing Tools.

Slide Show & Transition

  • Run show: F5 (from beginning), Shift+F5 (from current).
  • Transitions: Transitions tab → choose effect, set timing.
  • Animations: Animate objects.

Printing

File → Print – choose slides, handouts, notes; select layout.

📌 Important Questions – Chapter 5

Q1. What is Handout Master?

Handout is printout of slides (1–9 per page) for audience.

Q2. Advantages of presentation package?

Standard, attractive features, easy to use, export to multiple formats.

Q3. How to add movies/sounds in Impress?

Insert → Audio or Video → select file.

Chapter 6

Introduction to Internet and WWW

Internet इंटरनेट – global network of networks. Uses TCP/IP protocol. Started as ARPANET (1969). Vint Cerf is Father of Internet.

Computer Networks

  • LAN – local area, up to 1 km, high speed.
  • MAN – metropolitan area, city-wide.
  • WAN – wide area, countries/continents, Internet.

Network Topologies

  • Bus, Ring, Star, Mesh, Tree.

Networking Devices

  • Repeater, Hub, Switch, Bridge, Router, Gateway, NIC, Modem.

Internet Protocols

  • TCP/IP, HTTP/HTTPS, FTP, POP3, SMTP, Ethernet, UDP, PPP, Telnet.

IP Address

  • IPv4 – 32-bit (e.g., 172.16.254.1).
  • IPv6 – 128-bit (e.g., 2001:0db8:...).

ISP

Internet Service Provider – Tier1, Tier2, Tier3. Provides internet connection, email, hosting, security.

WWW, URL, Domain Names

  • WWW – World Wide Web (Tim Berners-Lee, 1989).
  • URL – Uniform Resource Locator.
  • Domain extensions: .com, .edu, .gov, .net, .org.

Web Browsers

  • Internet Explorer, Edge, Chrome, Firefox, Opera.

Search Engines

  • Google, Bing, Yahoo, Ask, Baidu, Yandex, DuckDuckGo.

📌 Important Questions – Chapter 6

Q1. What is ISP? How many parts?

ISP – Internet Service Provider. Divided into Tier1, Tier2, Tier3.

Q2. Define network topology.

Shape/layout of network. Types: Bus, Ring, Star, Mesh, Tree.

Q3. Difference between LAN and WAN?

LAN – local, private, high speed. WAN – wide, public, slower.

E-mail, Social Networking & e-Governance

E-mail ईमेल – electronic mail. First e-mail by Ray Tomlinson (1971). Address format: username@domain.

E-mail Components

  • To, CC, BCC, Subject, Body, Attachments, Signature.
  • Protocols: SMTP (send), POP3/IMAP (receive).

Social Networking

  • Platforms: Facebook, Twitter, LinkedIn, Instagram, WhatsApp.
  • Instant Messaging: WhatsApp, Messenger, Telegram.

E-Commerce

  • Buying/selling goods/services online.
  • Models: B2B, B2C, C2B, C2C, B2A, C2A.

e-Governance

  • Government services online – IRCTC, Passport, eHospital (ORS).
  • UMANG App – unified mobile app for governance.
  • DigiLocker – cloud storage for certificates.

Netiquette

Internet etiquette – respectful online behaviour, no spam, no abusive language, respect privacy.

📌 Important Questions – Chapter 7

Q1. What is Social Networking? Examples.

Connecting people via internet. Examples: Facebook, Instagram, LinkedIn, Twitter.

Q2. What is Netiquette?

Internet etiquette – respectful online communication.

B2B, B2C, C2C, C2B, B2A, C2A.

Chapter 8

Information Technology and Society – Cyber Law & IPR

Information Technology (IT) सूचना प्रौद्योगिकी – use of computers to store, retrieve, transmit, manipulate data. IT has revolutionized banking, finance, communication, education.

Advantages of IT

  • Cheaper, faster communication.
  • Global connectivity.
  • 24×7 online business.
  • Cost-effective processes.

Disadvantages of IT

  • Privacy issues.
  • Hacking, data theft.
  • Misuse of personal information.

Need for Cyber Law

With growth of IT, cyber crimes have increased – hacking, identity theft, phishing. Cyber laws regulate activities in cyberspace.

Indian IT Act 2000

Passed on 17 Oct 2000, 94 sections, 13 chapters. Legal recognition of electronic documents and digital signatures. Penalties for cyber crimes.

SectionOffensePunishment
43Unauthorized access, copying data, introducing virusCompensation up to ₹1 Crore
65Tampering with source codeImprisonment 3 years, fine ₹2 Lakh
66Hacking, altering dataImprisonment 3 years, fine ₹5 Lakh
66ASending offensive messagesImprisonment 3 years, fine
67Publishing obscene materialImprisonment 5 years, fine ₹10 Lakh

Intellectual Property Rights (IPR)

  • Patent – exclusive right to invention.
  • Copyright – protection for literary/artistic works.
  • Trademark – distinctive sign for goods/services.
  • Trade Secret – confidential business information.
  • Registered Design – visual design of objects.
  • Plant Varieties – rights for new plant breeds.

Applications of IT in Banking

  • Core Banking Solutions (CBS).
  • ATMs, Net Banking, Mobile Banking.
  • Electronic Clearing Service (ECS).
  • RTGS, NEFT, IMPS.
  • Prepaid Payment Systems (e-wallets).

📌 Important Questions – Chapter 8

Q1. What is IT Act 2000?

Indian law to regulate e-commerce, e-governance, and cyber crimes. Provides legal recognition to digital signatures and documents.

Q2. Types of Intellectual Property Rights.

Patents, Copyrights, Trademarks, Trade Secrets, Registered Designs, Plant Varieties.

Q3. Role of IT in banking.

CBS, ATMs, ECS, RTGS, NEFT, IMPS, internet/mobile banking.

Chapter 9

Overview of Futureskills and Cyber Security

Futureskills – platform by NASSCOM for IT professionals to upgrade skills in emerging technologies (IoT, AI, Robotics, etc.). Launched 19 Feb 2018.

Internet of Things (IoT)

Physical objects connected via sensors and software. Examples: smart watch, smart TV. Advantages: easy tracking, home automation, remote access. Disadvantages: security, privacy, complexity.

Big Data Analytics

Large volume of data – structured, unstructured, semi-structured. Analyzing to find patterns and useful information.

Cloud Computing

Delivery of services (storage, servers, database, networking, software) over internet. Types: Public, Private, Hybrid. Services: IaaS, PaaS, SaaS. Advantages: cost, speed, scalability, security, reliability.

Virtual Reality (VR)

Computer-generated simulation of 3D environment. Used in gaming, education, engineering, medical.

Artificial Intelligence (AI)

Machines programmed to think and act like humans. Languages: LISP, Python, Java, Prolog. Applications: gaming, NLP, vision systems, expert systems, speech recognition, robotics.

Blockchain Technology

Distributed database for secure transactions. Backbone of Bitcoin. Uses digital signatures for security.

3D Printing (Additive Manufacturing)

Creates 3D objects layer by layer. Advantages: fast production, cost-effective, low waste. Applications: aerospace, education, biomedical, robotics.

Robotics Process Automation (RPA)

Software robots that automate tasks. Advantages: increased accuracy, speed, cost savings, productivity.

Cyber Security

Protection of systems, networks, data from cyber attacks. Goals: privacy, integrity, availability. Types of attacks: system-based (virus, worm, Trojan) and web-based (phishing, DNS spoofing, DoS, MiTM, brute force).

Securing PC & Smartphone

  • Keep OS/software updated.
  • Use licensed software.
  • Be careful online; avoid suspicious links.
  • Backup regularly.
  • Use strong passwords.
  • Install antivirus, enable firewall.
  • For smartphone: strong password, trusted apps, regular updates, backup, remote wipe, Wi-Fi security, understand app permissions.

📌 Important Questions – Chapter 9

Q1. Advantages of Cloud Computing.

Cost, speed, scalability, security, reliability.

Q2. What is AI? Applications.

AI – machines with human-like intelligence. Applications: gaming, NLP, vision, expert systems, speech recognition, robotics.

Q3. What is Blockchain?

Distributed database for secure transactions; backbone of Bitcoin.
