Objective: Understand document creation and file saving.

STEPS / प्रक्रिया
  1. Open MS Word.
  2. Select Blank Document.
  3. Type a sample paragraph.
  4. Click File → Save As.
  5. Give a suitable file name.
  6. Select the required folder and save.
EXPECTED OUTPUT / परिणाम

Top Practical Exam Tricks

Small mistakes से बचने के लिए

01 — SAVE FIRST

Practical शुरू करते ही file को proper name से save कर दो.

02 — READ THE TASK

Question में दिए गए exact rows, columns, formatting और file name को carefully follow करो.

03 — OUTPUT VERIFY

Task complete होने के बाद output को एक बार जरूर check करो.

04 — FORMULA CHECK

Excel में formula लिखने के बाद result और cell references दोनों verify करो.

05 — FILE FORMAT

Question में DOCX, XLSX, PPTX या PDF मांगा गया हो तो correct format में save करो.

06 — DON'T PANIC

अगर कोई option तुरंत नहीं मिले तो relevant Ribbon tab और search/help facility का उपयोग करके calmly locate करो.
