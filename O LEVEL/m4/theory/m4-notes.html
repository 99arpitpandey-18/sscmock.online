Chapter 1

Introduction to Internet of Things

Internet of Things (IoT) इंटरनेट ऑफ थिंग्स is a concept in which physical objects/devices are connected to networks so that they can collect, exchange and process data.

IoT क्या है? / What is IoT?

IoT means connecting physical and virtual things with sensors, software and communication technologies so that they can exchange information. सरल भाषा में, IoT का मतलब है — ऐसी चीजों को Internet/network से connect करना जो data collect और exchange कर सकें.

Examples of IoT

  • Smart home devices.
  • Smart watches and fitness devices.
  • Smart agriculture systems.
  • Industrial monitoring systems.
  • Smart energy meters.
  • Environmental monitoring systems.
  • Connected vehicles.

Why IoT is Important?

  • Real-time data collection.
  • Remote monitoring.
  • Automation.
  • Better resource management.
  • Data-driven decision making.
  • Improved efficiency.
Exam Point: IoT combines physical objects, sensors, connectivity, software and data processing to create connected systems.

Chapter 2

IoT Characteristics & Building Blocks

Characteristics of IoT

  • Connectivity — devices communicate with each other/network.
  • Sensing — sensors collect information from the environment.
  • Intelligence — data can be processed to make useful decisions.
  • Heterogeneity — different types of devices and technologies can work together.
  • Dynamic nature — device state and environment may change continuously.
  • Scalability — IoT systems can contain a very large number of devices.
  • Security — connected devices and data need protection.

Building Blocks of IoT

Building Block Purpose
Things / Devices Physical objects that participate in the IoT system.
Sensors Measure physical conditions such as temperature, light or moisture.
Connectivity Provides communication between devices and systems.
Data Processing Processes collected information.
Applications Provide useful services and interfaces to users.
Security Protects devices, communication and data.
Remember: Basic IoT flow can be understood as: Sense → Connect → Process → Act यानि sensor data collect करता है, network data भेजता है, processing होती है और system action ले सकता है।

IoT Ecosystem

An IoT ecosystem may include devices, sensors, gateways, communication networks, processing systems, cloud/services and users.

Physical & Logical Design of IoT

Physical Design

Physical design describes the actual entities involved in an IoT system, such as devices, sensors, actuators, communication interfaces and gateways.

Logical Design

Logical design describes the logical representation of IoT entities, services, data flow and communication.

IoT Devices

  • Sensor devices.
  • Actuator devices.
  • Microcontroller-based devices.
  • Gateway devices.
  • Connected smart appliances.

Physical vs Logical Design

Physical Design Logical Design
Deals with actual hardware/devices. Deals with logical behavior and services.
Sensors, actuators, boards and networks. Data flow, services and communication logic.
Hardware-oriented view. Architecture-oriented view.
Remember: Physical Design = What hardware exists? Logical Design = How does the IoT system logically work?

Chapter 7

TCP/IP, OSI & IoT Connectivity

OSI Model

OSI stands for Open Systems Interconnection. It provides a conceptual seven-layer model for network communication.

Layer Name General Function
7 Application Network services for applications.
6 Presentation Data representation and transformation.
5 Session Session establishment and management.
4 Transport End-to-end transport.
3 Network Logical addressing and routing.
2 Data Link Frame-level communication.
1 Physical Transmission of bits/signals.

TCP/IP Model

Layer General Role
Application Application-level network services.
Transport Process-to-process communication.
Internet IP addressing and routing.
Network Access Link/physical network communication.

OSI vs TCP/IP

OSI TCP/IP
7-layer reference model. Practical Internet protocol architecture.
Separates Presentation and Session layers. These functions are generally handled within Application layer.
Reference/conceptual model. Protocol suite/model used for Internet communication.
Quick Trick: OSI = 7 Layers TCP/IP = commonly represented using 4 layers.

A sensor is a device that detects or measures a physical quantity and provides a corresponding signal.

Common Physical Quantities

  • Temperature.
  • Light intensity.
  • Humidity.
  • Moisture.
  • Gas concentration.
  • Motion.
  • Distance.

Common IoT Sensors

Sensor Measures / Detects

DHT Sensor Temperature and humidity, depending on model.
Moisture Sensor Moisture level in a material such as soil.
MQ135 Gas/air-quality related sensing.
IR Sensor Infrared-based detection.

Analog vs Digital Sensor Output

An analog output can represent a continuous range of values, while a digital output generally represents discrete logic states.

Remember: Sensor = input device. It senses a physical quantity and provides information that a controller can process.

Chapter 15

Digital & Analog Pins

Digital Pins

Digital pins work with discrete logic states. They are commonly used for digital input and output.

Analog Input

Analog input allows a microcontroller to read a value representing a varying physical signal.

Common Arduino Functions 

pinMode(pin, mode);

digitalWrite(pin, value);

digitalRead(pin);

analogRead(pin);

analogWrite(pin, value);
Function Purpose
pinMode() Configures a pin mode.
digitalWrite() Writes a digital output state.
digitalRead() Reads a digital input state.
analogRead() Reads an analog input value.
analogWrite() Produces a PWM output on supported pins.

LED Example 

const int LED_PIN = 13;

void setup() {

    pinMode(LED_PIN, OUTPUT);

}

void loop() {

    digitalWrite(LED_PIN, HIGH);

    delay(1000);

    digitalWrite(LED_PIN, LOW);

    delay(1000);

}
Practical Point: LED ON/OFF programs are among the basic exercises for understanding Arduino digital output.

Chapter 16

Sensor Interfacing

What is Interfacing?

Interfacing means connecting an external device such as a sensor or actuator to a microcontroller so that the microcontroller can read or control it.

LED Interfacing 

const int LED = 13;

void setup() {

    pinMode(LED, OUTPUT);

}

void loop() {

    digitalWrite(LED, HIGH);

    delay(500);

    digitalWrite(LED, LOW);

    delay(500);

}

Button Interfacing — Basic Logic 

int buttonPin = 2;

int ledPin = 13;

void setup() {

    pinMode(buttonPin, INPUT);

    pinMode(ledPin, OUTPUT);

}

void loop() {

    int state = digitalRead(buttonPin);

    if (state == HIGH) {

        digitalWrite(ledPin, HIGH);

    }
    else {

        digitalWrite(ledPin, LOW);

    }

}

Chapter 17

LCD, Keypad & Serial Communication

LCD

LCD stands for Liquid Crystal Display. It can be used to display sensor readings, messages and system status.

Typical LCD Uses

  • Display temperature.
  • Display humidity.
  • Display sensor values.
  • Display menu/status information.
  • Display user messages.

Keypad

A keypad provides a way for the user to enter numbers, characters or commands into an embedded system.

Serial Communication

Serial communication sends data sequentially between devices. Arduino provides serial communication facilities that can be used to communicate with a PC or other modules. 

void setup() {

    Serial.begin(9600);

}

void loop() {

    Serial.println("IoT System");

    delay(1000);

}

Serial Monitor

The Serial Monitor can display serial data sent by the Arduino and is useful for debugging and observing values.

Concept Purpose
Serial.begin() Initializes serial communication.
Serial.print() Sends data without automatically adding a new line.
Serial.println() Sends data followed by a new line.
Serial Monitor Displays serial communication data.
Exam Point: Serial communication is important for communication between a microcontroller and PC/module and for debugging.

Chapter 18

Bluetooth & Relay Applications

Bluetooth Module

Bluetooth is a short-range wireless communication technology. Modules such as HC-05 can be used in embedded projects for serial-style wireless communication.

Basic Bluetooth Concept 

Mobile / Bluetooth Device
          ↓
      Bluetooth
          ↓
     HC-05 Module
          ↓
     Microcontroller
          ↓
       Output

Applications

  • Wireless control.
  • Sending commands to a controller.
  • Receiving simple sensor/system data.

Relay Module

A relay is an electrically controlled switching device. In IoT/embedded applications, relay modules can allow a low-voltage controller to control an appropriately designed electrical circuit.

Safety Note: Mains electricity such as 220V AC is hazardous. Do not experiment with mains wiring without qualified supervision and appropriate safety equipment. For learning, use low-voltage demonstration circuits where possible.

Relay Concept 

Microcontroller
       ↓
   Relay Module
       ↓
Controlled Electrical Load
Remember: Bluetooth → wireless communication Relay → electrically controlled switching

Chapter 19

IoT Security & Privacy

Why IoT Security is Important?

IoT devices are connected to networks and may collect sensitive information. Weak security can expose devices, data and services to unauthorized access.

Major IoT Security Concerns

  • Unauthorized access.
  • Weak or default passwords.
  • Unsecured communication.
  • Insecure software or firmware.
  • Data privacy problems.
  • Device tampering.
  • Lack of updates.

IoT Privacy

Privacy means protecting information collected by IoT devices and ensuring that data is used appropriately.

Security Measures

Measure Purpose
Strong Authentication Helps prevent unauthorized access.
Encryption Protects data during storage or transmission when properly implemented.
Secure Updates Helps fix vulnerabilities.
Access Control Restricts who can access devices and services.
Network Security Helps protect connected devices and communication.
Privacy Controls Reduce unnecessary collection and exposure of personal data.

Security Levels

  • Device security.
  • Network security.
  • Application security.
  • Data security.
  • User/access security.
Exam Point: IoT security is not limited to the device. It should consider the complete ecosystem: device + network + application + data + user.

📌 Important Questions — Chapter 19

Q1. Why is security important in IoT?

Because connected devices and the data they handle can be exposed to unauthorized access and other threats.

Q2. What is IoT privacy?

Protection and appropriate handling of information collected by IoT devices.

Q3. Name two IoT security measures.

Strong authentication and secure communication/encryption.
