1. Controlled Systems

Control system को आसान भाषा में समझें

What is a Controlled System?

ENGLISH

A controlled system is a system in which the operation or behaviour of a device/process is monitored and controlled according to a desired condition or input.

हिंदी

Controlled System वह system है जिसमें किसी device या process के operation को किसी desired condition के अनुसार monitor और control किया जाता है।

💡 Example 1 — Air Conditioner (AC)

Suppose the required temperature is 24°C. The temperature sensor measures the room temperature. If temperature increases above the desired value, the controller can command the AC to cool the room.

Hindi: अगर room का temperature set temperature से ज्यादा हो जाता है, तो sensor information controller तक भेजता है और system cooling action लेता है।

💡 Example 2 — Refrigerator

A refrigerator continuously monitors temperature and controls the cooling mechanism to maintain a desired temperature range.

Basic Components

📡

Sensor

Measures physical condition.

🧠

Controller

Processes the information.

⚡

Actuator

Performs required action.

🎯

Target

Desired condition.

2. Feedback Loop

M4 exam का बहुत important concept

What is Feedback?

ENGLISH

Feedback is the process of returning information about the current condition of a system to the controller so that corrective action can be taken.

हिंदी

Feedback वह process है जिसमें system की current condition की information वापस controller को दी जाती है ताकि जरूरत पड़ने पर corrective action लिया जा सके।

Feedback Loop

A feedback loop continuously measures the output and uses that information to control or adjust the system.

1

Measure

Sensor measures condition.

2

Compare

Compare with desired value.

3

Decide

Controller decides action.

4

Act

Actuator performs action.

5

Repeat

System measures again.

🌡️ Thermostat Example

Set temperature = 24°C

Room temperature = 28°C → Sensor detects 28°C → Controller compares 28 with 24 → Cooling is required → AC starts cooling → Temperature decreases → Sensor measures again.

⭐ EXAM TRICK

Remember the sequence: Sensor → Controller → Actuator → System → Sensor यह feedback system को समझने के लिए सबसे useful sequence है।

3. TCP/IP Model

Internet communication का fundamental model

TCP/IP

ENGLISH

TCP/IP is a communication protocol suite used for communication between devices over networks and the Internet.

हिंदी

TCP/IP protocols का एक suite है जो network और Internet पर devices के बीच communication के लिए उपयोग किया जाता है।

TCP/IP Layers

1. Application Layer

Provides network services to applications. Examples include HTTP, HTTPS, FTP, DNS, SMTP.

2. Transport Layer

Provides end-to-end communication. Important protocols: TCP and UDP.

3. Internet Layer

Responsible for logical addressing and packet routing. Important protocol: IP.

4. Network Access Layer

Handles communication with the physical/network interface.

🧱

4. OSI Model

Seven-layer reference model

OSI Model — Open Systems Interconnection

ENGLISH

OSI is a seven-layer reference model developed to understand how communication takes place between networked systems.

हिंदी

OSI एक seven-layer reference model है जो network devices के बीच communication को समझने के लिए उपयोग किया जाता है।

7 OSI Layers — Top to Bottom

Layer Name Easy Meaning
7 Application User/application network services
6 Presentation Translation, encryption, compression
5 Session Establish/manage communication session
4 Transport End-to-end delivery
3 Network Routing and logical addressing
2 Data Link Frames and MAC addressing
1 Physical Bits and physical transmission
🧠 MEMORY TRICK

Top → Bottom: All People Seem To Need Data Processing Application → Presentation → Session → Transport → Network → Data Link → Physical

5. TCP/IP vs OSI

Exam में comparison question के लिए important

Feature TCP/IP OSI
Layers 4 layers 7 layers
Nature Protocol suite/model Reference model
Development Developed around Internet protocols Developed as a standard reference framework
Application Widely used in Internet networking Mainly used for understanding/reference
Transport TCP / UDP Transport layer
Internet/Network Internet layer Network layer
🎯 EXAM POINT

अगर question आए: "Which model has seven layers?" Answer: OSI Model अगर पूछा जाए: "Which model is strongly associated with Internet protocol suite?" Answer: TCP/IP

10. Process Flow of an IoT Application

IoT application में data कैसे travel करता है?

Typical IoT Data Flow

An IoT application generally collects data from the physical world, processes/transmits that data and may generate an action or useful output.

1

Thing

Physical object produces information.

2

Sensor

Measures physical quantity.

3

Network

Transfers data.

4

Processing

Data is analyzed.

5

Action

Decision/output is generated.

🏠 Smart Home Example

Temperature Sensor → Controller → Wi-Fi → Processing/Application → Decision → AC Control

Hindi: Temperature sensor room की information collect करता है → controller उसे process करता है → network के माध्यम से data जाता है → application/logic decision लेता है → required action होता है।
