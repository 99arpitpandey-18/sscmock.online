Introduction to Internet of Things

IoT Fundamentals • Concepts • Architecture • Applications

What is IoT?

The Internet of Things (IoT) is a system in which physical objects or "things" are connected to the Internet and are able to collect, exchange and sometimes process data.

Internet of Things (IoT) एक ऐसा system है जिसमें physical objects या "things" Internet से connected होते हैं और data को collect, exchange तथा process कर सकते हैं।

🔎 Example 1 — Smart Home

A smart bulb can receive commands through a network and can be controlled using a smartphone.

Smart bulb network के माध्यम से command receive करके smartphone से control किया जा सकता है।

🔎 Example 2 — Smart Agriculture

A soil-moisture sensor can measure soil conditions and send the information to an IoT system.

Soil-moisture sensor मिट्टी की स्थिति को measure करके IoT system को information भेज सकता है।

  • Real-world interaction

IoT Components

  • Things / Devices

Things and Connections

Devices • Communication • Networks • Protocols

What are "Things" in IoT?

A "thing" is a physical or virtual entity that can be identified and can participate in communication or data exchange.

IoT में "Thing" कोई physical या virtual entity हो सकती है जिसे identify किया जा सकता है और जो communication या data exchange में participate कर सकती है।

Smart Watch Smart Bulb Car Sensor Machine Camera Smart Meter

Wired Connections

  • Ethernet
  • USB
  • Serial communication
  • Industrial wired networks

Wired communication में devices physical cable के माध्यम से connected होते हैं।

Wireless Connections

  • Wi-Fi
  • Bluetooth
  • Bluetooth Low Energy
  • Zigbee
  • Cellular
  • LPWAN technologies

Wireless communication में devices radio/wireless medium के माध्यम से data exchange करते हैं।

Common IoT Protocols

MQTT

MQTT is a lightweight messaging protocol widely used for machine-to-machine and IoT communication.

MQTT एक lightweight messaging protocol है जिसका उपयोग IoT devices के बीच messages exchange करने के लिए किया जाता है।

HTTP / HTTPS

HTTP/HTTPS can be used for communication between IoT applications, web services and servers.

HTTP/HTTPS IoT application और server/web service के बीच communication में उपयोग हो सकता है।

🎯 EXAM FOCUS
  • Wi-Fi → common local wireless networking.
  • Bluetooth → short-range communication.
  • BLE → low-power short-range applications.
  • MQTT → lightweight IoT messaging.
  • HTTPS → HTTP communication with encryption through TLS.

Sensors, Actuators, Microcontrollers & Arduino

Input • Processing • Output • Programming

Sensor क्या है?

A sensor detects or measures a physical quantity and converts it into a signal that a system can process.

Sensor किसी physical quantity जैसे temperature, light, distance, humidity या motion को detect/measure करके system के लिए usable signal provide करता है।

Sensor Measures / Detects Example
Temperature Sensor Temperature Room monitoring
LDR Light intensity Automatic light
Ultrasonic Sensor Distance Obstacle detection
Soil Moisture Sensor Soil moisture Smart irrigation
PIR Sensor Motion Security systems

Actuator क्या है?

An actuator converts a control signal into a physical action.

Actuator controller से मिले control signal को physical action में convert करता है।

Motor Relay LED Buzzer Servo Motor

Sensor vs Actuator

Sensor Actuator
Input device Output device
Measures physical condition Performs physical action
Environment → System System → Environment
Example: temperature sensor Example: motor

Microcontroller

A microcontroller is a compact integrated circuit designed to control electronic systems. It can read inputs, execute a program and control outputs.

Microcontroller एक compact IC है जो inputs को read करता है, program execute करता है और outputs को control करता है।

🔎 Example

Temperature sensor → Microcontroller → Fan

Temperature बढ़ता है → sensor reading देता है → controller decision लेता है → fan ON हो जाता है।

Arduino

Arduino is an open-source electronics platform consisting of hardware boards and a software development environment.

Arduino एक open-source electronics platform है जिसमें hardware boards और programming/software development environment शामिल होते हैं।

Arduino IDE — Basic Structure

void setup()
{
    // runs once
}

void loop()
{
    // runs repeatedly
}

setup() सामान्यतः initialization के लिए और loop() repeated operations के लिए use किया जाता है।

Example: LED Blinking

int ledPin = 13;

void setup()
{
    pinMode(ledPin, OUTPUT);
}

void loop()
{
    digitalWrite(ledPin, HIGH);
    delay(1000);

    digitalWrite(ledPin, LOW);
    delay(1000);
}
Remember:
pinMode() → pin configuration
digitalWrite() → digital output control
delay() → pause for specified milliseconds

Example: Reading a Sensor

int sensorPin = A0;
int value;

void setup()
{
    Serial.begin(9600);
}

void loop()
{
    value = analogRead(sensorPin);

    Serial.println(value);

    delay(500);
}

यह example analog input को read करके Serial Monitor पर value display करता है।

🎯 EXAM FOCUS
  • Sensor = input / measurement.
  • Actuator = action / output.
  • Microcontroller = processing and control.
  • Arduino IDE = Arduino programs develop/upload करने का environment.
  • setup() normally runs once.
  • loop() repeatedly runs.

Security and Future of IoT Ecosystem

Threats • Protection • Privacy • Future Trends

Why IoT Security is Important?

IoT devices interact with the physical world and often collect valuable data. Weak security can affect confidentiality, integrity, availability and privacy.

IoT devices physical world के साथ interact करते हैं और important data collect कर सकते हैं। Weak security से data privacy और system security प्रभावित हो सकती है।

Common IoT Security Risks

  • Weak passwords
  • Unpatched software
  • Insecure communication
  • Unauthorized access
  • Data leakage
  • Malware
  • Insecure device configuration
  • Privacy problems

IoT Security Measures

Security Measure Purpose
Strong authentication Reduce unauthorized access
Encryption Protect data confidentiality
Secure updates Fix known vulnerabilities
Access control Limit permissions
Network security Reduce network-based threats
Monitoring Detect unusual activity

CIA Triad

Confidentiality Only authorized parties should access information.
Integrity Data should remain accurate and protected from unauthorized modification.
Availability Authorized users should be able to access the service when required.

Privacy in IoT

IoT devices may collect information about homes, locations, activities and environments. Therefore, responsible data collection, access control, secure storage and appropriate data handling are important.

IoT devices homes, locations और activities से related data collect कर सकते हैं। इसलिए responsible data collection और secure data handling जरूरी है।

Future of IoT

AI + IoT Edge Computing Smart Cities Industrial IoT Connected Vehicles Smart Agriculture Digital Twins Advanced Connectivity
🚀 AI + IoT Example

IoT sensors collect machine data. Analytics or AI can help identify patterns and support maintenance decisions.

IoT sensors machine का data collect करते हैं और analytics/AI patterns identify करके maintenance decisions में सहायता कर सकता है।

🎯 EXAM FOCUS
  • Authentication verifies identity.
  • Authorization controls permissions.
  • Encryption protects information.
  • Confidentiality = prevent unauthorized disclosure.
  • Integrity = protect correctness of data.
  • Availability = service/data accessible when needed.
  • Security must be considered throughout the IoT lifecycle.
