1. What is Arduino?

Arduino का basic concept

Arduino – Introduction

English: Arduino is an open-source electronics platform based on easy-to-use hardware and software. It is widely used for learning electronics, automation, embedded systems, robotics and IoT applications.

हिन्दी: Arduino एक open-source electronics platform है जिसमें hardware और software दोनों का उपयोग करके electronic projects बनाए जाते हैं। यह electronics, automation, robotics, embedded systems और IoT में बहुत उपयोगी है।

Exam Point:
Arduino = Hardware Board + Programming Environment (IDE)

Arduino Board के मुख्य भाग

  • Microcontroller – program को execute करता है।
  • Digital Pins – digital input/output के लिए।
  • Analog Input Pins – analog values पढ़ने के लिए।
  • USB Port – computer से connection और programming के लिए।
  • Power Jack – external power supply के लिए।
  • Reset Button – program को restart करने के लिए।
  • Power LED – board को power मिलने का indication।
  • TX/RX LEDs – serial communication indication।
💻

2. Arduino IDE

Programming environment को समझें

Arduino IDE क्या है?

English: Arduino IDE stands for Arduino Integrated Development Environment. It is software used to write, compile/verify and upload Arduino programs to the Arduino board.

हिन्दी: Arduino IDE का पूरा नाम Arduino Integrated Development Environment है। इसका उपयोग program लिखने, verify/compile करने और Arduino board में program upload करने के लिए किया जाता है।

Basic IDE Workflow

Write Code → Verify/Compile → Select Board & Port → Upload → Run

Important IDE Components

  • Editor – code लिखने के लिए।
  • Verify – code में compilation errors check करता है।
  • Upload – compiled program board में भेजता है।
  • Serial Monitor – serial data देखने/भेजने के लिए।
  • Board Selection – target Arduino board select करने के लिए।
  • Port Selection – connected board का communication port select करने के लिए।
📝

3. Arduino Sketch

Arduino program की structure

Basic Sketch Structure

English: An Arduino program is commonly called a Sketch. Every basic Arduino sketch contains two important functions: setup() and loop().

हिन्दी: Arduino program को सामान्यतः Sketch कहा जाता है। एक basic Arduino sketch में दो सबसे महत्वपूर्ण functions होते हैं: setup() और loop()।

void setup() { // Runs once } void loop() { // Runs repeatedly }

setup()

English: Runs once when the board starts or resets.

हिन्दी: Board start या reset होने पर सामान्यतः एक बार चलता है।

loop()

English: Runs repeatedly after setup().

हिन्दी: setup() के बाद बार-बार execute होता रहता है।

Remember: setup() = One-time initialization
loop() = Repeated execution

4. Arduino Programming Basics

Variables, data types और operators

Variables

English: A variable stores a value that can be used by a program.
हिन्दी: Variable memory में किसी value को store करने के लिए उपयोग होता है।

int age = 20; float temperature = 25.5; char grade = 'A'; bool status = true;

Common Data Types

Data Type Use / उपयोग Example
int Integer numbers / पूर्णांक int x = 10;
float Decimal values / दशमलव float t = 25.5;
char Single character / एक character char c = 'A';
boolean / bool True or false bool x = true;
String Text / text data String name="Arduino";

Operators

  • Arithmetic: +, -, *, /, %
  • Comparison: ==, !=, >, <, >=, <=
  • Logical: &&, ||, !
  • Assignment: =, +=, -=, *=, /=

5. Digital Input & Output

LED, switch और digital pins

pinMode()

English: Sets a pin as INPUT, OUTPUT or another supported mode.
हिन्दी: यह निर्धारित करता है कि pin input के रूप में काम करेगी या output के रूप में।

pinMode(13, OUTPUT); pinMode(2, INPUT);

digitalWrite()

Digital output pin को HIGH या LOW state देने के लिए।

digitalWrite(13, HIGH); digitalWrite(13, LOW);

digitalRead()

Digital input pin की state पढ़ने के लिए।

int state = digitalRead(2);
Exam Trick:
pinMode() → Pin का mode set
digitalWrite() → Digital output देना
digitalRead() → Digital input पढ़ना
📊

6. Analog Input & PWM Output

Analog values और PWM concept

analogRead()

English: Used to read an analog value from an analog input pin.

हिन्दी: Analog sensor/input से value पढ़ने के लिए analogRead() का उपयोग किया जाता है।

int sensorValue = analogRead(A0);

analogWrite()

Arduino boards that support PWM can use analogWrite() to generate a PWM output on suitable pins.

analogWrite(9, 128);
Important: analogWrite() का value range commonly 0–255 होता है on classic Arduino PWM APIs, जहाँ 0 लगभग 0% duty cycle और 255 लगभग 100% duty cycle को represent करता है।
⏱️

7. Delay Function

Timing control

delay()

English: delay() pauses the program for a specified number of milliseconds.
हिन्दी: delay() program execution को दिए गए milliseconds तक रोकता है।

delay(1000);

1000 milliseconds = approximately 1 second.

Example: LED ON → 1 second wait → LED OFF → 1 second wait
📡

8. Serial Communication

Serial Monitor को समझें

Serial.begin()

Serial communication शुरू करने के लिए।

void setup() { Serial.begin(9600); }

Serial.print() और Serial.println()

Serial.print("Temperature: "); Serial.println(25);

print() उसी line में output रखता है, जबकि println() output के बाद new line देता है।

Exam Point:
Serial.begin(9600) → Communication speed / baud rate set करता है।

9. Practical Programs

Exam और practical के लिए important examples

Program 1 – Blink LED

English: Turn an LED ON and OFF repeatedly.

हिन्दी: LED को बार-बार ON और OFF करना।

int led = 13; void setup() { pinMode(led, OUTPUT); } void loop() { digitalWrite(led, HIGH); delay(1000); digitalWrite(led, LOW); delay(1000); }

Program 2 – Push Button & LED

int button = 2; int led = 13; void setup() { pinMode(button, INPUT); pinMode(led, OUTPUT); } void loop() { int state = digitalRead(button); if(state == HIGH) { digitalWrite(led, HIGH); } else { digitalWrite(led, LOW); } }

Concept: Input → Read button → Condition → Control LED

Program 3 – Analog Sensor Reading

int sensor = A0; void setup() { Serial.begin(9600); } void loop() { int value = analogRead(sensor); Serial.println(value); delay(500); }

Sensor की reading Serial Monitor पर दिखाई जाएगी।

Program 4 – LED Brightness using PWM

int led = 9; void setup() { pinMode(led, OUTPUT); } void loop() { analogWrite(led, 50); delay(1000); analogWrite(led, 200); delay(1000); }

Program 5 – Serial Counter

int count = 0; void setup() { Serial.begin(9600); } void loop() { Serial.println(count); count++; delay(1000); }

11. Exam-Oriented Revision

Last-minute important points

🔥 Must Remember

  • Arduino is an open-source electronics platform.
  • Arduino program is commonly called a Sketch.
  • setup() normally executes once after startup/reset.
  • loop() executes repeatedly.
  • pinMode() configures a pin mode.
  • digitalWrite() controls digital output.
  • digitalRead() reads digital input.
  • analogRead() reads analog input.
  • analogWrite() provides PWM output on supported pins.
  • delay() uses milliseconds as its argument.
  • Serial.begin() initializes serial communication.
  • Serial Monitor is used to view serial data.
  • USB is commonly used for programming and communication with the board.
  • Reset button restarts the board program.
  • Verify checks/compiles the sketch; Upload transfers it to the board.
