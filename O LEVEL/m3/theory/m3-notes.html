Introduction to Python

Python पाइथन is a high-level, general-purpose programming language known for readable syntax and a large ecosystem of libraries.

Python क्यों सीखें? / Why Python?

  • Easy-to-read syntax.
  • Suitable for beginners.
  • Supports procedural, object-oriented and other programming styles.

Features of Python

Chapter 2

Problem Solving & Algorithms

Problem Solving means understanding a problem and developing a logical method to produce the desired result.

Basic Problem Solving Steps

  • Understand the problem.
  • Identify inputs and expected outputs.
  • Break the problem into smaller steps.
  • Design an algorithm.
  • Write pseudocode or draw a flowchart where useful.
  • Implement the solution.
  • Test and debug the program.

Algorithm

An algorithm is a finite sequence of well-defined steps for solving a problem.

Example Algorithm — Add Two Numbers 

Step 1: Start
Step 2: Read A
Step 3: Read B
Step 4: Calculate A + B
Step 5: Display result
Step 6: Stop

Flowchart

A flowchart represents an algorithm graphically using standard symbols.

Symbol / Concept Purpose
Oval Start / End
Rectangle Process
Diamond Decision / Condition
Parallelogram Input / Output
Remember: Algorithm = step-by-step solution. Flowchart = graphical representation of an algorithm. Pseudocode = structured description of program logic.

📌 Important Questions — Chapter 2

Q1. What is an algorithm?

A finite sequence of well-defined steps used to solve a problem.

Q2. Which flowchart symbol represents a decision?

Diamond.

Q3. What is pseudocode?

A structured, human-readable description of program logic.

File Handling

File handling allows a Python program to read from and write to files.

file = open(
    "data.txt",
    "r"
)

Common File Modes

Mode Purpose
r Read
w Write / overwrite
a Append
x Create and fail if file exists
b Binary mode modifier
t Text mode modifier

with Statement 

with open(
    "data.txt",
    "r"
) as file:

    data = file.read()

    print(data)

Writing a File 

with open(
    "data.txt",
    "w"
) as file:

    file.write("Hello Python")

Reading Lines 

with open(
    "data.txt",
    "r"
) as file:

    for line in file:

        print(line.strip())
Best Practice: Using with open(...) helps ensure the file is properly closed after the block.

Chapter 15

Exception Handling

An exception is an event that occurs during program execution and can disrupt normal flow if not handled.

try-except 

try:

    x = int(
        input("Enter number: ")
    )

    print(10 / x)

except ValueError:

    print("Invalid number")

except ZeroDivisionError:

    print("Cannot divide by zero")

finally 

try:

    print("Try block")

except Exception:

    print("Error")

finally:

    print("Always executed")

raise 

age = 15

if age < 18:

    raise ValueError(
        "Age must be 18 or above"
    )
Keyword Purpose
try Contains code that may raise an exception.
except Handles selected exceptions.
else Runs when no exception occurs.
finally Runs as part of cleanup regardless of exception outcome.
raise Explicitly raises an exception.

Chapter 16

Object Oriented Programming

Object-Oriented Programming (OOP) is a programming approach based on objects and classes.

Class

A class defines a structure/behavior from which objects can be created.

Object

An object is an instance of a class. 

class Student:

    def __init__(
        self,
        name,
        marks
    ):

        self.name = name

        self.marks = marks


    def show(self):

        print(
            self.name,
            self.marks
        )


s1 = Student(
    "Aman",
    85
)

s1.show()

Constructor

__init__() is commonly used as an initializer that runs when an object is created.

Important OOP Concepts

  • Class
  • Object
  • Encapsulation
  • Inheritance
  • Polymorphism
  • Abstraction

Inheritance Example 

class Animal:

    def speak(self):

        print("Animal sound")


class Dog(Animal):

    def bark(self):

        print("Dog barking")


d = Dog()

d.speak()

d.bark()
Remember: OOP commonly revolves around objects, classes and concepts such as inheritance, encapsulation, polymorphism and abstraction.

Practical Python Programs

1. Add Two Numbers 

a = float(
    input("Enter first number: ")
)

b = float(
    input("Enter second number: ")

2. Check Even or Odd 

n = int(
    input("Enter number: ")
)

if n % 2 == 0:

    print("Even")

else:

    print("Odd")

3. Find Largest of Three Numbers 

a = int(input("A: "))

b = int(input("B: "))

c = int(input("C: "))


largest = max(a, b, c)

print("Largest =", largest)

4. Factorial 

n = int(
    input("Enter number: ")
)

fact = 1

for i in range(
    1,
    n + 1
):

    fact *= i

print("Factorial =", fact)

5. Prime Number Check 

n = int(
    input("Enter number: ")
)

if n < 2:

    print("Not Prime")

else:

    prime = True

    for i in range(
        2,
        int(n ** 0.5) + 1
    ):

        if n % i == 0:

            prime = False

            break

    if prime:

        print("Prime")

    else:

        print("Not Prime")

6. Reverse a String 

text = input(
    "Enter text: "
)

print(text[::-1])

7. Sum of List Elements 

numbers = [10, 20, 30, 40]

total = sum(numbers)

print("Total =", total)

8. Count Vowels 

text = input(
    "Enter text: "
).lower()

count = 0

for ch in text:

    if ch in "aeiou":

        count += 1

print("Vowels =", count)
