1. Python – Basic Introduction

Python ko bilkul zero level se samjho

ENGLISH

Python is a high-level, general-purpose, interpreted programming language. It is widely used for web development, automation, data analysis, artificial intelligence, machine learning, scientific computing and many other applications.

HINDI

Python ek high-level, general-purpose aur interpreted programming language hai. Iska use web development, automation, data analysis, Artificial Intelligence, Machine Learning aur bahut saare software applications banane ke liye hota hai.

🐍 Python kya hai?

Python ek programming language hai jiske through hum computer ko instructions dete hain. In instructions ki help se hum programs aur applications bana sakte hain.

💡 Programming Language kya hai?

Programming language ek medium hai jiske through programmer computer ko instructions provide karta hai.

🎯 General Purpose

Python sirf ek particular type ke software ke liye nahi hai. Iska use multiple fields mein kiya ja sakta hai.

⚡ High Level Language

Python ka syntax human-readable hai, isliye beginners ke liye ise samajhna comparatively easy hota hai.

🐍

2. Why Python?

Python itna popular kyun hai?

Python ko beginners aur professional developers dono use karte hain. Iski popularity ka major reason iska relatively simple syntax aur large ecosystem hai.

Simple Example

Do numbers ko add karne ke liye Python mein bahut straightforward code likha ja sakta hai. 

print(10 + 20)
▶ Output 
30

5. Python Installation

Computer par Python kaise prepare karein?

Step 1 — Python Download

Python ki official distribution ko use karke Python install kiya ja sakta hai.

Step 2 — Installer Run

Download ki hui installer file ko run karein aur installation instructions follow karein.

Step 3 — PATH Option

Windows installation ke time PATH related option ko carefully check karna useful hota hai, taaki Python command terminal se accessible ho.

6. Python Interpreter

Interpreter ko simple language mein samjho

ENGLISH

An interpreter is a program that reads and executes source code. Python is commonly executed through a Python interpreter.

HINDI

Interpreter ek software/program hota hai jo source code ko process karke execute karta hai. Python programs ko Python interpreter ke through run kiya ja sakta hai.

⌨️ Interactive Mode

Is mode mein aap Python prompt par directly statements enter karke unka result dekh sakte hain.

📄 Script Mode

Python statements ko file mein save karke script ke form mein execute kiya ja sakta hai. Python source files commonly .py extension use karti hain.

Example — Interactive Statement

EASY 
>>> print("Hello")
▶ Output 
Hello
🖥️

7. IDE kya hota hai?

Integrated Development Environment

IDE ka full form Integrated Development Environment hai. IDE ek development environment provide karta hai jisme programmer code likh, edit, run aur debug kar sakta hai.

Examples

Python ecosystem mein different editors aur IDEs available hain, jaise IDLE, Visual Studio Code aur PyCharm.

🧠 Remember

  • IDE = Integrated Development Environment
  • IDLE is associated with Python and provides an environment for writing and executing Python programs.
  • Editor ka main purpose code likhna/edit karna hota hai.
  • IDE generally coding ke liye multiple development tools ek environment mein provide karta hai.

10. Identifiers

Variable, function etc. ke names

Identifier Python program mein kisi entity ko diya gaya naam hota hai, jaise variable, function, class etc.

Valid Examples

name
student_name
marks
total_marks
num1

Invalid Examples

2name
student-name
my name

🎯 Identifier Rules

  • Identifier letters, digits aur underscore contain kar sakta hai.
  • Identifier digit se start nahi kar sakta.
  • Spaces identifier mein allowed nahi hote.
  • Special symbols generally identifier ka part nahi hote.
  • Python keywords ko identifier ke roop mein use nahi karna chahiye.
  • Python identifiers case-sensitive hote hain.
🔑

12. Case Sensitivity

Capital aur small letters ka difference

Python case-sensitive language hai. Iska matlab uppercase aur lowercase names different ho sakte hain. 

name = "A"
Name = "B"

print(name)
print(Name)
▶ Output 
A
B

15. Python File Extension

Very important basic fact

Python source code files generally use the .py file extension. 

hello.py
program.py
calculator.py

🎯 One-Liner

  • Python source file extension → .py
  • Python interpreter → source code execute karne ke liye used
  • IDE → development environment
  • Keyword → reserved word
  • Identifier → user-defined name
  • Python → case-sensitive

16. Common Beginner Mistakes

Ye mistakes starting mein avoid karo

❌ Mistake 1 — Python ko HTML samajhna

Python programming language hai, jabki HTML ek markup language hai. Dono ka purpose different hai.

❌ Mistake 2 — Capitalization ignore karna

Python case-sensitive hai. Name aur name same nahi maane jaate.

❌ Mistake 3 — Keyword ko variable banana

Reserved keywords ko user-defined identifiers ke roop mein use nahi karna chahiye.

❌ Mistake 4 — Output ko guess karna

Code ko logically step-by-step evaluate karo. Operators ki precedence bhi samjho.
