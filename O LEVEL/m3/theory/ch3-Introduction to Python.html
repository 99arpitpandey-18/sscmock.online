What is Python?

Python ka basic introduction

Python is a high-level, general-purpose programming language.
Python एक high-level और general-purpose programming language है जिसका उपयोग अलग-अलग प्रकार के software और applications बनाने में किया जाता है।

Python को beginners के लिए relatively easy माना जाता है क्योंकि इसका syntax readable होता है। Python programming, automation, data analysis, web development, scientific computing और कई अन्य areas में उपयोग होती है।

High-Level Language

High-level language इंसानों के लिए comparatively easy होती है। Programmer को machine-level instructions directly लिखने की आवश्यकता नहीं होती।

हिंदी: High-level language को समझना और लिखना comparatively आसान होता है।

General-Purpose

Python केवल एक specific task के लिए नहीं है। It can be used for many different programming tasks.

हिंदी: Python का उपयोग कई अलग-अलग प्रकार के applications में किया जा सकता है।

Readable Syntax

Python code generally looks clean and readable.

हिंदी: Python की syntax comparatively सरल होने के कारण code को पढ़ना आसान होता है।

Interpreted Execution

Python programs are commonly executed through the Python interpreter.

हिंदी: Python interpreter program को execute करने में महत्वपूर्ण भूमिका निभाता है।

🎯 EXAM POINT

Python को याद रखें: High-Level + General-Purpose + Readable Syntax. NIELIT MCQ में Python की characteristics से direct questions पूछे जा सकते हैं।

Python Interpreter & Program Execution

Python code कैसे execute होता है?

An interpreter executes a program by translating/executing its instructions during program execution rather than requiring the user to manually create a native executable first.
Interpreter Python program को execute करने की प्रक्रिया में महत्वपूर्ण भूमिका निभाता है। Student को basic level पर यह समझना चाहिए कि Python source code को Python system समझकर execute करता है।
Example 1 — First Python Program Basic Execution 
print("Hello Python")
OUTPUT
Hello Python
Example 2 — Multiple Statements Execution Flow 
print("NIELIT")
print("M3-R5.1")
print("Python")
OUTPUT
NIELIT
M3-R5.1
Python
🎯 EXAM POINT

Python execution में interpreter एक key concept है। Interpreter और compiler के difference को जरूर revise करें।

Comments in Python

Code में notes लिखना

Comments are explanatory notes in source code and are ignored as executable instructions by Python.
Comments program को explain करने के लिए लिखे जाते हैं। इनका purpose code को readable और understandable बनाना होता है।
Example 1 — Single Line Comment # symbol 
# This is a comment
print("Hello")
OUTPUT
Hello
Example 2 — Comments with Code Readable Program 
# Store marks
marks = 85

# Display marks
print(marks)
OUTPUT
85
⚠️ COMMON MISTAKE

Comment के लिए # का उपयोग करें। Example: # Python is easy

Python Data Types

Data को किस type में store किया जाता है?

A data type defines the kind of value an object represents.
Data type यह बताता है कि किसी variable/object में किस प्रकार का data मौजूद है।

int

Whole numbers.
Example: 10, -5, 100

float

Decimal numbers.
Example: 10.5, 3.14

complex

Complex numbers.
Example: 2+3j

str

Text/string data.
Example: "Hello"

bool

Boolean values: True or False.

list

Ordered, mutable collection.
Example: [10,20,30]

tuple

Ordered, immutable collection.
Example: (10,20,30)

dict

Key-value collection.
Example: {"name":"Amit"}

Example — Checking Data Type type() 
x = 25
y = 5.5
name = "Python"

print(type(x))
print(type(y))
print(type(name))
OUTPUT
<class 'int'>
<class 'float'>
<class 'str'>
🎯 EXAM POINT

type() function किसी object/value का type check करने के लिए उपयोग होती है।

Strings in Python

Text data को समझें

A string is a sequence of characters enclosed in quotes.
String characters का sequence होता है जिसे quotes के अंदर लिखा जाता है। Single quotes और double quotes commonly used होते हैं।
Example 1 — Creating a String String 
name = "Python"

print(name)
OUTPUT
Python
Example 2 — String Indexing Index starts from 0 
word = "PYTHON"

print(word[0])
print(word[1])
print(word[5])
OUTPUT
P
Y
N
Example 3 — Negative Indexing Right to Left 
word = "PYTHON"

print(word[-1])
print(word[-2])
OUTPUT
N
O
Example 4 — String Slicing start : stop 
word = "PYTHON"

print(word[0:3])
print(word[2:5])
OUTPUT
PYT
THO
Example 5 — Concatenation + 
first = "Hello"
second = "Python"

print(first + " " + second)
OUTPUT
Hello Python
Example 6 — Repetition * 
word = "Hi "

print(word * 3)
OUTPUT
Hi Hi Hi
🎯 EXAM POINT

String indexing सामान्यतः 0 से शुरू होती है। Example: PYTHON में P का index 0 और N का index 5 है। Negative indexing में last character का index -1 होता है।

Input & Output Operations

Keyboard से data लेना और screen पर दिखाना

print() Function

English: print() is used to display output.
हिंदी: print() function screen पर output display करने के लिए उपयोग होता है।

Example 1 — print() Output 
print("Welcome")
print(100)
print(10 + 20)
OUTPUT
Welcome
100
30

input() Function

English: input() is used to accept data from the user through the console.
हिंदी: input() function user से console के माध्यम से input लेने के लिए उपयोग होती है।

Example 2 — User Input input() 
name = input("Enter your name: ")

print("Hello", name)
SAMPLE OUTPUT
Enter your name: Rahul
Hello Rahul
⚠️ VERY IMPORTANT

Python में input() से मिलने वाला user input सामान्यतः string के रूप में आता है। अगर numeric calculation करनी है, तो appropriate conversion करना पड़ सकता है।

Example 3 — Integer Input int() 
a = int(input("Enter first number: "))
b = int(input("Enter second number: "))

print(a + b)
SAMPLE OUTPUT
Enter first number: 10
Enter second number: 20
30
Example 4 — Float Input float() 
price = float(input("Enter price: "))

print(price)
SAMPLE OUTPUT
Enter price: 99.5
99.5
10

Variables

Data store करने का basic concept

A variable is a name that refers to a value/object in a program.
Variable एक नाम है जिसके माध्यम से हम किसी value/object को refer करते हैं।
Example 1 — Variables Assignment 
name = "Amit"
age = 20
marks = 85.5

print(name)
print(age)
print(marks)
OUTPUT
Amit
20
85.5
Example 2 — Changing a Variable Dynamic Assignment 
x = 10

print(x)

x = 25

print(x)
OUTPUT
10
25
💡 EASY UNDERSTANDING

सोचो variable एक label की तरह है जो किसी value को refer करता है।

marks = 90
यहाँ marks नाम है और 90 value है।

Common Student Mistakes

इन गलतियों से बचना बहुत जरूरी है

❌ input() को हमेशा int समझना

input() से प्राप्त value को numeric calculation के लिए अक्सर int() या float() में convert करना पड़ता है।

❌ Index 1 से शुरू करना

Python sequence indexing सामान्यतः 0 से शुरू होती है।
PYTHON → P = 0

❌ = और == को confuse करना

= assignment के लिए होता है।
== comparison के लिए।

❌ String quotes भूल जाना

Text value के लिए quotes का सही उपयोग करें।
Example: "Python"
