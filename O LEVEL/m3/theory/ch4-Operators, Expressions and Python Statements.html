1. What is an Operator?

Operator का basic concept

🇬🇧 ENGLISH

An operator is a special symbol or keyword that performs an operation on one or more values. These values are called operands.

🇮🇳 हिंदी

Operator एक special symbol या keyword होता है जो एक या एक से अधिक values पर कोई operation perform करता है। इन values को operands कहते हैं।

💡 Example समझो

10 + 5 में 10 और 5 operands हैं जबकि + operator है। यह दोनों numbers को जोड़ता है।

⚙️

and, or और not को master करें

7. Membership Operators

in और not in

🇬🇧 ENGLISH

Membership operators check whether a value exists inside a sequence such as a string or list.

🇮🇳 हिंदी

Membership operators यह check करते हैं कि कोई value string, list आदि sequence के अंदर मौजूद है या नहीं।

PYTHON 
name = "Python"

print("P" in name)
print("z" in name)
print("P" not in name)
OUTPUT 
True
False
False
🪪

8. Identity Operators

is और is not

🇬🇧 ENGLISH

Identity operators compare whether two variables refer to the same object in memory.

🇮🇳 हिंदी

Identity operators यह check करते हैं कि दो variables एक ही object को refer कर रहे हैं या नहीं।

PYTHON 
a = [1, 2, 3]
b = a
c = [1, 2, 3]

print(a is b)
print(a is c)
OUTPUT 
True
False
⚠️ Exam Point

== values compare करता है जबकि is object identity check करता है। दोनों को same मत समझना।

11. Operator Precedence

कौन सा operation पहले होगा?

जब एक expression में कई operators होते हैं, तो Python एक particular order follow करता है। इसे operator precedence कहते हैं।

Priority Operator / Concept
1 Parentheses ( )
2 Exponent **
3 Unary +, -
4 *, /, //, %
5 +, -
6 Comparison operators
7 not
8 and
9 or

Example 6 — Very Important

PYTHON 
result = 10 + 5 * 2

print(result)
OUTPUT 
20

क्योंकि multiplication पहले होगा: 5 × 2 = 10, फिर 10 + 10 = 20.

Example 7 — Parentheses

PYTHON 
result = (10 + 5) * 2

print(result)
OUTPUT 
30

14. Python Statements

Program instructions

🇬🇧 ENGLISH

A statement is an instruction that Python can execute. A Python program consists of one or more statements.

🇮🇳 हिंदी

Statement Python को दी गई एक instruction होती है जिसे Python execute करता है। पूरा program कई statements से मिलकर बन सकता है।

Assignment Statement
CODE 
x = 100

Variable में value assign करता है।

Print Statement
CODE 
print(x)

Output screen पर value display करता है।

Conditional Statement
CODE 
if x > 50:
    print("Pass")

Condition के आधार पर instruction execute करता है।

Loop Statement
CODE 
for i in range(3):
    print(i)

Repeated execution के लिए use होता है।

🔀

15. Control Statements — Quick Understanding

आगे आने वाले concepts की foundation

FOR

17. NIELIT Exam Tricks

MCQ में गलती कम करने के लिए

1️⃣ / और //

10 / 3 → 3.333...
10 // 3 → 3

2️⃣ % का मतलब

% remainder देता है।
17 % 5 = 2

3️⃣ ** का मतलब

2 ** 4 = 16

4️⃣ = और ==

= → Assignment
== → Comparison

5️⃣ Logical Operators

and → दोनों conditions True
or → कम से कम एक True
not → result उल्टा

6️⃣ input()

input() से आने वाला data सामान्यतः string होता है। Number के लिए int() / float() याद रखें।

7️⃣ == vs is

== → values compare करता है।
is → object identity check करता है।
