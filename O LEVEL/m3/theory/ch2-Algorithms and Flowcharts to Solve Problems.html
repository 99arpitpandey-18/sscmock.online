1. Chapter Introduction

Chapter ko sabse pehle simple language mein samjho

Variables क्या होते हैं?

Variable एक नाम होता है जिसमें हम कोई value store कर सकते हैं।

A variable is a name used to store a value in a Python program.

Simple Formula:
Variable = Name + Stored Value
PYTHON EXAMPLE
name = "Arpit"
age = 19
marks = 85.5
name → "Arpit"    age → 19    marks → 85.5
📦

9. Type Conversion

एक data type को दूसरे data type में बदलना

Implicit Conversion

Python automatically smaller compatible type को larger type में convert कर सकता है।

IMPLICIT CONVERSION
a = 10
b = 2.5

c = a + b

print(c)
print(type(c))
12.5
<class 'float'>

Explicit Conversion / Type Casting

हम manually भी type convert कर सकते हैं।

TYPE CASTING
x = "25"

a = int(x)

print(a)
print(type(a))
25
<class 'int'>

int()

Value को integer में convert करता है।

float()

Value को floating point number में convert करता है।

str()

Value को string में convert करता है।

17. Operator Precedence

कौन सा operator पहले execute होगा?

Python expression में operators एक निश्चित order में execute होते हैं।

EXAMPLE
result = 10 + 5 * 2
print(result)
20

पहले multiplication हुआ:
5 × 2 = 10
फिर addition:
10 + 10 = 20

Quick Order:
() → ** → *, /, //, % → +, - → comparison → logical
🌍

21. Quick Practice MCQs

Chapter 2 को test करें

Q1. Which symbol is used for assignment in Python? A. == B. = C. != D. ===
✔ Answer: B. =
Q2. What is the data type of 10.5? A. int B. str C. float D. bool
✔ Answer: C. float
Q3. What does % operator return? A. Quotient B. Remainder C. Power D. Average
✔ Answer: B. Remainder
Q4. What is 10 // 3? A. 3 B. 3.33 C. 1 D. 4
✔ Answer: A. 3
Q5. Which function is used to find the type of a variable? A. datatype() B. typeof() C. type() D. findtype()
✔ Answer: C. type()
Q6. Which is a Boolean value? A. "True" B. 1 C. True D. "False"
✔ Answer: C. True
Q7. What is the result of 2 ** 3? A. 5 B. 6 C. 8 D. 9
✔ Answer: C. 8
Q8. Which is a valid variable name? A. 2name B. my-name C. my_name D. class
✔ Answer: C. my_name
Q9. Which operator is used for equality comparison? A. = B. == C. != D. =>
✔ Answer: B. ==
Q10. Which operator means "not equal to"? A. == B. = C. != D. <>
✔ Answer: C. !=
