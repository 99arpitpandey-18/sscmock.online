Python क्या है? Why Python? Where is Python used?

Important Practical Programs

Exam-oriented Python practice

1. Largest of Three Numbers

Python Program 
a = int(input("Enter A: "))
b = int(input("Enter B: "))
c = int(input("Enter C: "))

if a >= b and a >= c:
    largest = a
elif b >= a and b >= c:
    largest = b
else:
    largest = c

print("Largest =", largest)

2. Sum of First N Numbers

Python Program 
n = int(input("Enter N: "))

total = 0

for i in range(1, n + 1):
    total += i

print("Sum =", total)

3. Prime Number Check

Python Program 
n = int(input("Enter number: "))

if n < 2:
    print("Not Prime")
else:

    prime = True

    for i in range(2, n):
        if n % i == 0:
            prime = False
            break

    if prime:
        print("Prime")
    else:
        print("Not Prime")

4. Reverse a String

Python Program 
text = input("Enter text: ")

print(text[::-1])

5. Count Vowels

Python Program 
text = input("Enter text: ")

count = 0

for ch in text.lower():

    if ch in "aeiou":
        count += 1

print("Vowels =", count)
