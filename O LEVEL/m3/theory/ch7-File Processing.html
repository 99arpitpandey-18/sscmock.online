1. What is File Processing?

Basic concept • मूल अवधारणा

File Processing / फ़ाइल प्रोसेसिंग

English: File processing means performing operations on files such as creating, opening, reading, writing, updating and closing files.

हिन्दी: File Processing का अर्थ files पर अलग-अलग operations करना है, जैसे file बनाना, खोलना, पढ़ना, लिखना, data जोड़ना और file को बंद करना।

📄 File

A file is a collection of data stored permanently on a storage device. Examples: TXT, CSV, PDF, JPG etc.

File data को permanently store करने का माध्यम है।

🐍 Why Python Files?

Python provides simple built-in functions and methods for working with files.

Python में files के साथ काम करना बहुत आसान है क्योंकि built-in functions उपलब्ध हैं।

🔄

2. Basic File Processing Workflow

File handling का basic flow

Step 1 — Open

First open the file using the open() function.

सबसे पहले file को open() function से खोलते हैं।

Step 2 — Process

Read, write or append data according to the requirement.

Requirement के अनुसार data को read, write या append करते हैं।

Step 3 — Close

Close the file after completing the operation.

काम पूरा होने के बाद file को close करना चाहिए।

Step 4 — Verify

Check whether the required data has been correctly processed.

Check करें कि data सही तरीके से process हुआ या नहीं।

🧠 Memory Trick

O → P → C
Open → Process → Close

याद रखें: “Open → Work → Close”

🔓

3. open() Function

Syntax

PYTHON

हिन्दी: open() function file को खोलता है और एक file object return करता है।

4. File Modes

Exam का सबसे important हिस्सा

Mode Meaning Use
r Read Existing file को पढ़ने के लिए
w Write Writing; existing content can be overwritten
a Append Existing file के end में data जोड़ने के लिए
x Create New file create करने के लिए
r+ Read + Write Read और write दोनों
w+ Write + Read Write और read दोनों
a+ Append + Read Append और read दोनों
b Binary Binary data के लिए
🔥 Super Important Exam Trick

r = Read
w = Write
a = Add at end
x = eXclusive creation
b = Binary

8. close() Method

File बंद करना

English: The close() method closes an opened file.

हिन्दी: close() method opened file को बंद करता है।

EXAMPLE 08 
f = open("student.txt", "r")

print(f.read())

⭐ Exam Point

9. with Statement

Safe और convenient file handling

Why use with?

English: The with statement automatically handles closing the file after the block is completed.

हिन्दी: with statement का उपयोग करने पर block complete होने के बाद file automatically close हो जाती है।

EXAMPLE 09 — WITH 
with open("student.txt", "r") as f:

    data = f.read()

    print(data)

13. writelines()

Multiple strings लिखना

EXAMPLE 12

    "HTML\n",
    "CSS\n",
    "JavaScript\n"

with open("web.txt", "w") as f:

    f.writelines(lines)

ध्यान दें: writelines() automatically हर string के बीच newline नहीं लगाता। यदि अलग lines चाहिए तो strings में \n देना पड़ सकता है।

17. Complete File Processing Program

Exam-style practical example

COMPLETE EXAMPLE 
# Create and write data

with open("marks.txt", "w") as f:

    f.write("Rahul - 85\n")
    f.write("Aman - 78\n")
    f.write("Neha - 92\n")


# Read data

with open("marks.txt", "r") as f:

    data = f.read()

    print(data)


# Append data

with open("marks.txt", "a") as f:

    f.write("Priya - 88\n")

18. Common Mistakes

Students अक्सर यहाँ गलती करते हैं

  • File open करके close करना भूल जाना
  • r, w और a modes में confusion करना
  • w mode से existing content overwrite होने की possibility भूल जाना
  • read(), readline() और readlines() को same समझना
  • writelines() में newline automatically expect करना
  • File name/path गलत लिखना
  • File को wrong mode में open करना
  • FileNotFoundError को ignore करना
  • seek() और tell() को confuse करना
  • String और file object के बीच difference भूलना
