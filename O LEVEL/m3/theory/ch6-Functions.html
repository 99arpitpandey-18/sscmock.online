1. What is a Function?

Function ka basic concept

ENGLISH

A function is a reusable block of code designed to perform a specific task. Instead of writing the same code again and again, we create a function once and call it whenever required.

हिंदी

Function code का एक reusable block होता है जो किसी particular task को perform करता है। एक ही code को बार-बार लिखने के बजाय हम उसे function में लिखकर जरूरत के अनुसार call करते हैं।

💡 Easy Trick: Function को एक machine की तरह समझो। आप उसे input देते हो → machine काम करती है → output देती है।

Function = Input → Processing → Output
🧠

2. Why Do We Use Functions?

Functions ke advantages

01

Code Reusability

Write code once and use it multiple times.

Code को एक बार लिखकर कई बार use किया जा सकता है।

02

Easy Debugging

Functions divide a large program into smaller manageable blocks.

बड़े program को छोटे blocks में divide करने से error find करना आसान होता है।

03

Less Repetition

Repeated statements do not need to be written again.

बार-बार same statements लिखने की जरूरत नहीं होती।

04

Better Organization

A complex program becomes easier to understand.

Complex program ज्यादा organized और easy to understand हो जाता है।

3. Defining a Function

Function kaise create karte hain?

ENGLISH

In Python, a function is created using the def keyword followed by the function name and parentheses.

हिंदी

Python में function बनाने के लिए def keyword का use किया जाता है। इसके बाद function का name और parentheses लिखे जाते हैं।

def function_name(): statements Example: def greet(): print("Hello")
🐍 Python Example 01 
def greet():
    print("Hello Student!")

greet()
▶ OUTPUT 
Hello Student!
📌 Remember: Function define करने से function automatically execute नहीं होता। उसे execute करने के लिए function को call करना पड़ता है।
📞

4. Calling a Function

Function ko execute kaise karein?

ENGLISH

Calling a function means executing the statements written inside that function.

हिंदी

Function calling का मतलब है function के अंदर लिखे statements को execute करना।

🐍 Example 02 
def welcome():
    print("Welcome to M3-R5")

welcome()
▶ OUTPUT 
Welcome to M3-R5
🎯 EXAM POINT: Definition और Calling अलग concepts हैं। def welcome(): → Function definition welcome() → Function call

5. Parameters & Arguments

Input function ke andar kaise bhejte hain?

PARAMETER

A parameter is a variable written inside the function definition.


Function definition में लिखे variable को parameter कहते हैं।

ARGUMENT

An argument is the actual value passed to a function when it is called.


Function call करते समय दी गई actual value को argument कहते हैं।

🐍 Example 03 
def square(n):
    print(n * n)

square(5)
▶ OUTPUT 
25
💡 याद रखने की Trick: Parameter = Placeholder Argument = Actual Value Example: def square(n): यहाँ n = Parameter और square(5) यहाँ 5 = Argument

7. return Statement

Function se value wapas lena

ENGLISH

The return statement sends a value back from a function to the place where the function was called.

हिंदी

return statement function से value को वापस उस जगह भेजता है जहाँ function को call किया गया था।

🐍 Example 06 — Return Value 
def add(a, b):
    return a + b

result = add(15, 25)

print(result)
▶ OUTPUT 
40
🎯 IMPORTANT: print() value ko screen par display karta hai.
return value ko function se caller ke paas wapas bhejta hai.
⚖️

8. print() vs return

Very important exam comparison

print() return
Displays output on screen. Sends value back from function.
Generally used for displaying. Used when result is needed elsewhere.
Does not return the calculated value to caller in the same way. Returns a value to caller.
Example: print(a+b) Example: return a+b

9. Default Arguments

Default value wale parameters

A default argument is a parameter that already has a default value. If the caller does not provide a value, Python uses the default value.


Default argument में parameter को पहले से एक value दी जाती है। अगर function call के समय value नहीं दी जाती, तो default value use होती है।

🐍 Example 07 
def greet(name="Student"):
    print("Hello", name)

greet()
greet("Amit")
▶ OUTPUT 
Hello Student
Hello Amit
🔑

10. Keyword Arguments

Parameter name ke through value dena

In keyword arguments, values are passed using parameter names. Therefore, the order of arguments is not important.


Keyword argument में value parameter के नाम के साथ pass की जाती है। इसलिए arguments का order important नहीं रहता।

🐍 Example 08 
def student(name, age):
    print(name, age)

student(age=20, name="Ravi")
▶ OUTPUT 
Ravi 20
📍

11. Positional Arguments

Position ke according values

In positional arguments, values are assigned according to their position in the function call.


Positional arguments में values उनकी position के according parameters को assign होती हैं।

🐍 Example 09 
def info(name, city):
    print("Name:", name)
    print("City:", city)

info("Arjun", "Agra")
▶ OUTPUT 
Name: Arjun
City: Agra

12. Local & Global Variables

Variable scope ko easy way mein samjho

L

Local Variable

A variable created inside a function is generally local to that function.

Function के अंदर बनाया गया variable generally उस function के scope तक limited होता है।

G

Global Variable

A variable created outside functions is a global variable and can generally be accessed from functions.

Function के बाहर बनाया गया variable global variable कहलाता है।

🐍 Example 10 
x = 10

def show():
    y = 20

    print(x)
    print(y)

show()
▶ OUTPUT 
10
20

13. Recursive Function

Function ka khud ko call karna

ENGLISH

A recursive function is a function that calls itself. A proper stopping condition, called a base case, is necessary to stop recursion.

हिंदी

Recursive function वह function है जो खुद को call करता है। Recursion को रोकने के लिए base condition जरूरी होती है।

🐍 Example 11 — Factorial 
def factorial(n):

    if n == 0:
        return 1

    return n * factorial(n - 1)

print(factorial(5))
▶ OUTPUT 
120
⚠️ IMPORTANT: Recursive function में base condition नहीं होगी तो function repeatedly call हो सकता है और program में recursion-related error आ सकता है।

17. Common Mistakes

Students commonly make these errors

1. Function call भूल जाना
Function define कर दिया लेकिन call नहीं किया।
2. Indentation गलत करना
Python में function body correctly indented होना जरूरी है।
3. Parameter और Argument को confuse करना
Parameter → definition में variable
Argument → call के समय actual value
4. print और return को same समझना
print display करता है जबकि return value को caller के पास भेजता है।
5. Recursive function में base condition भूलना
Recursion को stop करने के लिए base condition जरूरी है।
