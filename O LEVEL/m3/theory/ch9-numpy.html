1. What is NumPy?

NumPy का basic concept समझें

ENGLISH

NumPy stands for Numerical Python. It is a Python library mainly used for numerical calculations, scientific computing and working with multidimensional arrays.

हिन्दी

NumPy का पूरा नाम Numerical Python है। यह Python की एक library है जिसका उपयोग numerical calculation, scientific computing और multidimensional arrays के लिए किया जाता है।

Exam Point: NumPy का मुख्य object ndarray है, जिसे NumPy array भी कहा जाता है।
⭐

2. Why Do We Use NumPy?

NumPy की आवश्यकता क्यों पड़ती है?

  • Large numerical data के साथ काम करना आसान होता है।
  • Multidimensional arrays को efficiently handle करता है।
  • Mathematical operations आसानी से perform किए जा सकते हैं।
  • Array operations Python lists की तुलना में numerical computing में अधिक efficient हो सकते हैं।
  • Scientific computing, data analysis और machine learning में widely used है।
Easy Trick: Python List = General purpose collection
NumPy Array = Numerical data के लिए powerful structure

4. NumPy Array

ndarray को समझें

ENGLISH

A NumPy array is an object used to store elements of the same data type in one or more dimensions.

हिन्दी

NumPy array एक ऐसा data structure है जिसमें सामान्यतः एक ही प्रकार के data elements को एक या अधिक dimensions में रखा जाता है।

EXAMPLE 1 — CREATE ARRAY
import numpy as np

a = np.array([10, 20, 30, 40])

print(a)
OUTPUT
[10 20 30 40]
EXAMPLE 2 — ARRAY FROM LIST
import numpy as np

numbers = [5, 10, 15, 20]

arr = np.array(numbers)

print(arr)
OUTPUT
[ 5 10 15 20]
📐

6. Important Array Attributes

ndarray की important properties

ndim

Array की number of dimensions बताता है।

shape

Array की dimensions का size बताता है।

size

Array में total elements की संख्या बताता है।

dtype

Elements का data type बताता है।

itemsize

एक element के bytes में size को बताता है।

nbytes

Array द्वारा उपयोग किए गए total bytes को बताता है।

EXAMPLE

a = np.array([
    [10,20,30],
    [40,50,60]
])

print(a.ndim)
print(a.shape)
print(a.size)

2
(2, 3)
6

7. Array Indexing

Array के elements access करना

ENGLISH

Indexing is used to access individual elements of an array. Like Python lists, NumPy arrays use zero-based indexing.

हिन्दी

Indexing का उपयोग array के individual elements को access करने के लिए किया जाता है। NumPy में indexing zero से शुरू होती है।

EXAMPLE 1
a = np.array([10,20,30,40])

print(a[0])
print(a[2])
print(a[-1])
OUTPUT

30
40

2D Indexing

EXAMPLE 2

    [10,20,30],
    [40,50,60]
])

print(a[0,1])
print(a[1,2])
OUTPUT

60

14. Reshaping an Array

Array का shape बदलना

ENGLISH

The reshape() method changes the shape of an array without changing its data.

हिन्दी

reshape() array के data को बदले बिना उसके shape को बदलने के लिए उपयोग किया जाता है।

EXAMPLE
a = np.array([1,2,3,4,5,6])

b = a.reshape(2,3)

print(b)
OUTPUT
[[1 2 3]
 [4 5 6]]
Important: Reshape करते समय total number of elements compatible होना चाहिए। उदाहरण: 6 elements को 2×3 में reshape किया जा सकता है।
📉

21. Common Mistakes

इन गलतियों से बचें

Mistake 1: NumPy import किए बिना np.array() use करना।

Correct: import numpy as np
Mistake 2: reshape में incompatible dimensions देना।

Example: 6 elements को 2×4 में reshape नहीं किया जा सकता।
Mistake 3: np.arange() और np.linspace() को same समझना।

दोनों का purpose और argument behavior अलग है।
Mistake 4: Array indexing में पहला index 1 समझना।

Python और NumPy में indexing सामान्यतः 0 से शुरू होती है।
