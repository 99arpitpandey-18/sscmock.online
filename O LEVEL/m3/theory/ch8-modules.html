1. What is a Module?

Module ki basic concept

Module Definition

A module is a Python file containing definitions, functions, variables or classes that can be reused in another Python program.

Module ek Python file hoti hai jisme functions, variables, classes ya other reusable code ho sakta hai. Is code ko doosre Python programs mein reuse kiya ja sakta hai.

💡 Easy Trick: Module = Reusable Python Code stored in a file.
Example maths.py, calculator.py, student.py etc. Python files modules ban sakti hain.
Benefit Large program ko small reusable files mein divide karna easy ho jata hai.
💡

4. import Statement

Module ko program mein include karna

The import statement is used to make a module available in the current Python program.

import statement ka use kisi module ko current program mein use karne ke liye kiya jata hai.

EXAMPLE 01 — import math Basic Import 
import math

print(math.sqrt(25))
print(math.pi)
OUTPUT
5.0 3.141592653589793
Notice: math.sqrt() aur math.pi mein math. module name hai.
🎯

5. from ... import

Specific function ko import karna

We can import a specific function or object from a module using from ... import.

Agar hume poora module use nahi karna aur sirf specific function chahiye, to from ... import use kar sakte hain.

EXAMPLE 02 from math import sqrt 
from math import sqrt

print(sqrt(49))
OUTPUT
7.0
EXAMPLE 03 Multiple Imports 
from math import sqrt, pow

print(sqrt(64))
print(pow(2,3))
OUTPUT
8.0 8.0
🏷️

6. import with Alias

Module ka short name banana

Long module name ko short name dene ke liye as keyword use kiya ja sakta hai.

EXAMPLE 04 Alias 
import math as m

print(m.sqrt(81))
print(m.pi)
OUTPUT
9.0 3.141592653589793
⭐ Exam Point: as keyword alias/alternate name dene ke liye use hota hai.
🧮

7. math Module

Most important standard module examples

Function / Constant Meaning Example
math.sqrt(x) Square root math.sqrt(16) → 4.0
math.pow(x,y) x raised to y math.pow(2,3) → 8.0
math.ceil(x) Next integer / upper rounding math.ceil(4.2) → 5
math.floor(x) Lower integer math.floor(4.9) → 4
math.pi Value of π 3.14159...
math.factorial(x) Factorial math.factorial(5) → 120
EXAMPLE 05 — math Functions Practical 
import math

print(math.sqrt(36))
print(math.pow(2,4))
print(math.ceil(5.2))
print(math.floor(5.9))
print(math.factorial(5))
OUTPUT
6.0 16.0 6 5 120

10. User-Defined Module

Apna module kaise banaye?

Step 1 — Create Module File

Suppose hum calculator.py naam ki file banate hain.

calculator.py MODULE FILE 
def add(a,b):
    return a+b

def subtract(a,b):
    return a-b

def multiply(a,b):
    return a*b

Step 2 — Use the Module

Ab ek second file main.py banate hain.

main.py IMPORT MODULE 
import calculator

print(calculator.add(10,5))
print(calculator.subtract(10,5))
print(calculator.multiply(10,5))
OUTPUT
15 5 50
⭐ Important: calculator.py aur main.py ko same folder mein rakhna beginner example mein easiest approach hai.
📤

15. LEGB Rule

Python name lookup ka basic idea

Letter Meaning Explanation
L Local Current function ke andar.
E Enclosing Outer function ka scope.
G Global Module/program level.
B Built-in Python ke built-in names.
🧠 Remember: L → E → G → B
🚦

16. __name__

Module ka important special variable

Python mein __name__ ek special built-in variable hai. Jab file directly run hoti hai, generally uska value "__main__" hota hai.

EXAMPLE 12 __name__ 
print(__name__)
DIRECT EXECUTION OUTPUT
__main__
🛡️

17. if __name__ == "__main__"

Important practical concept

EXAMPLE 13 MAIN GUARD 
def greet():
    print("Hello Python")

if __name__ == "__main__":
    greet()
OUTPUT
Hello Python

Is pattern ka use ye ensure karne ke liye kiya jata hai ki kuch code tab execute ho jab file directly run ki jaye.

🚀

18. Mini Project — Student Module

Real practical example

student.py

def percentage(m1,m2,m3):

    total = m1 + m2 + m3

    return total / 3


def result(mark):

    if mark >= 40:
        return "Pass"

    return "Fail"

main.py

import student

marks = student.percentage(70,80,90)

print("Percentage:",marks)
print("Result:",student.result(marks))
OUTPUT
Percentage: 80.0 Result: Pass
