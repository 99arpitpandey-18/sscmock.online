05

Sequence Data Types

List, Tuple and Dictionary

Lists, tuples and dictionary; slicing, indexing, concatenation and other operations on sequence data types.

📋 List Mutable sequence
🔒 Tuple Immutable sequence
🗝️ Dictionary Key-value pairs
Important: Concept of mutability is very important for examination.

Examples include finding maximum, minimum, mean; linear search on list/tuple of numbers and counting frequency of elements in a list using a dictionary. 

numbers = [10, 20, 30, 40, 50]

print(max(numbers))
print(min(numbers))

mean = sum(numbers) / len(numbers)

print(mean)

File Processing

Working with files in Python

Concept of Files, file opening in various modes and closing of a file, reading from a file and writing onto a file.

Important File Functions

📂 open() File खोलने के लिए
❌ close() File बंद करने के लिए
📖 read() File का content पढ़ने के लिए
📄 readline() एक line पढ़ने के लिए
📚 readlines() Lines को read करने के लिए
✍️ write() File में data लिखने के लिए
📝 writelines() Multiple lines लिखने के लिए
📍 tell() Current file position जानने के लिए
↔️ seek() File position बदलने के लिए 
file = open("example.txt", "w")

file.write("Hello Python")

file.close()
