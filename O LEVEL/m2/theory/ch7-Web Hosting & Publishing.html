Chapter Objective

What you will learn in this chapter

Web Hosting & Publishing | वेब होस्टिंग और पब्लिशिंग

Web publishing is the process of making a website available to users over the Internet. A website normally contains files such as HTML, CSS, JavaScript, images, audio and video. These files are stored on a web server and delivered to users through the Internet.

Web Publishing का अर्थ किसी website को Internet पर users के लिए उपलब्ध कराना है। Website की HTML, CSS, JavaScript, images, audio और video जैसी files को web server पर store किया जाता है और फिर users Internet के माध्यम से उन्हें access करते हैं।

🌐

1. Domain Name

Website की Internet पहचान

🔗

What is a Domain?

A domain name is the human-readable address used to access a website on the Internet.

Domain Name website का वह readable address है जिसका उपयोग Internet पर website को खोलने के लिए किया जाता है।

  • Example: example.com
  • Easy to remember
  • Represents website identity
  • Connected with an IP address
🧩

Parts of Domain

A domain may contain a name and a Top-Level Domain (TLD).

Domain में मुख्य रूप से domain name और Top-Level Domain (TLD) शामिल होते हैं।

  • .com → Commercial
  • .org → Organization
  • .edu → Education
  • .gov → Government
  • .in → India country-code domain
☁️

2. Web Hosting

Website files को server पर रखने की service

What is Web Hosting? | Web Hosting क्या है?

Web hosting is a service that provides storage and server resources for website files so that the website can be accessed through the Internet.

Web Hosting एक ऐसी service है जिसमें website की files को web server पर store किया जाता है ताकि users Internet के माध्यम से website को access कर सकें।

  • Stores website files
  • Provides server resources
  • Makes website available online
  • May provide databases and email services
⚖️

Domain vs Hosting

Important examination comparison

Domain Name Web Hosting
Website का address Website files रखने की service
Example: example.com Server storage/resources
Helps users locate website Stores and serves website content
Related to DNS Related to web servers
🖥️

3. Web Server

Website files को users तक पहुँचाने वाला system

🖥️

Definition

A web server is a computer system or software that stores, processes and delivers web content to clients.

Web Server एक computer system या software है जो website content को store/process करके clients को deliver करता है।

📤

Main Function

  • Receives client requests
  • Processes requests
  • Finds requested resource
  • Sends response to client
🧭

4. DNS – Domain Name System

Domain name को IP address से connect करता है

DNS | Domain Name System

DNS is a naming system that translates human-readable domain names into IP addresses used by computers and network systems.

DNS यानी Domain Name System domain name को उसके corresponding IP address से resolve करता है। इससे users को numerical IP address याद रखने की आवश्यकता नहीं होती।

  • DNS = Domain Name System
  • Converts/resolves domain names to IP addresses
  • Helps locate Internet resources
  • Works as an important part of Internet naming
🔐

5. HTTP & HTTPS

Web communication protocols

Feature HTTP HTTPS
Full Form HyperText Transfer Protocol HyperText Transfer Protocol Secure
Security Not encrypted by TLS Uses encrypted connection with TLS
Browser Indicator May show non-secure indication depending on browser/context Typically shown with a secure connection indicator
Common Use General web communication Secure web communication

Exam Point

HTTPS uses TLS to help provide confidentiality, integrity and authentication for communication between a client and server.

HTTPS में TLS का उपयोग secure communication के लिए किया जाता है। यह data की confidentiality, integrity और server authentication में सहायता करता है।

📂

6. FTP – File Transfer Protocol

Files transfer करने के लिए protocol

📤

FTP

FTP is a protocol used for transferring files between a client and a server over a network.

FTP एक network protocol है जिसका उपयोग client और server के बीच files transfer करने के लिए किया जाता है।

🔒

SFTP

SFTP means SSH File Transfer Protocol and provides secure file transfer over SSH.

SFTP SSH के माध्यम से secure file transfer उपलब्ध कराता है।

8. Types of Web Hosting

Common hosting models

Shared Hosting Multiple websites share resources of the same server. कम लागत वाली websites के लिए commonly used.
VPS Hosting A physical server is divided into isolated virtual environments with dedicated allocations.
Dedicated Hosting A complete physical server is allocated to one customer or application.
Cloud Hosting Website resources can operate across a cloud infrastructure rather than a single physical server.
Free Hosting Basic hosting services may be provided at no cost, usually with limitations.
Reseller Hosting Hosting resources can be resold to other customers under a reseller arrangement.

Exam में बार-बार पूछे जाने वाले concepts
