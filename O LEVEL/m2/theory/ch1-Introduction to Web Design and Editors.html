1. Internet

इंटरनेट क्या है?

Internet इंटरनेट

English

Internet is a worldwide network of interconnected computers and devices that communicate with each other using standard communication protocols.

हिन्दी

Internet दुनिया भर में जुड़े हुए computers और devices का एक विशाल network है, जो communication protocols की सहायता से एक-दूसरे से communicate करते हैं।

Exam Definition:

Internet is a global network of interconnected computer networks.
इंटरनेट interconnected computer networks का एक global network है।

⚡

Important Features of Internet

इंटरनेट की प्रमुख विशेषताएँ

🌍

Global Network

वैश्विक नेटवर्क

Internet connects millions of networks, computers and devices across the world. इंटरनेट पूरी दुनिया के लाखों networks, computers और devices को connect करता है।

💬

Communication

संचार

It allows users to communicate through email, messaging, video conferencing etc. यह email, messaging और video conferencing के माध्यम से communication की सुविधा देता है।

🔎

Information Access

जानकारी प्राप्त करना

Users can access educational, scientific, business and other information. Users विभिन्न प्रकार की information access कर सकते हैं।

☁️

Online Services

ऑनलाइन सेवाएँ

Internet provides online banking, shopping, education, entertainment and many other services.

🌍

2. World Wide Web (WWW)

World Wide Web का परिचय

World Wide Web WWW

English

World Wide Web is a collection of interconnected web pages and resources that are accessed through the Internet using web browsers.

हिन्दी

WWW interconnected web pages और resources का एक collection है, जिसे Internet के माध्यम से web browser की सहायता से access किया जाता है।

Very Important:

Internet और WWW एक ही चीज नहीं हैं।
Internet = Network
WWW = Web pages/resources का system

⚖️

Internet vs WWW

दोनों में अंतर

Internet WWW
Global network of networks.
Networks का global network. 		Collection of interconnected web resources.
Web resources का collection.
Internet is broader. WWW is a service running over the Internet.
Uses many services such as email, FTP etc. Mainly provides access to web pages/resources.
🖥️

3. Website

वेबसाइट क्या है?

Website वेबसाइट

English

A website is a collection of related web pages and digital resources available under a common domain name.

हिन्दी

Website related web pages और digital resources का collection होता है, जो सामान्यतः एक common domain name के अंतर्गत उपलब्ध होता है।

Example:

A college website may contain Home, About Us, Courses, Contact, Gallery आदि अलग-अलग web pages।

📄

4. Web Page

वेब पेज

Web Page वेब पेज

English

A web page is a single document or page displayed inside a web browser.

हिन्दी

Web page एक single document/page होता है जिसे web browser के अंदर display किया जाता है।

Remember:

Website = Collection of Web Pages
Web Page = Individual Page

हिन्दी

6. Front End

Front End क्या होता है?

Front End फ्रंट एंड

English

Front End is the part of a website or application that users can directly see and interact with. Common technologies include:

HTML → Structure
CSS → Styling
JavaScript → Interaction

हिन्दी

Front End वेबसाइट का वह हिस्सा है जिसे user सीधे देखता और interact करता है। मुख्य technologies:

HTML → Structure
CSS → Design
JavaScript → Interaction

⚙️

7. Back End

Back End क्या होता है?

Back End बैक एंड

English

Back End is the server-side part of a website that handles application logic, databases, authentication and server operations.

हिन्दी

Back End वेबसाइट का server-side हिस्सा है, जो application logic, database, authentication और server operations को handle करता है।

Exam Trick:

Front End = What user sees
Back End = What works behind the screen

💻

8. Client-Side & Server-Side Scripting

Client और Server Scripting

Client-Side Scripting Server-Side Scripting
Runs mainly in the user's browser.
User के browser में execute होता है। 		Runs on the web server.
Web server पर execute होता है।
Common example: JavaScript Examples: PHP, Python, Node.js etc.
Used for user interface interaction. Used for server logic and data processing.
Usually reduces server processing for client-side tasks. Server performs processing before response.

9. Responsive Web Design

Responsive Web Design क्या है?

Responsive Web Design Responsive Web Designing

English

Responsive Web Design is an approach in which a website automatically adapts its layout and content according to the screen size and device.

हिन्दी

Responsive Web Design ऐसी technique है जिसमें website का layout और content अलग-अलग screen sizes और devices के अनुसार automatically adjust होता है।

Main Goal:

Website should work properly on:
📱 Mobile
📱 Tablet
💻 Laptop
🖥️ Desktop

📑

10. Static Website

Static Website क्या है?

Static Website स्थिर वेबसाइट

English

A static website generally displays fixed content. The content usually changes only when the website files are manually modified.

हिन्दी

Static website में content सामान्यतः fixed होता है। Content बदलने के लिए website की files को manually modify करना पड़ता है।

Examples:

Simple portfolio, basic information website, small brochure website आदि static हो सकते हैं।

🔄

11. Dynamic Website

Dynamic Website क्या है?

Dynamic Website गतिशील वेबसाइट

English

A dynamic website can generate or change content based on user interaction, data, application logic or database information.

हिन्दी

Dynamic website में content user interaction, data, application logic या database के आधार पर बदल या generate हो सकता है।

Examples:

Online shopping websites, social platforms, banking systems, portals आदि dynamic features का उपयोग कर सकते हैं।

⚖️

Static vs Dynamic Website

Exam में बहुत important comparison

Feature Static Website Dynamic Website
Content Mostly fixed Can change dynamically
Database Generally not required Often used
Interaction Limited More interactive
Maintenance Manual changes Can be managed through application/database
Complexity Usually simpler Usually more complex
