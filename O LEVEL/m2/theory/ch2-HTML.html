01

What is HTML?

HTML की basic understanding

English Explanation

HTML stands for HyperText Markup Language. It is the standard markup language used to create and structure content on web pages.

🇮🇳 हिंदी में HTML का पूरा नाम HyperText Markup Language है। इसका उपयोग web page की structure बनाने के लिए किया जाता है। HTML में headings, paragraphs, images, links, tables और forms जैसे elements बनाए जाते हैं।

HTML क्या करता है?

  • Web page की structure बनाता है
  • Text को organize करता है
  • Images और links add करता है
  • Tables और forms बनाता है
  • Browser को content structure बताता है

HTML क्या नहीं है?

  • HTML programming language नहीं है
  • HTML calculations के लिए नहीं है
  • HTML मुख्यतः markup/structure के लिए है

🎯 EXAM IMPORTANT

  • HTML = HyperText Markup Language
  • HTML is a markup language.
  • HTML is used to structure web pages.
  • HTML files normally use .html extension.
02

Basic HTML Document Structure

HTML document का basic skeleton

Basic Structure

Every HTML document normally contains a document type declaration, html element, head section and body section.

🇮🇳 हिंदी में एक basic HTML document में मुख्य रूप से DOCTYPE, html, head और body sections होते हैं।
HTML • Basic Structure 
<!DOCTYPE html>

<html>

<head>
    <title>My Web Page</title>
</head>

<body>

    <h1>Welcome</h1>

    <p>This is my web page.</p>

</body>

</html>
Part Purpose
<!DOCTYPE html> Declares HTML document type
<html> Root element
<head> Contains metadata and title
<title> Defines browser/page title
<body> Contains visible page content
03

HTML Tags & Elements

Tags और elements का concept

HTML Tag

A tag is a markup instruction enclosed within angle brackets < >.

🇮🇳 हिंदी में HTML tag angle brackets < > के अंदर लिखा जाता है। Example: <p>

HTML Element

An element generally consists of an opening tag, content and a closing tag.

Example 
<p>Hello World</p>
💡 Remember

Opening tag → Content → Closing tag

🎯 EXAM POINT

  • Opening tag example: <p>
  • Closing tag example: </p>
  • Some elements are void/empty elements.
  • Example: <br>, <img>, <hr>
04

HTML Attributes

Elements को additional information देना

What is an Attribute?

Attributes provide additional information about HTML elements.

🇮🇳 हिंदी में Attribute HTML element की additional information provide करता है। Attribute generally opening tag के अंदर लिखा जाता है।
Attribute Example 
<a href="https://example.com">
    Visit Website
</a>

<img src="photo.jpg" alt="My Photo">
Attribute Use
href Specifies link destination
src Specifies resource/image location
alt Alternative text for image
id Unique identifier
class Groups elements for styling/script
title Additional advisory information
05

HTML Headings

h1 से h6 तक headings

HTML provides six levels of headings: <h1> to <h6>.

🇮🇳 हिंदी में HTML में छह heading levels होते हैं: h1, h2, h3, h4, h5 और h6। 
<h1>Main Heading</h1>
<h2>Sub Heading</h2>
<h3>Section Heading</h3>
<h4>Heading 4</h4>
<h5>Heading 5</h5>
<h6>Heading 6</h6>

🎯 EXAM POINT

  • Highest-level heading: h1
  • Lowest-level heading: h6
  • Total heading levels = 6

HTML Hyperlinks

Web pages को connect करना

<a> Anchor Element

The anchor element is used to create hyperlinks.

🇮🇳 हिंदी में <a> tag का उपयोग एक web page, website या किसी resource का link बनाने के लिए किया जाता है। 
<a href="https://example.com">
Visit Website
</a>

New Tab 

<a
href="https://example.com"
target="_blank">

Open Website

</a>

🎯 IMPORTANT

  • <a> = Anchor element
  • href = Hypertext Reference
  • target="_blank" commonly opens the linked page in a new browsing context.

HTML Images

Web page में images add करना

<img> Element

The img element is used to embed an image in a web page.

🇮🇳 हिंदी में <img> tag का उपयोग web page में image display करने के लिए किया जाता है। 
<img
src="photo.jpg"
alt="My Photo"
width="300">
Attribute Purpose
src Image source/path
alt Alternative text
width Image width
height Image height
09

HTML Lists

Ordered, unordered और description lists

Unordered List

Uses bullets. 

<ul>

    <li>HTML</li>
    <li>CSS</li>
    <li>JavaScript</li>

</ul>

Ordered List

Uses numbers by default. 

<ol>

    <li>HTML</li>
    <li>CSS</li>
    <li>JavaScript</li>

</ol>

Description List

Used for terms and their descriptions. 

<dl>

    <dt>HTML</dt>
    <dd>Markup language</dd>

</dl>

🎯 EXAM POINT

  • <ul> = Unordered List
  • <ol> = Ordered List
  • <li> = List Item
  • <dl> = Description List
10

HTML Tables

Rows और columns में data display करना

Tables are used to present structured data in rows and columns.

🇮🇳 हिंदी में HTML table का उपयोग data को rows और columns के रूप में display करने के लिए किया जाता है। 
<table>

    <tr>

        <th>Name</th>
        <th>Marks</th>

    </tr>

    <tr>

        <td>Rahul</td>
        <td>85</td>

    </tr>

</table>
Tag Meaning
<table> Creates table
<tr> Table row
<th> Table header cell
<td> Table data cell
<caption> Table caption

HTML Forms

User input collect करना

HTML forms are used to collect information from users.

🇮🇳 हिंदी में Form का उपयोग user से information/input लेने के लिए किया जाता है। जैसे name, email, password, gender, choices आदि। 
<form>

    <label>Name:</label>

    <input
    type="text"
    name="name">

    <br><br>

    <label>Email:</label>

    <input
    type="email"
    name="email">

    <br><br>

    <input
    type="submit"
    value="Submit">

</form>
Control Use
text Single-line text
email Email input
password Password input
radio Select one option
checkbox Select multiple choices
submit Submit form
reset Reset form values
12

Block & Inline Elements

Layout behaviour समझें

Block Elements

Block elements generally start on a new line and take available horizontal space.

हिंदी Block element सामान्यतः नई line से शुरू होता है।

Examples: div, p, h1, section

Inline Elements

Inline elements generally flow within the current line.

हिंदी Inline element सामान्यतः उसी line में content के साथ रहता है।

Examples: span, a, strong

13

Semantic HTML

Meaningful HTML structure

What is Semantic HTML?

Semantic elements clearly describe the meaning and purpose of their content.

🇮🇳 हिंदी में Semantic HTML elements अपने content का meaning/purpose clearly बताते हैं। इससे document की structure अधिक meaningful और understandable बनती है।
Element Purpose
<header> Introductory/header content
<nav> Navigation links
<main> Main page content
<section> Thematic section
<article> Independent content
<aside> Related/sidebar content
<footer> Footer information 
<header>

    <h1>My Website</h1>

</header>

<nav>

    <a href="#">Home</a>
    <a href="#">About</a>

</nav>

<main>

    <section>

        <h2>About Us</h2>

        <p>Website content...</p>

    </section>

</main>

<footer>

    Copyright 2026

</footer>
