1. Web Graphics

वेब ग्राफिक्स का परिचय

Definition / परिभाषा

Web Graphics refers to visual content such as images, icons, illustrations, diagrams and other graphical elements used on websites.

Web Graphics का अर्थ ऐसी graphical सामग्री से है जिसे websites पर information देने या website को visually attractive बनाने के लिए प्रयोग किया जाता है।

2. Digital Images

Digital Image और Pixel को समझें

What is a Digital Image?

A digital image is an image represented electronically using numerical data.

Digital Image एक electronic image होती है जिसे computer numerical data के रूप में store और process करता है।

Pixel

Pixel stands for Picture Element. It is the smallest addressable element of a digital image.

Pixel का अर्थ Picture Element है। यह digital image का सबसे छोटा individual element माना जाता है।

More pixels generally allow an image to represent more detail, although image quality also depends on other factors such as source, compression and display characteristics.
🔲

3. Raster vs Vector Graphics

दोनों graphics के बीच अंतर

🟦

Raster Graphics

Raster graphics are made from pixels.

Examples: JPEG, PNG, GIF, WebP.

Raster image pixels से बनी होती है। इसे बहुत अधिक enlarge करने पर pixelation दिखाई दे सकती है।

🔷

Vector Graphics

Vector graphics are based on mathematical paths, shapes and curves.

Example: SVG.

Vector graphics mathematical paths और shapes पर आधारित होती हैं। इन्हें अलग-अलग sizes में scale करना सामान्यतः अधिक flexible होता है।

Raster vs Vector — Quick Comparison

Feature Raster Vector
Basic Unit Pixels Paths / Shapes
Examples JPEG, PNG, GIF, WebP SVG
Scaling May lose quality when enlarged Usually scales cleanly
Best For Photographs and detailed images Logos, icons, diagrams

4. Image Formats

Important image file formats

JPEG / JPG

JPEG is widely used for photographs and complex images. It uses lossy compression.

JPEG photographs के लिए commonly used format है। इसमें lossy compression का उपयोग किया जाता है।

PNG

PNG supports lossless compression and transparency.

PNG lossless compression और transparency support करता है।

GIF

GIF supports simple animations and a limited color palette.

GIF छोटे animations के लिए उपयोग किया जा सकता है और इसकी color palette सीमित होती है।

SVG

SVG is a vector-based format commonly used for scalable graphics.

SVG vector-based format है और logos, icons तथा diagrams के लिए useful है।

WebP

WebP is a modern image format designed to provide efficient compression for web images.

WebP web images के लिए efficient compression देने वाला modern format है।

AVIF

AVIF is a modern image format that can provide strong compression and high image quality.

AVIF एक modern image format है जो अच्छी compression efficiency और image quality प्रदान कर सकता है।

5. HTML Image Element

Website में image कैसे लगाएँ?

<img> Element

The HTML <img> element is used to embed an image in a web page.

HTML में <img> element का उपयोग webpage के अंदर image दिखाने के लिए किया जाता है। 

<img src="student.jpg" alt="Student studying">

Important Attributes

  • src — image का path/location बताता है।
  • alt — image का alternative text देता है।
  • width — image की width निर्धारित कर सकता है।
  • height — image की height निर्धारित कर सकता है।
<img
    src="computer.jpg"
    alt="Computer system"
    width="500"
    height="300"
>
💡 Exam Tip

ALT attribute accessibility के लिए important है और जब image load नहीं होती तो उसका alternative description उपलब्ध करा सकता है।

🎨

6. SVG Graphics

Scalable Vector Graphics

What is SVG?

SVG stands for Scalable Vector Graphics. It is an XML-based format for describing two-dimensional vector graphics.

SVG का पूरा नाम Scalable Vector Graphics है। यह two-dimensional vector graphics को describe करने के लिए XML-based format है। 

<svg width="200" height="120"
     xmlns="http://www.w3.org/2000/svg">

    <circle
        cx="100"
        cy="60"
        r="40"
        fill="skyblue"
    />

</svg>

SVG Uses

  • Logos
  • Icons
  • Charts
  • Diagrams
  • Scalable illustrations

7. Web Audio

Website में Audio का उपयोग

HTML5 Audio

The HTML <audio> element is used to embed sound content in a webpage.

HTML5 में <audio> element का उपयोग webpage में audio content embed करने के लिए किया जाता है। 

<audio controls>
    <source src="music.mp3" type="audio/mpeg">
    Your browser does not support audio.
</audio>

Important Audio Attribute

  • controls — audio controls दिखाता है।
  • autoplay — browser policies के अधीन audio automatically play करने का प्रयास करता है।
  • loop — audio को repeat करने के लिए उपयोग होता है।
  • muted — audio को initially muted कर सकता है।
Exam: <audio> is an HTML5 element used to embed sound content.
🎬

8. Web Video

Website में Video का उपयोग

HTML5 Video

The HTML <video> element is used to embed video content in a webpage.

HTML5 में <video> element का उपयोग webpage के अंदर video content embed करने के लिए किया जाता है। 

<video width="640" controls>

    <source
        src="lesson.mp4"
        type="video/mp4"
    >

    Your browser does not support video.

</video>

Important Video Attributes

  • controls — video controls display करता है।
  • width — video की width निर्धारित कर सकता है।
  • height — video की height निर्धारित कर सकता है।
  • poster — video शुरू होने से पहले preview image दे सकता है।
  • loop — video को repeat करने के लिए।
  • muted — video को initially muted रखने के लिए।

10. Image Optimization

Website performance के लिए जरूरी

Why Optimize Images?

Large image files can increase page loading time and consume more bandwidth. Proper optimization can improve website performance.

बहुत बड़ी image files webpage की loading को slow कर सकती हैं और अधिक bandwidth consume कर सकती हैं। इसलिए images को properly optimize करना useful है।

Common Techniques

  • Appropriate image dimensions का उपयोग करें।
  • Suitable image format choose करें।
  • Unnecessary metadata remove किया जा सकता है।
  • Compression techniques का उपयोग करें।
  • Modern formats जैसे WebP/AVIF कई cases में useful हो सकते हैं।
  • Responsive images के लिए suitable techniques use करें।

11. Accessibility

Accessible Multimedia & Images

Why Accessibility Matters?

Web content should be usable by as many people as possible, including users who rely on assistive technologies.

Website का content अधिक से अधिक users के लिए accessible होना चाहिए, जिसमें assistive technologies का उपयोग करने वाले users भी शामिल हैं।

Important Practices

  • Images के लिए meaningful ALT text दें।
  • Decorative images के लिए appropriate empty alt इस्तेमाल किया जा सकता है।
  • Video के लिए captions उपलब्ध कराना helpful है।
  • Audio-only content के लिए text alternative useful है।
  • Multimedia controls keyboard और assistive technology users के लिए usable होने चाहिए।
