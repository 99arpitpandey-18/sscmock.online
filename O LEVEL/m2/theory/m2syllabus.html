Web Publishing & Browsing

Website को Internet पर Publish करना

Web Hosting

Web hosting is a service that makes website files available on the Internet. The website files are stored on a web server.

🚀 PICTURE METHOD — Website Publishing
💻 Website Files HTML/CSS/JS
→
☁️ Web Hosting Server
→
🌐 Domain Website Address
→
👨‍💻 Visitor Browser

SGML

SGML stands for Standard Generalized Markup Language. It is a standard for defining markup languages.

HTML

HTML is used to create and structure web documents.

CGI

CGI stands for Common Gateway Interface. It is a mechanism that allows web servers to interact with external programs.

Web Browser

A web browser is software used to access and display web pages. Examples include Chrome, Edge, Firefox and Opera.

Search Engine

A search engine helps users find information on the Internet using keywords.

Meta Search Engine

A meta search engine gathers search results from multiple search engines or sources.

HTTP

HTTP stands for HyperText Transfer Protocol. It is a protocol used for communication between web clients and web servers.

Important Exam Questions

Frequently Asked Concepts
HTML का full form क्या है?

HTML = HyperText Markup Language.

CSS का उपयोग किस लिए किया जाता है?

CSS का उपयोग HTML elements की styling, layout, colour, fonts और presentation के लिए किया जाता है।

JavaScript किस प्रकार की language है?

JavaScript को commonly client-side scripting language के रूप में पढ़ाया जाता है।

W3.CSS क्या है?

W3.CSS एक CSS framework है जिसमें predefined classes उपलब्ध होती हैं।

Responsive Web Design क्या है?

ऐसी web design जो अलग-अलग screen sizes जैसे desktop, tablet और mobile के अनुसार adapt हो जाए।

Static और Dynamic Website में difference?

Static website में content सामान्यतः fixed होता है, जबकि dynamic website में content user input, server logic या database के अनुसार बदल सकता है।

HTTP का full form क्या है?

HTTP = HyperText Transfer Protocol.

Web Hosting क्या है?

Web hosting वह service है जिसके माध्यम से website की files web server पर रखी जाती हैं ताकि Internet पर access की जा सकें।

Front End क्या होता है?

Website का वह हिस्सा जो user browser में देखता और interact करता है, Front End कहलाता है।

Back End क्या होता है?

Website का server-side हिस्सा जो processing, application logic और data handling करता है, Back End कहलाता है।
