Chapter 1

Introduction to Web & Internet

Internet इंटरनेट is a global network of interconnected computer networks. It allows computers and devices to communicate and exchange information.

Internet vs Web

Internet World Wide Web
Global network infrastructure. Collection of interlinked web resources accessed through the Internet.
Supports many services such as email, file transfer and web. Mainly consists of websites and web pages.

Important Internet Terms

  • Website — Collection of related web pages.
  • Web Page — Individual document displayed by a browser.
  • Homepage — Main or entry page of a website.
  • URL — Uniform Resource Locator.
  • Domain Name — Human-readable name used to identify a website.
  • IP Address — Numerical network address.
  • Browser — Software used to access web resources.
Exam Point: Internet aur WWW same nahi hain. WWW is a service/resource system that operates over the Internet.

Common Internet Services

  • World Wide Web
  • Email
  • File Transfer
  • Remote access
  • Online communication
  • Cloud-based services

Chapter 2

Web Browsers, Servers & Hosting

Web Browser

A web browser वेब ब्राउज़र is software used to request, receive and display web resources.

Examples of Browsers

  • Google Chrome
  • Mozilla Firefox
  • Microsoft Edge
  • Safari
  • Opera

Web Server

A web server stores or accesses web resources and responds to requests from clients.

Client and Server

Client Server
Requests a resource/service. Provides the requested resource/service.
Example: Web browser. Example: Web server.

Web Hosting

Web hosting is a service through which website files are stored on servers and made accessible over a network/Internet.

Domain Name

A domain name is an easy-to-remember name used instead of a numerical IP address.

Example: example.com is easier for humans to remember than a numerical IP address.

DNS

DNS — Domain Name System maps domain names to IP addresses.

HTTP and HTTPS

Protocol Meaning Purpose
HTTP HyperText Transfer Protocol Transfer web resources.
HTTPS HTTP Secure HTTP communication over a secure encrypted connection.
Remember: DNS → Domain Name System
HTTP → HyperText Transfer Protocol
HTTPS → Secure HTTP communication

Chapter 6

CSS Fundamentals

CSS Cascading Style Sheets is used to control the presentation and visual styling of web pages.

Three Ways to Apply CSS

Type Example
Inline CSS style attribute inside an HTML element.
Internal CSS <style> element inside the document.
External CSS Separate .css file linked with <link>.

CSS Syntax

p{
    color: blue;
    font-size: 18px;
}

Here p is the selector, color and font-size are properties, and their assigned values are blue and 18px.

Important Selectors

/* Element selector */
p{
    color:blue;
}

/* Class selector */
.box{
    padding:20px;
}

/* ID selector */
#header{
    background:black;
}

/* Universal selector */
*{
    box-sizing:border-box;
}

Common CSS Properties

  • color
  • background-color
  • font-size
  • font-family
  • font-weight
  • text-align
  • width
  • height
  • margin
  • padding
  • border

Box Model

CSS box model consists of:

  • Content
  • Padding
  • Border
  • Margin
Remember: Content → Padding → Border → Margin

Chapter 7

CSS Layout & Responsive Design

Display Property

  • block — block-level layout behavior.
  • inline — inline-level behavior.
  • inline-block — inline placement with box dimensions.
  • none — element is not displayed.
  • flex — creates a flex container.
  • grid — creates a grid container.

Flexbox

.container{

    display:flex;

    justify-content:center;

    align-items:center;

    gap:20px;

}

CSS Grid

.container{

    display:grid;

    grid-template-columns:
        repeat(3, 1fr);

    gap:20px;

}

Responsive Web Design

Responsive design means a webpage adapts its layout and content to different screen sizes and devices.

Media Query

@media(max-width:600px){

    .container{
        grid-template-columns:1fr;
    }

}
Exam Point: Responsive design improves usability across desktop, tablet and mobile screen sizes.

Mobile-First Approach

Mobile-first design begins with styles for smaller screens and progressively enhances the layout for larger screens.

Chapter 9

DOM, Events & Validation

DOM

DOM — Document Object Model represents the structure of an HTML document as objects that scripts can access and manipulate.

Selecting Elements

document.getElementById("title");

document.querySelector(".box");

document.querySelectorAll(".item");

Changing Content

document.getElementById("title")
        .textContent = "New Title";

Events

An event is an action or occurrence detected by the browser.

  • click
  • input
  • change
  • submit
  • mouseover
  • keydown
  • load

Event Listener

button.addEventListener(
    "click",
    function(){

        alert("Button clicked");

    }
);

Form Validation

Validation checks whether user input satisfies required rules before it is processed. 

function validate(){

    let name =
        document.getElementById("name").value;

    if(name.trim() === ""){

        alert("Name is required");

        return false;
    }

    return true;
}
Important: Client-side JavaScript validation should not be treated as the only security control because users can bypass browser-side code.

Chapter 11

Web Design Principles

UI — User Interface

UI is the visual and interactive interface through which users interact with a website or application.

UX — User Experience

UX refers to the overall experience users have while interacting with a product or website.

Important Design Principles

  • Consistency — keep similar elements and interactions consistent.
  • Hierarchy — make important content visually prominent.
  • Contrast — distinguish important elements clearly.
  • Whitespace — use empty space to improve readability.
  • Alignment — organize content along visual lines.
  • Typography — select and arrange text appropriately.
  • Accessibility — design so people with different abilities can use the site.
  • Usability — make tasks easy to understand and perform.

Navigation

Good navigation helps users understand where they are and move between important sections efficiently.

Accessibility Basics

  • Use meaningful alt text for informative images.
  • Maintain readable text and sufficient contrast.
  • Use headings in logical order.
  • Make interactive controls keyboard accessible where appropriate.
  • Use descriptive link text.

SEO Basics

SEO — Search Engine Optimization is the practice of improving the discoverability and presentation of web content in search engines.

  • Meaningful page titles.
  • Useful content.
  • Logical heading structure.
  • Descriptive URLs.
  • Relevant metadata.
  • Good performance and mobile usability.

Chapter 12

Angular JS / Web Framework Concepts

Modern web development often uses frameworks and libraries to structure applications and make development more manageable.

Framework

A framework provides an organized structure, tools and conventions for building applications.

Angular

Angular is a web application framework associated with TypeScript-based development.

Important Concepts

  • Component — reusable building block of an application UI.
  • Template — defines the view/UI associated with a component.
  • Data Binding — connects application data and UI.
  • Directive — adds behavior or structure to elements.
  • Service — reusable logic/data functionality.
  • Routing — navigation between views.
  • Module — organizational unit for application code.

Single Page Application

SPA stands for Single Page Application. A SPA can update parts of the interface without requiring a complete page reload for every navigation action.

Exam Focus: Framework concepts such as components, templates, directives, services, data binding and routing are important terminology.

Web Publishing

Web publishing means preparing and making website resources available through a web server.

Typical Publishing Process

  • Plan website structure.
  • Create HTML/CSS/JavaScript files.
  • Create and optimize media resources.
  • Test website locally.
  • Obtain domain and hosting where required.
  • Upload website files.
  • Configure required server settings.
  • Test the published website.
  • Maintain and update the website.

FTP

FTP — File Transfer Protocol is a protocol historically used for transferring files between systems.

Common Website Files

File Purpose
index.html Common default/entry HTML file.
style.css CSS stylesheet.
script.js JavaScript file.
images/ Directory for image resources.

Localhost

localhost refers to the local computer/system when accessing a locally running web service.

Website Maintenance

  • Update content.
  • Fix broken links.
  • Keep software/dependencies updated where applicable.
  • Review performance.
  • Maintain backups.
  • Monitor security.
Remember: Publishing is not the end of web development. Regular maintenance is required for a useful and secure website.

Chapter 14

Web Security & Best Practices

HTTPS

HTTPS provides encrypted communication between a browser and a web server when properly configured.

Strong Web Practices

  • Use HTTPS for web communication where appropriate.
  • Validate user input.
  • Escape or safely handle untrusted content.
  • Keep software and dependencies updated.
  • Use secure authentication practices.
  • Avoid exposing sensitive information in client-side code.
  • Keep reliable backups.

Common Web Risks

Risk Basic Idea
XSS Untrusted content/script can execute in a user's browser when improperly handled.
Injection Untrusted input is interpreted as commands or queries.
Weak Authentication Inadequate authentication can allow unauthorized access.
Insecure Transport Unencrypted communication can expose data to interception.

Accessibility and Security

A good website should consider both usability/accessibility and security rather than focusing on appearance alone.

Important: Never place passwords, secret keys or other sensitive credentials inside publicly accessible HTML or JavaScript files.

📌 Important Questions — Chapter 14

Q1. Why is HTTPS important?

It provides encrypted web communication when properly configured.

Q2. What is input validation?

Checking whether supplied input meets expected rules.

Q3. What is XSS?

Cross-Site Scripting is a class of vulnerability involving unsafe handling of untrusted content in web pages.
