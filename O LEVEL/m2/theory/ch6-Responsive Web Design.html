Responsive Web Design

Responsive Web Design — उत्तरदायी वेब डिजाइन

Learn how to design websites that automatically adjust their layout, size, images and content according to different screen sizes such as mobile phones, tablets, laptops and desktops.

1. What is Responsive Web Design?

Responsive design का basic concept

English

Responsive Web Design (RWD) is an approach to web development in which a website automatically adapts its layout and content according to the screen size, resolution and orientation of the device being used.

हिन्दी

Responsive Web Design एक ऐसी तकनीक है जिसमें website का layout और content user के device की screen के अनुसार automatically adjust होता है।

💡 Exam Point

Responsive website का main objective है — different screen sizes पर बेहतर user experience देना।

📱

Responsive websites की आवश्यकता क्यों है?

आज की अधिकांश websites responsive approach का उपयोग करती हैं।

Accessibility

Content को विभिन्न screen sizes पर आसानी से access किया जा सकता है।

3. Responsive vs Non-Responsive

Difference समझें

Responsive Website Non-Responsive Website
Screen size के अनुसार layout बदलता है। Layout generally fixed हो सकता है।
Mobile पर आसानी से usable होती है। Mobile पर horizontal scrolling हो सकती है।
Flexible images और layouts इस्तेमाल होते हैं। Fixed dimensions ज्यादा common होते हैं।
CSS media queries का उपयोग हो सकता है। Media queries जरूरी नहीं होतीं।
🔭

4. Viewport

Responsive design का important concept

English

The viewport is the visible area of a web page on the user's device screen.

For responsive websites, the viewport meta tag is commonly placed inside the HTML head section.

हिन्दी

Viewport browser window का वह visible area है जिसमें webpage दिखाई देता है।

Responsive websites में viewport meta tag बहुत important है। 

<meta name="viewport"
content="width=device-width, initial-scale=1.0">
🎯 याद रखें

width=device-width → viewport की width को device की width के बराबर करता है।
initial-scale=1.0 → initial zoom level निर्धारित करता है।

📐

5. Flexible Layout

Fixed और flexible dimensions

English

Responsive layouts generally use flexible units such as percentage, em, rem, vw and vh instead of relying only on fixed pixel dimensions.

हिन्दी

Responsive layout में केवल fixed px values पर निर्भर रहने के बजाय %, em, rem, vw और vh जैसी flexible units का उपयोग किया जा सकता है। 

.container{
    width:90%;
    max-width:1200px;
    margin:auto;
}

img{
    max-width:100%;
    height:auto;
}
📱

6. Media Queries

Responsive CSS का सबसे important topic

English

CSS media queries allow developers to apply different CSS rules depending on conditions such as viewport width, height, orientation and other device characteristics.

हिन्दी

Media Query CSS की ऐसी technique है जिससे हम अलग-अलग screen sizes के लिए अलग CSS rules apply कर सकते हैं। 

@media (max-width: 768px){

    .container{
        width:95%;
    }

    .cards{
        grid-template-columns:1fr;
    }

    h1{
        font-size:28px;
    }

}
🔥 Exam Trick

max-width → दी गई width से छोटी या बराबर screen पर rules लागू।
min-width → दी गई width से बड़ी या बराबर screen पर rules लागू।

🧱

7. Flexbox in Responsive Design

Flexible one-dimensional layout

English

CSS Flexbox is a layout model designed for arranging elements in a row or column and distributing available space efficiently.

हिन्दी

Flexbox एक CSS layout system है जिसका उपयोग elements को row या column में flexible तरीके से arrange करने के लिए किया जाता है। 

.container{
    display:flex;
    flex-wrap:wrap;
    gap:20px;
}

.card{
    flex:1 1 250px;
}
  • display:flex
  • flex-direction
  • justify-content
  • align-items
  • flex-wrap
  • gap
▦

8. CSS Grid

Two-dimensional responsive layout

English

CSS Grid is a two-dimensional layout system that allows developers to create rows and columns.

हिन्दी

CSS Grid एक two-dimensional layout system है जिसमें rows और columns दोनों को आसानी से control किया जा सकता है। 

.cards{
    display:grid;
    grid-template-columns:
    repeat(3,1fr);
    gap:20px;
}

@media(max-width:768px){

    .cards{
        grid-template-columns:1fr;
    }

}
🖼️

9. Responsive Images

Images को responsive कैसे बनाएं?

Important CSS

img{
    max-width:100%;
    height:auto;
}

max-width:100% image को उसके parent container से बड़ा होने से रोकता है।

height:auto image का aspect ratio maintain करने में मदद करता है।

11. Mobile First Design

Mobile-first approach

English

Mobile-first design means designing the basic experience for small screens first and then enhancing the layout for larger screens using media queries.

हिन्दी

Mobile-first approach में सबसे पहले छोटे screen size यानी mobile के लिए design बनाया जाता है। इसके बाद बड़ी screens के लिए media queries द्वारा layout enhance किया जाता है। 

.card{
    width:100%;
}

/* Larger screens */

@media(min-width:768px){

    .card{
        width:48%;
    }

}

13. Complete Responsive Example

HTML + CSS practical

<!DOCTYPE html>
<html>

<head>

<meta name="viewport"
content="width=device-width, initial-scale=1.0">

<style>

body{
    font-family:Arial;
    margin:0;
}

.container{
    width:90%;
    max-width:1100px;
    margin:auto;
}

.cards{
    display:grid;
    grid-template-columns:
    repeat(3,1fr);
    gap:20px;
}

.card{
    padding:20px;
    border:1px solid #ddd;
}

img{
    max-width:100%;
    height:auto;
}

@media(max-width:768px){

    .cards{
        grid-template-columns:1fr;
    }

}

</style>

</head>

<body>

<div class="container">

    <h1>Responsive Website</h1>

    <div class="cards">

        <div class="card">Card 1</div>
        <div class="card">Card 2</div>
        <div class="card">Card 3</div>

    </div>

</div>

</body>
</html>

14. Common Responsive Design Problems

Important mistakes

  • Viewport meta tag भूल जाना
  • बहुत ज्यादा fixed width का उपयोग करना
  • Images को responsive न बनाना
  • Mobile screen पर horizontal scrolling आने देना
  • Text का बहुत छोटा होना
  • Buttons को बहुत छोटा रखना
  • केवल desktop पर website test करना
