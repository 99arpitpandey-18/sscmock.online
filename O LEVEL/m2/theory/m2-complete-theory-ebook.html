01

Introduction to Web Designing

Internet, Web, Website, Web Page, Browser, Server, URL, HTTP/HTTPS, Domain Name and basic web architecture.

What is Internet? इंटरनेट क्या है?

The Internet is a worldwide network of interconnected computers and devices that communicate using standard communication protocols.

इंटरनेट दुनिया भर के computers और devices का interconnected network है जो communication protocols की सहायता से आपस में data का आदान-प्रदान करता है।

  • Internet is a global network.
  • It connects computers, servers and smart devices.
  • TCP/IP is the fundamental protocol suite.
  • It provides services such as Web, Email and FTP.

What is World Wide Web? World Wide Web क्या है?

The World Wide Web is a system of interconnected web documents and resources accessed through the Internet.

World Wide Web इंटरनेट पर उपलब्ध interconnected web pages और resources की system है।

  • WWW uses web browsers.
  • Web pages are commonly accessed using HTTP/HTTPS.
  • Websites contain one or more web pages.

Website vs Web Page Website और Web Page में अंतर

Website Web Page
Collection of related web pages. Single document/page.
Usually has a domain name. Usually has a specific URL.
Example: educational website. Example: About Us page.

Web Browser Web Browser क्या है?

A web browser is software used to access, retrieve and display information from websites.

Web browser एक software application है जिसका उपयोग websites को खोलने और web content को display करने के लिए किया जाता है।

  • Google Chrome
  • Microsoft Edge
  • Mozilla Firefox
  • Safari

Web Server Web Server क्या है?

A web server stores web resources and responds to requests from clients such as browsers.

Web server web files/resources को store करता है और browser जैसे clients की requests का response देता है।

  • Client sends request.
  • Server processes request.
  • Server sends response.
  • Browser displays the result.

URL Uniform Resource Locator

A URL identifies the location of a resource on the Web.

URL web पर किसी resource की location/address को identify करता है। 

https://www.example.com/about.html
  • https → Protocol
  • www.example.com → Domain
  • /about.html → Resource/path

HTTP and HTTPS HTTP तथा HTTPS

HTTP stands for HyperText Transfer Protocol. It is used for communication between web clients and servers. HTTPS is the secure version of HTTP and uses encryption through TLS.

HTTP का पूरा नाम HyperText Transfer Protocol है। इसका उपयोग browser और server के बीच communication के लिए होता है। HTTPS इसका secure version है जिसमें communication encrypted होता है।

⭐ EXAM POINT

HTTPS में S का अर्थ Secure होता है। HTTPS web communication को अधिक सुरक्षित बनाने के लिए encryption का उपयोग करता है।

⚡ Chapter 1 Quick Revision

Internet = Global network
WWW = Web resources system
Browser = Web content access software
Server = Provides requested resources
URL = Web resource address
HTTPS = Secure HTTP

HTML – HyperText Markup Language

HTML document structure, elements, tags, attributes, headings, paragraphs, links, images, lists, tables, forms and semantic HTML.

What is HTML? HTML क्या है?

HTML stands for HyperText Markup Language. It is the standard markup language used to structure content on web pages.

HTML का पूरा नाम HyperText Markup Language है। इसका उपयोग web page के content और structure को define करने के लिए किया जाता है।

⭐ EXAM POINT

HTML is a markup language, not a programming language.

HTML Document Structure HTML document का basic structure 

<!DOCTYPE html>
<html>
<head>
    <title>My Page</title>
</head>
<body>
    <h1>Hello World</h1>
</body>
</html>

HTML Tags and Elements Tags और Elements

A tag is written using angle brackets. An element generally contains an opening tag, content and closing tag.

Tag angle brackets में लिखा जाता है। Element में सामान्यतः opening tag, content और closing tag होते हैं। 

<p>This is a paragraph.</p>

Attributes Attributes क्या होते हैं?

Attributes provide additional information about HTML elements.

Attributes HTML elements को additional information प्रदान करते हैं। 

<a href="https://example.com">
Visit Website
</a>
  • href is an attribute.
  • src is commonly used for image source.
  • alt provides alternative text for images.
  • id uniquely identifies an element.

Headings and Paragraphs Headings एवं Paragraphs 

<h1>Main Heading</h1>
<h2>Sub Heading</h2>
<h3>Small Heading</h3>

<p>This is a paragraph.</p>

HTML में h1 से h6 तक heading levels उपलब्ध होते हैं।

Hyperlinks Hyperlink / Link

The anchor element is used to create hyperlinks.

Anchor element का उपयोग hyperlink बनाने के लिए किया जाता है। 

<a href="page2.html">
Open Page 2
</a>

Lists Lists के प्रकार

HTML mainly provides ordered, unordered and description lists.

Images Images जोड़ना

src image का path बताता है और alt image के alternative text को define करता है।

HTML Tables HTML Table 

<table>

    <th>Name</th>
    <th>Marks</th>
</tr>

    <td>Rahul</td>
    <td>85</td>

  • tr → Table Row
  • th → Table Heading

HTML Forms Forms का उपयोग

Forms collect information from users and submit it for processing.

Forms का उपयोग users से information collect करने के लिए किया जाता है।

Semantic HTML Semantic Elements

Semantic elements clearly describe the meaning of their content.

Semantic elements अपने content का meaning clearly बताते हैं।

  • <header> → Header section
  • <nav> → Navigation
  • <main> → Main content
  • <section> → Section
  • <article> → Independent article
  • <aside> → Side content
  • <footer> → Footer

CSS – Cascading Style Sheets

Selectors, colors, fonts, backgrounds, borders, box model, positioning, display, Flexbox, Grid and CSS organization.

What is CSS? CSS क्या है?

CSS stands for Cascading Style Sheets. It is used to control the presentation and visual appearance of HTML documents.

CSS का पूरा नाम Cascading Style Sheets है। इसका उपयोग HTML elements की styling और presentation को control करने के लिए होता है।

Types of CSS CSS के प्रकार

  • Inline CSS
  • Internal CSS
  • External CSS
<p style="color:red">
Inline CSS
</p>

Large websites के लिए external CSS generally अधिक maintainable होती है।

CSS Selectors Selectors 

p{
    color:blue;
}

.box{
    padding:20px;
}

#title{
    font-size:30px;
}
  • Element selector
  • Class selector
  • ID selector
  • Universal selector
  • Attribute selector

Colors Colors 

color:red;

color:#00d9ff;

color:rgb(0,217,255);

background-color:#111827;

Box Model CSS Box Model

Every HTML element can be considered as a box consisting of content, padding, border and margin.

CSS box model में मुख्य रूप से Content, Padding, Border और Margin शामिल होते हैं।

  • Content
  • Padding
  • Border
  • Margin

Display Property Display 

display:block;

display:inline;

display:inline-block;

display:flex;

display:grid;

display:none;

Flexbox Flexible Box Layout 

.container{
    display:flex;
    justify-content:center;
    align-items:center;
    gap:20px;
}

Flexbox एक dimensional layout system है जिसका उपयोग items को row या column में arrange करने के लिए किया जाता है।

CSS Grid Grid Layout 

.grid{
    display:grid;
    grid-template-columns:
    repeat(3,1fr);
    gap:20px;
}

CSS Grid दो-dimensional layouts बनाने के लिए useful है।

Positioning CSS Position Property 

position:static;

position:relative;

position:absolute;

position:fixed;

position:sticky;
⭐ EXAM POINT

position:fixed element viewport के relative positioned रहता है, जबकि sticky element scrolling के दौरान specified threshold तक normal flow में behave करता है।

JavaScript & Client-Side Scripting

JavaScript basics, variables, data types, operators, conditions, loops, functions, arrays, events and DOM.

What is JavaScript? JavaScript क्या है?

JavaScript is a programming language widely used to add logic, interaction and dynamic behavior to web pages.

JavaScript एक programming language है जिसका उपयोग web pages में logic, interaction और dynamic behavior जोड़ने के लिए किया जाता है।

Variables Variables 

let name = "Rahul";

const age = 20;

var city = "Agra";

Variable data को temporarily store करने के लिए उपयोग किया जाता है। Modern JavaScript में let और const commonly preferred हैं।

Data Types Data Types

  • String

Loop का उपयोग किसी task को repeatedly execute करने के लिए किया जाता है।

Functions Functions

DOM – Document Object Model DOM क्या है?

The DOM represents an HTML document as a structured tree of objects. JavaScript can use the DOM to access and modify elements.

DOM HTML document को objects के structured tree के रूप में represent करता है। JavaScript DOM की सहायता से HTML elements को access और modify कर सकता है। 

document.getElementById("title");

document.querySelector(".box");

document.getElementById("title")
.innerText = "New Heading";
⭐ EXAM POINT

DOM = Document Object Model. JavaScript और HTML के बीच interaction समझने के लिए DOM बहुत important concept है।

Web Graphics & Multimedia

Images, image formats, SVG, audio, video, multimedia elements, optimization and accessibility basics.

Web Graphics Web Graphics क्या हैं?

Web graphics are visual elements used to communicate information and improve the appearance of web pages.

Web graphics websites पर information को visually present करने और design को attractive बनाने के लिए उपयोग किए जाते हैं।

Raster vs Vector Raster और Vector Graphics

Raster Vector
Pixel based. Mathematical paths based.
Photographs are commonly raster. Logos/icons often use vector.
Scaling may reduce quality. Can scale without the same pixelation issue.

Common Image Formats Image Formats

  • JPEG / JPG → Photographs
  • PNG → Transparency support
  • GIF → Simple animations
  • SVG → Vector graphics
  • WebP → Modern web image format

SVG Scalable Vector Graphics

SVG is an XML-based vector graphics format suitable for scalable icons, diagrams and illustrations.

SVG एक vector graphics format है जिसे scalable graphics, icons और diagrams के लिए उपयोग किया जा सकता है।

Audio Web Audio 

<audio controls>

<source
src="music.mp3"
type="audio/mpeg">

Your browser does not support audio.

</audio>

Video Web Video 

<video
controls
width="500">

<source
src="video.mp4"
type="video/mp4">

</video>

Multimedia Optimization Multimedia Optimization क्यों?

  • Compress large images.
  • Use suitable image formats.
  • Use responsive image dimensions.
  • Avoid unnecessarily large media files.
  • Provide alternative text for meaningful images.
  • Provide captions/transcripts where appropriate.
💡 STUDY TIP

Better optimized multimedia improves page loading performance and can provide a better user experience.

Responsive Web Design

Mobile-friendly websites, viewport, media queries, flexible layouts, Flexbox, Grid and responsive design principles.

What is Responsive Web Design? Responsive Web Design क्या है?

Responsive Web Design is an approach in which a website adapts its layout and content to different screen sizes and devices.

Responsive Web Design में website का layout और content अलग-अलग screen sizes और devices के अनुसार adapt होता है।

Viewport Viewport Meta Tag 

<meta
name="viewport"
content="width=device-width,
initial-scale=1.0">

यह mobile browsers को page की width और initial scaling के बारे में information देता है।

Media Query Media Queries 

@media(max-width:700px){

    .container{
        grid-template-columns:1fr;
    }

}

Media queries screen conditions के आधार पर अलग CSS rules apply करने की सुविधा देती हैं।

Responsive Units Flexible Units

  • % → Relative percentage
  • em → Relative to font size
  • rem → Relative to root font size
  • vw → Viewport width
  • vh → Viewport height

Mobile First Design Mobile First Approach

Mobile-first design starts with the smaller screen layout and progressively enhances it for larger screens.

Mobile-first approach में पहले छोटे screens के लिए design तैयार किया जाता है और फिर larger screens के लिए enhance किया जाता है।

Responsive Flexbox Flexible Layout 

.cards{
    display:flex;
    flex-wrap:wrap;
    gap:20px;
}

.card{
    flex:1 1 250px;
}

Responsive Design Principles Important Principles

  • Use flexible layouts.
  • Use responsive images.
  • Use media queries.
  • Make navigation usable on small screens.
  • Keep text readable.
  • Avoid unnecessary horizontal scrolling.
  • Test websites on different screen sizes.

🎯 Chapter 6 Exam Focus

  • Responsive Web Design definition.
  • Viewport meta tag.
  • Media Query syntax.
  • Mobile-first approach.
  • Responsive units.
  • Flexbox and Grid.

Web Hosting & Publishing

Domain names, DNS, hosting, servers, FTP, file management, uploading websites and publishing websites.

What is Web Hosting? Web Hosting क्या है?

Web hosting is a service that provides storage and server resources for making website files accessible over the Internet.

Web hosting ऐसी service है जो website files को server पर store करके Internet के माध्यम से users तक उपलब्ध कराती है।

Domain Name Domain Name क्या है?

A domain name is a human-readable name used to identify a website on the Internet.

Domain name website की पहचान के लिए उपयोग किया जाने वाला human-readable address/name है।

Example: example.com

DNS Domain Name System

DNS translates domain names into IP addresses used by networked systems to locate servers.

DNS domain name को संबंधित IP address से resolve करने में मदद करता है।

⭐ EXAM POINT

DNS = Domain Name System.

Types of Hosting Hosting के प्रकार

  • Shared Hosting
  • VPS Hosting
  • Dedicated Hosting
  • Cloud Hosting

FTP File Transfer Protocol

FTP is a protocol used for transferring files between systems, commonly between a local computer and a server.

FTP files को एक system से दूसरे system में transfer करने के लिए उपयोग किया जाने वाला protocol है।

Website Publishing Website Publish करने की प्रक्रिया

  • Create website files.
  • Test website locally.
  • Purchase/choose domain if required.
  • Set up hosting.
  • Connect domain/DNS as needed.
  • Upload website files.
  • Test the live website.

Basic Website File Structure Recommended Structure 

my-website/
│
├── index.html
├── about.html
├── contact.html
│
├── css/
│   └── style.css
│
├── js/
│   └── script.js
│
└── images/
    ├── logo.png
    └── banner.jpg

index.html commonly website का main entry page होता है। CSS, JavaScript और images को अलग folders में रखना project को organize करने में मदद करता है।

Local vs Live Website Local Website और Live Website

Local Live
Runs on your own computer/environment. Accessible through Internet.
Useful for development/testing. Available to users online.
May use localhost. Usually accessed through domain/URL.
