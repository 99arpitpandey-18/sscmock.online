1. What is CSS?

CSS का basic concept

CSS — Cascading Style Sheets

ENGLISH

CSS stands for Cascading Style Sheets. It is a stylesheet language used to describe how HTML elements should look on a web page.

हिंदी

CSS का पूरा नाम Cascading Style Sheets है। इसका उपयोग HTML elements को सुंदर बनाने और उनका layout, color, font, spacing आदि निर्धारित करने के लिए किया जाता है।

CSS क्यों जरूरी है?

  • HTML → Structure बनाता है
  • CSS → Design और presentation करता है
  • JavaScript → Behaviour और interaction देता है
  • CSS से website attractive और readable बनती है।
🧩

Page को style और design CSS करता है।

2. CSS Syntax

CSS rule का structure

CSS Example 
p {
    color: blue;
    font-size: 18px;
}
ENGLISH

The selector selects an HTML element. Properties define what should change, and values specify how it should look.

हिंदी

Selector HTML element को select करता है। Property बताती है कि क्या change करना है और value बताती है कि वह change कैसे होगा।

🔗

3. Ways to Apply CSS

Inline, Internal और External CSS

① Inline CSS

CSS directly HTML element के अंदर style attribute में लिखा जाता है।

Example:
<p style="color:red;">Hello</p>

② Internal CSS

CSS को same HTML document के <style> element में लिखा जाता है।

Useful when one page has its own styles.

③ External CSS

CSS को अलग .css file में लिखा जाता है और HTML में link किया जाता है।

Example:
<link rel="stylesheet" href="style.css">

🎯

4. CSS Selectors

Most important exam topic

p

Element Selector

Selects all elements of a particular HTML tag.

Example:
p { color:red; }

.box

Class Selector

Selects elements having a particular class. Class selector starts with .

Example:
.box { padding:10px; }

#title

ID Selector

Selects an element using its id. ID selector starts with #.

Example:
#title { color:blue; }

*

Universal Selector

Selects all HTML elements.

Example:
* { margin:0; }

h1,p

Group Selector

Same style can be applied to multiple selectors.

Example:
h1,p { color:green; }

div p

Descendant Selector

Selects elements inside another element.

Example:
div p { color:red; }

8. CSS Display Property

Element का layout behaviour

block

Element normally पूरी available width लेता है और नई line से start होता है।

Examples: div, p, h1

inline

Element केवल required width लेता है और same line में रह सकता है।

Examples: span, a

inline-block

Inline की तरह line में रहता है लेकिन width और height apply की जा सकती है।

none

Element को display से remove कर देता है।

Example: display:none;

10. CSS Flexbox

Modern layout system

Flexbox क्या है?

ENGLISH

Flexbox is a CSS layout system used to arrange elements efficiently in rows or columns.

हिंदी

Flexbox एक CSS layout system है जिसका उपयोग elements को row या column में आसानी से arrange करने के लिए किया जाता है।

Important Flexbox Properties

display:flex Flex container बनाता है।
flex-direction row या column direction।
justify-content Main axis alignment।
align-items Cross axis alignment।
flex-wrap Items को wrap करने देता है।
gap Items के बीच space।

11. Complete CSS Example

HTML + CSS का practical example

HTML + CSS 
<!DOCTYPE html>

<html>

<head>

<style>

body {
    font-family: Arial;
    background: #eef4ff;
}

    color: #286cff;

}

    width: 300px;

    margin: 30px auto;

    border-radius: 15px;

}

    border: none;

    border-radius: 7px;
}

    <h2>Welcome</h2>

        This is my CSS website.
    </p>

    </button>

</body>

12. Responsive CSS

Mobile और desktop friendly design

Media Query

Media queries का उपयोग अलग-अलग screen sizes के लिए अलग CSS rules apply करने में किया जाता है। 

@media (max-width: 600px) {

    .container {
        width: 100%;
    }

    h1 {
        font-size: 25px;
    }

}
ENGLISH

Responsive design allows a website to adapt to mobile, tablet and desktop screens.

हिंदी

Responsive design website को mobile, tablet और desktop अलग-अलग screen sizes के अनुसार adjust करने में मदद करता है।
