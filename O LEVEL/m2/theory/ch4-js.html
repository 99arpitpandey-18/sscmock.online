1. Introduction to JavaScript

JavaScript क्या है?

What is JavaScript?

ENGLISH

JavaScript is a high-level programming/scripting language mainly used to make web pages interactive and dynamic.

हिन्दी

JavaScript एक high-level programming/scripting language है जिसका उपयोग web pages को interactive और dynamic बनाने के लिए किया जाता है।

JavaScript can be used for:

  • Changing HTML content
  • Changing CSS styles
  • Validating forms
  • Creating interactive buttons
  • Handling user events
  • Creating dynamic web pages
  • Manipulating HTML elements
  • Working with browser APIs
Exam Point:

HTML provides structure, CSS provides presentation/style, and JavaScript provides behavior and interactivity.

HTML vs CSS vs JavaScript

Technology Main Purpose Simple Meaning
HTML Structure Web page का ढांचा
CSS Presentation Web page की design/style
JavaScript Behavior Web page में interaction

3. Variables

Data को store करने के लिए variables

What is a Variable?

ENGLISH

A variable is a named container used to store data.

हिन्दी

Variable एक named container है जिसका उपयोग data को store करने के लिए किया जाता है।

let

let age = 20;

age = 21;

const

const is used when a variable should not be reassigned. 

const pi = 3.14159;

var

var is the older JavaScript keyword for declaring variables. Modern JavaScript generally prefers let and const. 

var name = "Arjun";
Remember:

let → value can be reassigned
const → variable cannot be reassigned
var → older variable declaration method

6. Conditional Statements

Decision making in JavaScript

if Statement

let age = 20;

if(age >= 18){

    console.log("Eligible");

}

if...else

let marks = 65;

if(marks >= 40){

    console.log("Pass");

}else{

    console.log("Fail");

}

else if

let marks = 85;

if(marks >= 90){

    console.log("A+");

}else if(marks >= 75){

    console.log("A");

}else if(marks >= 60){

    console.log("B");

}else{

    console.log("C");

}

switch Statement

let day = 2;

switch(day){

    case 1:
        console.log("Monday");
        break;

    case 2:
        console.log("Tuesday");
        break;

    default:
        console.log("Invalid day");

}
🔁

7. Loops

Repeated execution of code

for Loop

for(let i = 1; i <= 5; i++){

    console.log(i);

}

while Loop

let i = 1;

while(i <= 5){

    console.log(i);

    i++;

}

do...while Loop

let i = 1;

do{

    console.log(i);

    i++;

}while(i <= 5);
Exam Trick:

for loop is generally used when the number of iterations is known. while loop is useful when the condition controls how long the loop runs.

8. Functions

Reusable blocks of code

What is a Function?

ENGLISH

A function is a reusable block of code designed to perform a particular task.

हिन्दी

Function code का एक reusable block है जो किसी particular task को perform करता है। 

function greet(){

    console.log("Hello Student");

}

greet();

Function with Parameters

function add(a,b){

    return a + b;

}

let result = add(10,20);

console.log(result);

Arrow Function

const add = (a,b) => {

    return a + b;

};

10. JavaScript Events

User actions को handle करना

What is an Event?

ENGLISH

An event is an action that occurs in the browser, such as clicking a button, typing in a field or loading a page.

हिन्दी

Event browser में होने वाली कोई action है, जैसे button click करना, typing करना या page load होना।

Common Events

  • onclick
  • onchange
  • onmouseover
  • onmouseout
  • onkeydown
  • onkeyup
  • onsubmit
  • onload
<button onclick="showMessage()">
    Click Me
</button>

<script>

function showMessage(){

    alert("Button Clicked!");

}

</script>

11. DOM — Document Object Model

HTML elements को JavaScript से control करना

What is DOM?

ENGLISH

DOM represents an HTML document as a tree of objects. JavaScript can use the DOM to read and modify HTML elements.

हिन्दी

DOM HTML document को objects की tree के रूप में represent करता है। JavaScript की मदद से HTML elements को read और modify किया जा सकता है।

getElementById()

<p id="demo">
    Hello
</p>

<script>

document.getElementById("demo")
.innerHTML = "Welcome Student";

</script>

Changing CSS Using JavaScript

document.getElementById("demo")
.style.fontSize = "25px";

querySelector()

document.querySelector("#demo")
.innerHTML = "New Text";

Complete Mini Practical

HTML + CSS + JavaScript together

Interactive Button Example

यह example HTML element को JavaScript के साथ connect करता है। 

<!DOCTYPE html>

<html>

<head>

<title>JavaScript Demo</title>

</head>

<body>

<h2 id="heading">
    Welcome Student
</h2>

<button onclick="changeText()">
    Click Me
</button>


<script>

function changeText(){

    document.getElementById("heading")
    .innerHTML = "JavaScript is Working!";

}

</script>

</body>

</html>
How it works:

Button click → function executes → DOM element selected → text changes.
