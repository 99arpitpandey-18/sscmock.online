Part A — HTML Practical

Basic से advanced HTML practice

01
BASIC

Create a Basic HTML Web Page

एक basic HTML webpage बनाइए जिसमें title, heading और paragraph हो।
Task Create an HTML document containing a title, main heading and a paragraph introducing yourself.
💻 CODE
<!DOCTYPE html>
<html>
<head>
<title>My First Page</title>
</head>

<body>

<h1>My First Web Page</h1>

<p>My name is Arpit.</p>

</body>
</html>
👁 EXPECTED OUTPUT

Browser में "My First Web Page" heading और उसके नीचे paragraph दिखाई देगा।

💡 EXAM TRICK

हर HTML document में DOCTYPE, html, head और body structure याद रखें।

02
BASIC

Display Different Heading Levels

H1 से H6 तक सभी heading levels को webpage पर प्रदर्शित करें।
Task Create six headings using h1 to h6 tags.
💻 CODE
<h1>Heading 1</h1>
<h2>Heading 2</h2>
<h3>Heading 3</h3>
<h4>Heading 4</h4>
<h5>Heading 5</h5>
<h6>Heading 6</h6>
👁 EXPECTED OUTPUT

Six headings अलग-अलग sizes में दिखाई देंगी। H1 सबसे बड़ी और H6 सबसे छोटी होगी।

💡 TRICK

h1 → largest, h6 → smallest. Heading size बदलने के लिए CSS का use करना बेहतर है।

  • JavaScript में script tag और function syntax ध्यान से लिखें।
