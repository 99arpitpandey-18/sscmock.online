1. Conditional Sentences क्या होते हैं?

Conditional Sentence वह sentence होता है जिसमें किसी condition यानी शर्त और उसके result यानी परिणाम की बात की जाती है।

आसान शब्दों में, यदि एक काम किसी दूसरी condition पर depend करता है, तो वहाँ Conditional Sentence का प्रयोग किया जाता है।

⭐ सबसे पहले यह समझें

Condition = शर्त

Result = परिणाम

If + Condition → Result

If you work hard, you will succeed.

यदि तुम मेहनत करोगे, तो सफल हो जाओगे।

2. Conditional Sentence की Basic Structure

Conditional sentence में सामान्यतः दो clauses होते हैं:

If-clause → Condition / शर्त

Main clause → Result / परिणाम

If it rains, we will stay at home.

If it rains → Condition

we will stay at home → Result

Clause की Position

If you study hard, you will pass.

You will pass if you study hard.

🔥 SSC Rule

If-clause पहले आए तो सामान्यतः comma लगाया जाता है।

Main clause पहले आए तो सामान्यतः comma की आवश्यकता नहीं होती।

3. Types of Conditional Sentences

Type Main Use Basic Structure Example
Zero Facts / General Truth If + Present, Present If you heat ice, it melts.
First Real / Possible Future If + Present, will + V1 If you study, you will pass.
Second Unreal / Imaginary Present or Future If + Past, would + V1 If I were rich, I would help people.
Third Unreal Past If + had + V3, would have + V3 If I had studied, I would have passed.

4. Zero Conditional

Zero Conditional का प्रयोग general truths, facts, scientific facts और habitual results के लिए किया जाता है।

⭐ Formula

If + Simple Present, Simple Present

If you heat ice, it melts.

यदि आप बर्फ को गर्म करते हैं, तो वह पिघलती है।

If water reaches 100°C, it boils.

If you touch fire, it burns.

If plants do not get water, they die.

Zero Conditional पहचान

General truth → Zero Conditional

Scientific fact → Zero Conditional

हमेशा होने वाला result → Zero Conditional

5. First Conditional

First Conditional का प्रयोग ऐसी condition के लिए किया जाता है जो real या possible future situation हो।

⭐ Formula

If + Simple Present, will + V1

If you study hard, you will pass the exam.

यदि तुम मेहनत से पढ़ोगे, तो परीक्षा पास करोगे।

If it rains, we will stay at home.

If he comes, I will meet him.

If she works hard, she will succeed.

🎯 SSC Golden Rule

Future meaning होने पर भी If-clause में सामान्यतः will नहीं आता।

❌ If he will come, I will meet him.

✅ If he comes, I will meet him.

6. Second Conditional

Second Conditional का प्रयोग ऐसी situation के लिए होता है जो imaginary, unlikely या unreal present/future हो।

⭐ Formula

If + Simple Past, would + V1

If I were rich, I would help the poor.

यदि मैं अमीर होता, तो गरीबों की मदद करता।

If I had a car, I would travel more.

If she knew the answer, she would tell us.

If he studied harder, he would get better marks.

Second Conditional में Were

⭐ Important SSC Rule

Unreal / hypothetical condition में I, he, she, it के साथ भी were का प्रयोग किया जाता है।

If I were rich, I would help others.

If he were here, he would help us.

If she were my friend, I would tell her.

❌ If I was rich, I would buy a car.

✅ If I were rich, I would buy a car.

7. Third Conditional

Third Conditional का प्रयोग ऐसी past situation के लिए होता है जो वास्तव में नहीं हुई और जिसका result भी past में नहीं हुआ।

⭐ Formula

If + Past Perfect, would have + V3

If I had studied hard, I would have passed the exam.

यदि मैंने मेहनत से पढ़ाई की होती, तो मैं परीक्षा पास कर गया होता।

If he had worked hard, he would have succeeded.

If she had arrived earlier, she would have met him.

🎯 Third Conditional पहचान

Past में condition पूरी नहीं हुई + past result नहीं हुआ → Third Conditional

❌ If I would have studied, I would have passed.

✅ If I had studied, I would have passed.

8. Mixed Conditional

जब condition और result अलग-अलग time periods से related हों, तब Mixed Conditional का प्रयोग किया जाता है।

Past Condition → Present Result

Formula

If + had + V3, would + V1

If I had studied medicine, I would be a doctor now.

यदि मैंने medicine पढ़ी होती, तो आज मैं doctor होता।

If he had worked hard, he would have a good job now.

Present Condition → Past Result

Formula

If + Past Simple, would have + V3

If I were more careful, I would not have made that mistake.

यदि मैं अधिक सावधान होता, तो मैंने वह गलती नहीं की होती।

9. Unless का प्रयोग

Unless का अर्थ सामान्यतः if...not के समान होता है।

⭐ Rule

Unless = If...not

Unless you work hard, you will not succeed.

If you do not work hard, you will not succeed.

❌ Unless you do not work hard, you will fail.

✅ Unless you work hard, you will fail.

🔥 SSC Trick

Unless में सामान्यतः extra not मत लगाइए।

10. If...not

Negative condition बनाने के लिए If + subject + do/does/did not आदि का प्रयोग किया जा सकता है।

If you do not study, you will fail.

यदि तुम पढ़ाई नहीं करोगे, तो fail हो जाओगे।

If he does not come, we will leave.

If she did not know the answer, she would ask someone.

11. Provided / Providing / As Long As

Provided that, providing that और as long as का प्रयोग भी condition बताने के लिए किया जा सकता है।

You can go out provided that you finish your work.

You can borrow my book as long as you return it.

We will support you provided you follow the rules.

12. In Case

In case का प्रयोग precaution या possibility के लिए किया जाता है।

Take an umbrella in case it rains.

बारिश होने की स्थिति में umbrella ले लो।

Take some money in case you need it.

⭐ Difference

If → condition/result

In case → precaution / पहले से तैयारी

13. Whether और If

If conditional sentence में condition बताने के लिए आता है, जबकि whether का प्रयोग अक्सर alternatives या indirect question में होता है।

If you work hard, you will succeed.

I don't know whether he will come.

🎯 SSC Exam Point

Condition के लिए If और alternatives/uncertainty के लिए Whether को context के अनुसार पहचानें।

14. If + Should

कभी-कभी future possibility को formal तरीके से व्यक्त करने के लिए If + should का प्रयोग किया जाता है।

If you should need any help, call me.

If he should arrive, tell him to wait.

🔥 Note

यहाँ should possibility को express करता है।

15. If + Were

Hypothetical या unreal condition में were का प्रयोग विशेष रूप से important है।

If I were you, I would accept the offer.

If I were rich, I would travel the world.

If he were here, he would help us.

⭐ SSC Favourite Structure

If I were you, I would...

16. If + Had

Third Conditional में If-clause के अंदर Past Perfect का प्रयोग होता है।

Formula

If + subject + had + V3, subject + would have + V3

If I had known, I would have helped you.

If she had studied, she would have passed.

If they had arrived earlier, they would have caught the train.

17. If-Clause में Will का प्रयोग

सामान्य First Conditional में If-clause में will का प्रयोग नहीं किया जाता।

❌ If he will come, I will meet him.

✅ If he comes, I will meet him.

❌ If you will study hard, you will pass.

✅ If you study hard, you will pass.

लेकिन Special Case

यदि will willingness, insistence या refusal का अर्थ दे रहा हो, तो कुछ contexts में If-clause में will आ सकता है।

If you will listen to me, I can help you.

यहाँ will willingness को indicate कर रहा है।

18. If + Imperative

कभी-कभी condition के बाद main clause में imperative sentence भी आ सकता है।

If you see Rahul, tell him to call me.

If you need help, ask the teacher.

If you feel tired, take some rest.

19. Common Errors – SSC

Incorrect Correct Reason
If he will come, I will meet him. If he comes, I will meet him. First Conditional में If-clause में simple present।
If I was you, I would accept it. If I were you, I would accept it. Unreal condition → were.
If I would have studied, I would have passed. If I had studied, I would have passed. Third Conditional में If-clause → had + V3.
Unless you don't work, you will fail. Unless you work, you will fail. Unless already negative meaning देता है।
If he had worked, he would succeed yesterday. If he had worked, he would have succeeded yesterday. Past result → would have + V3.
If I knew the answer, I will tell you. If I knew the answer, I would tell you. Second Conditional → would + V1.
If it will rain, we will stay home. If it rains, we will stay home. If-clause में simple present।
If I had known this, I would tell you. If I had known this, I would have told you. Past unreal result → would have + V3.

20. SSC Conditional Sentences Tricks

🔥 Trick 1 – Zero Conditional

If + Present → Present

General Truth / Fact

🔥 Trick 2 – First Conditional

If + Present → will + V1

Real / Possible Future

🔥 Trick 3 – Second Conditional

If + Past → would + V1

Unreal / Imaginary Present or Future

🔥 Trick 4 – Third Conditional

If + had + V3 → would have + V3

Unreal Past

🔥 Trick 5 – If I Were You

Always remember:

If I were you, I would...

🔥 Trick 6 – Unless

Unless = If...not

Unless में generally extra “not” नहीं लगाते।

🔥 Trick 7 – If-Clause में Will

Normal future condition:

If + Present → will + V1

21. SSC PYQ-Based / Exam Pattern Practice

Question 1 SSC Pattern

If you work hard, you _____ succeed.

A. would
B. will
C. would have
D. had
Answer: B. will

First Conditional: If + Present → will + V1.

Question 2 SSC Pattern

If I _____ rich, I would help the poor.

A. am
B. was
C. were
D. had been
Answer: C. were

Unreal / hypothetical condition में If I were का प्रयोग होता है।

Question 3 SSC Pattern

If he _____ hard, he would have passed the examination.

A. studied
B. studies
C. had studied
D. has studied
Answer: C. had studied

Third Conditional: If + had + V3 → would have + V3.

Question 4 SSC Pattern

If it _____ tomorrow, we will stay at home.

A. will rain
B. rains
C. rained
D. had rained
Answer: B. rains

First Conditional में If-clause में Simple Present आता है।

Question 5 SSC Pattern

If I _____ you, I would accept the offer.

A. am
B. was
C. were
D. had been
Answer: C. were

Hypothetical advice structure: If I were you...

Question 6 SSC Pattern

Unless you _____ hard, you will not succeed.

A. work
B. worked
C. will work
D. had worked
Answer: A. work

Unless के बाद इस structure में Simple Present आता है।

Question 7 SSC Pattern

If you heat ice, it _____.

A. will melt
B. melted
C. melts
D. would melt
Answer: C. melts

General scientific fact → Zero Conditional.

Question 8 SSC Pattern

If she knew the answer, she _____ tell us.

A. will
B. would
C. would have
D. had
Answer: B. would

Second Conditional: If + Past → would + V1.

Question 9 SSC Pattern

If I had known about the problem, I _____ helped you.

A. will have
B. would
C. would have
D. had
Answer: C. would have

Third Conditional में result clause: would have + V3.

Question 10 SSC Pattern

Unless you hurry, you _____ miss the train.

A. would
B. will
C. had
D. would have
Answer: B. will

Unless you hurry = If you do not hurry. First Conditional structure में will आएगा।

Error Detection Practice

Find the error:

If he will come, I will meet him.

Error: will come

Correct: If he comes, I will meet him.

Find the error:

If I was you, I would accept the offer.

Error: was

Correct: If I were you, I would accept the offer.

Find the error:

If I would have known, I would have helped you.

Error: would have known

Correct: If I had known, I would have helped you.

Find the error:

Unless you do not study, you will fail.

Error: do not

Correct: Unless you study, you will fail.

22. Quick Revision – Conditional Sentences

Rule 2 Zero → General Truth / Fact
Rule 3 First → If + Present, will + V1
Rule 4 First → Real / Possible Future
Rule 5 Second → If + Past, would + V1
Rule 6 Second → Unreal / Imaginary
Rule 7 If I were you ✔
Rule 8 Third → If + had + V3
Rule 9 Third → would have + V3
Rule 10 Unless = If...not
Rule 11 Don't normally use “not” after Unless
Rule 12 If-clause में normal future के लिए will नहीं
Rule 13 If + should → possible/formal condition
Rule 14 Mixed → Different time periods
🎯 SSC Conditional Sentences Final Checklist
  • Zero Conditional → General truth / fact.
  • Zero → If + Present, Present.
  • First Conditional → Real / possible future.
  • First → If + Present, will + V1.
  • Second Conditional → Unreal / imaginary present or future.
  • Second → If + Past, would + V1.
  • Hypothetical condition → If I were you.
  • Third Conditional → Unreal past.
  • Third → If + had + V3, would have + V3.
  • Unless = If...not.
  • Unless के साथ generally extra “not” नहीं लगाते।
  • Normal First Conditional में If-clause में will नहीं आता।
  • Mixed Conditional में condition और result अलग-अलग time से हो सकते हैं।
  • If + should formal/possible condition को express कर सकता है।
