01. What is a Computer?

कंप्यूटर क्या है?

💻 Computer – Definition

Computer एक electronic device है जो user द्वारा दिए गए data को input के रूप में स्वीकार करता है, उसे process करता है और useful information के रूप में output देता है।


A computer is an electronic device that accepts data as input, processes it according to instructions, stores it when required, and produces meaningful output.

📌 Simple Example

अगर आप calculator में 50 + 20 enter करते हैं:

  1. Input: 50 + 20
  2. Processing: Addition
  3. Output: 70

02. Characteristics of Computer

कंप्यूटर की प्रमुख विशेषताएँ

⚡

Speed

Computer बहुत तेज गति से calculations और operations perform कर सकता है।
कंप्यूटर बहुत तेजी से कार्य करता है।

🎯

Accuracy

सही instructions और data मिलने पर computer highly accurate results देता है।
सही input होने पर परिणाम सही होता है।

💾

Storage

Computer large amount of data को store कर सकता है।
बहुत अधिक data को सुरक्षित रखा जा सकता है।

🔄

Consistency

Computer बार-बार same task करने पर भी consistent result देता है।

🤖

Automation

Instructions मिलने के बाद computer automatically tasks perform कर सकता है।

🌐

Versatility

Computer education, banking, business, science, entertainment आदि में इस्तेमाल होता है।

04. Types of Computers

कंप्यूटर के प्रकार

🖥️ Desktop Computer

एक computer system जिसे सामान्यतः desk/table पर रखा जाता है।

💻 Laptop

Portable computer जिसे आसानी से एक स्थान से दूसरे स्थान पर ले जाया जा सकता है।

📱 Tablet

Touchscreen based portable computing device.

📱 Smartphone

Mobile device जिसमें computing, internet, communication और applications की सुविधाएँ होती हैं।

🏢 Mainframe

Large organizations में huge amounts of data और transactions process करने के लिए उपयोग किया जाता है।

🚀 Supercomputer

Extremely high-performance computer जिसका उपयोग scientific और complex calculations में किया जाता है।

📌 Exam Point

Supercomputer को अत्यधिक complex और high-speed calculations के लिए उपयोग किया जाता है।

05. Generations of Computer

कंप्यूटर की पीढ़ियाँ

Generation Period (Approx.) Main Technology Important Feature
First 1940s–1950s Vacuum Tubes Very large & generated much heat
Second 1950s–1960s Transistors Smaller and more reliable
Third 1960s–1970s Integrated Circuits (IC) Faster and smaller
Fourth 1970s–Present Microprocessors Personal computers became common
Fifth Present & Future AI & advanced technologies Intelligent computing

🧠 याद रखने की Trick

Vacuum Tube → Transistor → IC → Microprocessor → AI

06. Computer Hardware

कंप्यूटर के भौतिक भाग

🔧 Hardware क्या है?

Computer के वे physical components जिन्हें हम देख और छू सकते हैं, hardware कहलाते हैं।

Examples: Keyboard, Mouse, Monitor, CPU, Printer, Hard Disk, RAM आदि।


⌨️ Keyboard

Text, numbers और commands enter करने के लिए उपयोग होता है।

🖱️ Mouse

Pointing, selecting, clicking और dragging के लिए।

🖥️ Monitor

Computer द्वारा generated output को screen पर दिखाता है।

🖨️ Printer

Digital information को paper पर print करता है।

💿 Storage

Data को store करने के लिए HDD, SSD आदि का उपयोग होता है।

🧠 RAM

Programs और data को temporarily hold करने वाली memory.

07. Computer Software

सॉफ्टवेयर क्या है?

💿 Software

Software instructions/programs का collection होता है जो computer को बताता है कि कौन सा काम कैसे करना है।


Software को हम सामान्यतः देख सकते हैं लेकिन physically touch नहीं कर सकते।


⚙️

System Software

Computer hardware को manage करने और system को operate करने के लिए आवश्यक software.


Examples:
  • Operating System
  • Device Drivers
  • Utility Programs
📱

Application Software

User की specific requirements पूरी करने के लिए बनाया गया software.


Examples:
  • Word Processor
  • Spreadsheet
  • Web Browser
  • Media Player

09. CPU – Central Processing Unit

कंप्यूटर का मस्तिष्क

🧠 CPU

CPU का full form Central Processing Unit है। इसे commonly computer का brain कहा जाता है।


CPU instructions को process करता है और computer के विभिन्न operations को control करता है।


🧠 CENTRAL PROCESSING UNIT
ALU
Arithmetic Logic Unit
CU
Control Unit
Registers
Temporary Storage

➕ ALU

Arithmetic Logic Unit

Arithmetic operations जैसे addition, subtraction, multiplication, division तथा logical operations perform करता है।

🎛️ CU

Control Unit

Computer के different components के operations को control और coordinate करता है।

📦 Registers

CPU के अंदर मौजूद very fast temporary storage locations जो processing के दौरान data/instructions hold करते हैं।

10. Computer Memory

कंप्यूटर मेमोरी

⚡

Primary Memory

CPU द्वारा directly access की जाने वाली main memory.


  • RAM
  • ROM
  • Cache Memory
💾

Secondary Memory

Long-term data storage के लिए उपयोग की जाती है।


  • Hard Disk
  • SSD
  • Pen Drive
  • Memory Card
  • CD/DVD

Memory Nature Main Point
RAM Volatile Power off होने पर stored data generally lost हो जाता है
ROM Non-volatile Data/instructions power off के बाद भी retained रहते हैं
Cache Very Fast CPU को frequently needed data/instructions जल्दी उपलब्ध कराने में मदद करती है
Hard Disk / SSD Non-volatile Long-term storage

📌 Important

RAM = Volatile Memory
ROM = Non-Volatile Memory
