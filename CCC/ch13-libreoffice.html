01. What is LibreOffice?

LibreOffice क्या है?

📘 LibreOffice

LibreOffice एक free और open-source office productivity suite है। इसका उपयोग documents बनाने, spreadsheets तैयार करने, presentations बनाने, databases manage करने और graphics/drawings बनाने के लिए किया जाता है।


English: LibreOffice is a free and open-source office suite containing applications for word processing, spreadsheets, presentations, databases and drawing.

⭐ Important for CCC

LibreOffice एक Open Source Software है। इसका उपयोग commercial और educational दोनों environments में किया जा सकता है।

04. LibreOffice Calc

Spreadsheet Application

📊 Calc

LibreOffice Calc एक spreadsheet application है। इसका उपयोग rows और columns में data organize करने, formulas और functions से calculations करने, sorting, filtering और charts बनाने के लिए किया जाता है।

⭐ Important

Calc की default OpenDocument file extension: .ods

Row

Horizontal line of cells. Generally numbers से identify होती है।

Column

Vertical line of cells. Generally letters से identify होती है।

Cell

Row और column के intersection को cell कहते हैं।

Formula

Calculation के लिए formula का उपयोग किया जाता है।

Example

=SUM(A1:A10)

यह A1 से A10 तक values का total calculate करेगा।

05. LibreOffice Impress

Presentation Software

📽️ Impress

LibreOffice Impress presentation बनाने और present करने के लिए उपयोग किया जाता है।


इसमें slides, text, images, charts, tables, animations और transitions add किए जा सकते हैं।

📄

Slide

✨

Animation

🔄

Transition

एक slide से दूसरी slide पर जाने का effect।

🖼️

Images

Presentation में images insert की जा सकती हैं।

📌 Important

LibreOffice Impress की default OpenDocument Presentation extension: .odp

06. LibreOffice Base

Database Management

🗄️ Base

LibreOffice Base एक database management application है। इसका उपयोग database create, manage और query करने के लिए किया जाता है।

Table

Form

Report
