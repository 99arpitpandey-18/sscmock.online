01. What is Cloud Computing?

Cloud Computing क्या है?

☁️ Cloud Computing

Cloud Computing एक technology है जिसमें computing resources जैसे servers, storage, databases, software और processing power को internet के माध्यम से access किया जाता है।


Cloud computing means using computing resources and services over the Internet instead of depending only on a local computer.

⭐ आसान भाषा में

अगर आपका data या software आपके computer में locally store/run होने के बजाय Internet पर available servers पर रखा और access किया जा रहा है, तो यह cloud computing का example हो सकता है।

📌 Exam Point

Cloud = Internet-based computing services

04. Cloud Service Models

IaaS, PaaS और SaaS

Model Full Form What It Provides Easy Example
IaaS Infrastructure as a Service Virtual machines, storage, networking आदि। Virtual Server
PaaS Platform as a Service Application development के लिए platform और environment। Development Platform
SaaS Software as a Service Ready-to-use software/application internet के माध्यम से। Web-based Application
🏗️

IaaS

IaaS = Infrastructure

PaaS

PaaS = Platform
💻

SaaS

SaaS = Software

07. Cloud Storage

Cloud में data storage

💾 Cloud Storage क्या है?

Cloud Storage एक service है जिसमें digital files और data को remote servers पर store किया जाता है और Internet के माध्यम से access किया जा सकता है।


📁

File Storage

Documents, images और अन्य files को store करना।

🔄

Synchronization

Multiple devices पर updated files maintain करने में मदद करता है।

📤

Backup

Important data की additional copy रखने में cloud services उपयोगी हो सकती हैं।

🔗

Sharing

Files या folders को अन्य लोगों के साथ share किया जा सकता है।

⚠️ Important

Cloud storage का उपयोग करते समय strong passwords, secure authentication और appropriate sharing permissions का ध्यान रखना चाहिए।

09. Cloud Security

Cloud में data को सुरक्षित रखना

🔐 Cloud Security

Cloud security का मतलब cloud-based systems, applications और data को unauthorized access, misuse और अन्य security threats से protect करना है।


🔑

Strong Password

Strong और unique passwords का उपयोग करें।

🛡️

Authentication

User identity verify करने के लिए secure authentication mechanisms उपयोग किए जाते हैं।

👁️

Access Control

केवल authorized users को required data और resources की access दी जानी चाहिए।

💾

Backup

Important information की backup copies रखना data protection में useful है।

⚠️ Security Tips

  • Strong password use करें।
  • Unknown links पर click न करें।
  • Account sharing avoid करें।
  • Important data की backup रखें।
  • File sharing permissions carefully check करें।

11. Limitations of Cloud Computing

Cloud Computing की limitations

🌐

Internet Dependency

कई cloud services के लिए reliable Internet connection आवश्यक होता है।

🔐

Security Concerns

Improper configuration या weak security से data risks पैदा हो सकते हैं।

⏳

Downtime

Service provider की outage होने पर service temporarily unavailable हो सकती है।

🔒

Privacy

Sensitive data को cloud पर store करते समय privacy requirements का ध्यान रखना चाहिए।

12. Cloud vs Local Computing

Cloud और traditional local computing में difference

☁️ Cloud Computing

  • Resources remote servers पर हो सकते हैं।
  • Internet के माध्यम से access किया जाता है।
  • Resources scale किए जा सकते हैं।
  • Physical infrastructure की requirement कम हो सकती है।
  • Multiple locations से access possible हो सकता है।

🖥️ Local Computing

  • Resources local computer या local infrastructure पर होते हैं।
  • Data और applications local system पर run हो सकते हैं।
  • Hardware capacity upgrade करनी पड़ सकती है।
  • Maintenance local organization/user को करनी पड़ सकती है।
  • Remote access के लिए additional setup की आवश्यकता हो सकती है।

🔥 Cloud Computing – Quick Revision

  • Cloud Computing Internet के माध्यम से computing resources और services access करने की technology है।
  • Cloud में computing, storage, applications और networking जैसी services मिल सकती हैं।
  • IaaS = Infrastructure as a Service
  • PaaS = Platform as a Service
  • SaaS = Software as a Service
  • Public Cloud सामान्य users/organizations के लिए available cloud environment हो सकता है।
  • Private Cloud किसी particular organization के dedicated use के लिए हो सकता है।
  • Hybrid Cloud = Public + Private Cloud combination।
  • Cloud Storage का उपयोग online data/files store करने के लिए किया जाता है।
  • Scalability का मतलब resources को requirement के अनुसार increase या decrease करना है।
  • Cloud Computing का एक major benefit flexibility और scalable resources है।
  • Cloud services के लिए कई situations में reliable Internet connection important होता है।
  • Cloud Security में authentication, access control, strong passwords और data protection important हैं।
  • Data Center में servers और networking infrastructure रखा जा सकता है।
  • Virtual Machine एक software-based computer environment है।
