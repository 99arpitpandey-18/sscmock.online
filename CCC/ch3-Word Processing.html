01. What is Word Processing?

Word Processing क्या है?

📝 Word Processing

Word Processing का अर्थ है computer की सहायता से text documents को create, edit, format, save और print करना।


A word processor is software used to create, edit, format, save and print text-based documents.

📌 Examples

  • LibreOffice Writer
  • Microsoft Word
  • Google Docs

⭐ Word Processor से क्या कर सकते हैं?

  1. Document create करना
  2. Text type करना
  3. Text edit करना
  4. Text formatting करना
  5. Tables insert करना
  6. Images add करना
  7. Document save करना
  8. Document print करना

03. Creating & Managing Documents

Document बनाना, खोलना और save करना

📄

New Document

नया document create करने के लिए New option का उपयोग किया जाता है।

📂

Open

पहले से saved document को open करने के लिए Open option।

💾

Save

Current document में किए गए changes को save करता है।

📑

Save As

Document को नए नाम, location या format में save करने के लिए।

🖨️

Print

Document की hard copy निकालने के लिए print option।

❌

Close

Current document या application को बंद करने के लिए।

📌 Important Shortcuts

New = Ctrl + N    Open = Ctrl + O    Save = Ctrl + S

11. Find & Replace

Text को जल्दी search और replace करना

🔎 Find

Document में किसी particular word या phrase को search करने के लिए Find option का उपयोग किया जाता है।


Shortcut: Ctrl + F

🔄 Replace

एक word/phrase को दूसरे word/phrase से replace करने के लिए Find & Replace feature उपयोग किया जाता है।


इसका उपयोग बड़े documents में बहुत useful होता है।

13. Mail Merge

एक ही document को multiple recipients के लिए personalize करना

📬 Mail Merge क्या है?

Mail Merge एक feature है जिसके द्वारा एक main document और data source को combine करके multiple personalized documents तैयार किए जा सकते हैं।


Example: कई students को अलग-अलग नाम के साथ certificates या letters तैयार करना।
