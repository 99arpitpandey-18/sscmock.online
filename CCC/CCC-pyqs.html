01 Computer
Computer ka brain kise kaha jata hai?

B. CPU
C. Keyboard
D. Printer
✓ Answer: B. CPU

02 Memory

A. ROM
B. RAM
C. DVD
D. Hard Disk
✓ Answer: B. RAM
RAM mein data power off hone par normally retain nahi hota.

A. Output
B. Storage
C. Input
D. Processing
✓ Answer: C. Input
