01. What is a Spreadsheet?

Spreadsheet क्या है?

📊 Spreadsheet

Spreadsheet एक software application है जिसका उपयोग data को rows और columns में organize करने, calculations करने, analysis करने और charts बनाने के लिए किया जाता है।


A spreadsheet organizes data in rows and columns and allows calculations, analysis and graphical presentation.

⭐ Spreadsheet के मुख्य उपयोग

  • Data entry
  • Calculations
  • Data analysis
  • Sorting & filtering
  • Charts and graphs
  • Reports बनाना
  • Budget और accounts maintain करना

03. Workbook & Worksheet

Workbook और Worksheet में difference

📚

Workbook

Spreadsheet file को सामान्यतः workbook कहा जाता है। इसमें एक या अधिक worksheets हो सकती हैं।

📄

Worksheet

Workbook के अंदर मौजूद individual spreadsheet page को worksheet कहा जाता है।

📑

Sheet Tab

अलग-अलग worksheets को identify और switch करने के लिए sheet tabs उपयोग किए जाते हैं।

📌 Easy Trick

Workbook = पूरी file

Worksheet = Workbook के अंदर एक sheet

04. Rows, Columns & Cells

Spreadsheet की basic structure

↔️

Row

Rows horizontal direction में होती हैं और सामान्यतः numbers से identify होती हैं।


Example: 1, 2, 3, 4...
↕️

Column

Columns vertical direction में होती हैं और सामान्यतः letters से identify होती हैं।


Example: A, B, C, D...
🔲

Cell

Row और column के intersection को cell कहते हैं।


Example: A1, B5, C10

⭐ Cell Address

Column letter + Row number = Cell Address


Example: B5

यहाँ B = Column और 5 = Row

07. Formulas

Spreadsheet में calculation का basic concept

➗ Formula क्या है?

Formula एक expression है जिसका उपयोग spreadsheet में calculations करने के लिए किया जाता है।


सामान्यतः formula = sign से शुरू होता है।

Example 1: Addition

=A1+B1

A1 और B1 की values को add करेगा।

Example 2: Multiplication

=A1*B1

A1 और B1 की values multiply करेगा।

Example 3: Average

=AVERAGE(B2:B6)

B2 से B6 तक values का average calculate करेगा।

⭐ Important Operators

Addition = +

Subtraction = -

Multiplication = *

Division = /

Power = ^

08. Important Spreadsheet Functions

CCC Exam के लिए बहुत important functions

Function Purpose Example
SUM Values का total निकालना =SUM(A1:A10)
AVERAGE Average निकालना =AVERAGE(A1:A10)
MAX Maximum value =MAX(A1:A10)
MIN Minimum value =MIN(A1:A10)
COUNT Numeric cells count करना =COUNT(A1:A10)
COUNTA Non-empty cells count करना =COUNTA(A1:A10)
ROUND Number को round करना =ROUND(A1;2)

09. Cell References

Relative, Absolute और Mixed references

A1

Relative Reference

Formula copy करने पर row और column reference change हो सकता है।

$A$1

Absolute Reference

Row और column दोनों fixed रहते हैं।

$A1

Mixed Reference

Column fixed और row relative होता है।

A$1

Mixed Reference

Row fixed और column relative होता है।

📌 Dollar Sign ($)

Spreadsheet formulas में $ sign का उपयोग reference को fixed रखने के लिए किया जाता है।

10. Sorting & Filtering

Data को organize और display करना

⬆️

Ascending Sort

Numbers को छोटे से बड़े और text को A से Z order में arrange किया जा सकता है।

⬇️

Descending Sort

Numbers को बड़े से छोटे और text को Z से A order में arrange किया जा सकता है।

🔍

Filter

Large dataset में केवल required records display करने के लिए filter उपयोग किया जाता है।

⭐ Example

यदि students का data है तो filter की सहायता से केवल "Pass" students को display किया जा सकता है।

12. Freeze Rows & Columns

Large spreadsheet में useful feature

❄️ Freeze

Freeze feature की सहायता से किसी row या column को fixed रखा जा सकता है ताकि scrolling करते समय वह visible रहे।


Example: Large student database में heading row को freeze करने पर नीचे scroll करते समय heading दिखाई देती रहती है।
