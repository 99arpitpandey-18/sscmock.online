01. What is Internet?

Internet क्या है?

🌐 Internet

Internet दुनिया भर में जुड़े हुए computers और networks का एक विशाल network है।


It allows computers and devices around the world to communicate and share information.

⭐ Simple Definition

Internet = Network of Networks

यानी अलग-अलग networks का interconnected global network.

🌍

Global Network

Internet पूरी दुनिया में devices और networks को connect करता है।

💬

Communication

Email, messaging और video calling जैसी services possible होती हैं।

📚

Information

Internet से information और educational resources access किए जा सकते हैं।

🛒

Online Services

Shopping, banking, ticket booking और कई online services available हैं।

03. World Wide Web (WWW)

Web क्या है?

🌎 World Wide Web

WWW Internet पर उपलब्ध interconnected web pages और resources की system है जिन्हें web browser के माध्यम से access किया जाता है।


WWW और Internet एक ही चीज नहीं हैं।

⭐ Important Difference

Internet = Global network infrastructure

WWW = Internet पर चलने वाली web pages/resources की service

05. URL – Uniform Resource Locator

Web resource का address

🔗 URL

URL = Uniform Resource Locator

URL Internet पर किसी resource/web page का address बताता है।


https:// www example.com /ccc

Part Meaning
https Protocol
www Web service prefix
example.com Domain name
/ccc Specific path/resource

10. Download & Upload

☁️ → 💻

💻 → ☁️

15. Safe Internet Practices

Internet use करते समय basic safety

🔐

Strong Password

Strong और unique passwords का उपयोग करें।

🚫

Suspicious Links

Unknown या suspicious links पर click करने से बचें।

🛡️

HTTPS

Sensitive information देते समय secure connection और सही website address check करें।

🔒

Privacy

Personal information को unnecessary websites पर share न करें।

⚠️ Remember

B. Single Computer
C. Operating System
