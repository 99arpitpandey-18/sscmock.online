Chapter 01

Introduction to Computer

Computer Fundamentals • Hardware • Software • Memory • CPU • I/O Devices

🖥️ What is Computer?

Computer is an electronic device that accepts data, processes it and produces meaningful information.


Hindi: Computer एक electronic device है जो data को input के रूप में लेता है, उसे process करता है और useful information देता है।

⭐ Characteristics of Computer

⚡

Speed

Computer बहुत तेजी से calculations और instructions execute कर सकता है।

🎯

Accuracy

सही instructions और data मिलने पर computer accurate results देता है।

💾

Storage

Computer large amount of data store कर सकता है।

🔁

Diligence

Computer repetitive tasks को बिना थके perform कर सकता है।

🔄

Versatility

अलग-अलग प्रकार के tasks perform किए जा सकते हैं।

🤖

Automation

Program दिए जाने पर tasks automatically perform हो सकते हैं।

💾 Memory

CPU द्वारा directly accessed memory.

  • RAM
  • ROM
  • Cache

Long-term data storage के लिए।

  • Hard Disk
  • SSD
  • Pen Drive
  • Memory Card
📌 Exam Point: CPU को commonly computer का "brain" कहा जाता है।

🧰 Hardware & Software

🔩

Hardware

Computer के physical components जिन्हें touch किया जा सकता है।

Example: Keyboard, Mouse, Monitor, CPU, Printer.

💿

Software

Programs और instructions का collection.

Example: Operating System, Browser, Word Processor.

🔥 Chapter 1 Quick Revision

  • Computer = Electronic data processing device.
  • CPU = Central Processing Unit.
  • ALU = Arithmetic Logic Unit.
  • CU = Control Unit.
  • RAM is volatile memory.
  • ROM is non-volatile memory.
  • Keyboard is an input device.
  • Monitor is an output device.
  • Hardware can be physically touched.
  • Software consists of programs/instructions.

Operating System

OS Basics • Desktop • Files • Folders • Settings • Utilities

⚙️ What is Operating System?

Operating System is system software that manages computer hardware and provides an interface between user and computer.


Hindi: Operating System एक system software है जो hardware resources को manage करता है और user को computer के साथ interact करने का interface देता है।

🧠

Memory Management

Memory resources को manage करता है।

📁

File Management

Files और folders को organize और manage करता है।

⚙️

Process Management

🔌

Device Management

Hardware devices को manage करता है।

🔐

Security

User accounts और access control में मदद करता है।

🖥️

📝 What is Word Processor?

Word Processor is software used to create, edit, format, save and print text documents.


Examples include word-processing applications available in office suites such as LibreOffice Writer and Microsoft Word.

Chapter 04

Spreadsheet

Workbook • Worksheet • Cells • Formulas • Functions • Charts • Data

📊 What is Spreadsheet?

Spreadsheet is software used to organize, calculate, analyze and present data in rows and columns.


Examples include LibreOffice Calc and Microsoft Excel.

📚 Workbook & Worksheet

📘

Workbook

Spreadsheet file जिसमें one or more worksheets हो सकती हैं।

📄

Worksheet

Rows और columns से बना working sheet.

🧱 Rows, Columns & Cells

Term Meaning
Row Horizontal arrangement
Column Vertical arrangement
Cell Intersection of row and column
Cell Address Column letter + row number, e.g. A1

🧮 Formula

=A1+B1 =A1*B1 =A1/B1 =A1-B1
Spreadsheet formulas generally begin with = sign.

🔢 Important Functions

Function Purpose Example
SUM Adds values =SUM(A1:A5)
AVERAGE Calculates average =AVERAGE(A1:A5)
MAX Largest value =MAX(A1:A5)
MIN Smallest value =MIN(A1:A5)
COUNT Counts numeric entries =COUNT(A1:A5)

📌 Cell References

Relative Reference

Formula copy करने पर reference generally change हो सकता है।

Example: A1

Absolute Reference

Reference को fixed रखने के लिए $ का उपयोग किया जा सकता है।

Example: $A$1

🔎 Sorting & Filtering

Sorting

Data को ascending/descending या अन्य selected order में arrange करना।

Filtering

केवल required records/data को display करना।

📈 Charts

📊

Column Chart

Categories की values compare करने में useful.

📈

Line Chart

Trends दिखाने के लिए useful.

🥧

Pie Chart

Parts of a whole represent करने के लिए।

📉

Bar Chart

Categories की comparison के लिए useful.

⌨️ Spreadsheet Shortcuts

🔥 Chapter 4 Quick Revision

  • Spreadsheet data को rows और columns में organize करता है।
  • Workbook spreadsheet file होती है।
  • Worksheet workbook के अंदर sheet होती है।
  • Cell = row और column का intersection.
  • Cell address example = A1.
  • Formula generally = sign से start होता है।
  • SUM = addition.
  • AVERAGE = average.
  • MAX = largest value.
  • MIN = smallest value.
  • COUNT = numeric entries count.
  • Chart data को graphical form में present करता है।

Presentation

Slides • Layouts • Images • Tables • Charts • Animation • Transition

🎞️ What is Presentation?

Presentation is a collection of slides used to communicate information visually to an audience.


Presentation software examples include LibreOffice Impress and Microsoft PowerPoint.

🖼️ Slide Components

📄

Slide

Presentation का individual page.

📝

Text

Information लिखने के लिए।

🖼️

Images

Visual information के लिए।

📊

Charts

Data को graphical form में दिखाने के लिए।

🧩 Slide Layout

Slide Layout यह निर्धारित करता है कि slide पर title, text, images आदि किस arrangement में दिखाई देंगे।

✨ Animation vs Transition

✨

Animation

Slide के अंदर मौजूद objects/text पर visual effect.

🔄

Transition

एक slide से दूसरी slide पर जाने के समय effect.

Exam Trick:

Animation → Object
Transition → Slide

📊 Tables & Charts

Table

Information को rows और columns में organize करने के लिए।

🌎 WWW

WWW = World Wide Web
