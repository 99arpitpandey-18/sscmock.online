01. What is a Presentation?

Presentation क्या होती है?

📽️ Presentation

Presentation एक ऐसा माध्यम है जिसमें information, ideas, data और concepts को slides के माध्यम से audience के सामने प्रस्तुत किया जाता है।


A presentation is a collection of slides used to communicate information, ideas and data visually.

⭐ Presentation के उपयोग

  • Education / Teaching
  • Business Meetings
  • Project Presentation
  • Training
  • Seminars
  • Reports & Data Visualization

09. Animation

Objects को animated effects देना

✨ Animation क्या है?

Animation का उपयोग slide के अंदर मौजूद objects जैसे text, images या shapes पर visual effects apply करने के लिए किया जाता है।


🎯 Entrance Animation

Object को slide पर आने का effect देता है।

ENTER

🚪 Exit Animation

Object को slide से जाने का effect देता है।

EXIT

📌 Animation vs Transition

Animation = Slide के अंदर मौजूद object पर effect.

Transition = एक slide से दूसरी slide पर जाने का effect.

10. Slide Transition

Slides के बीच visual effect

Transition एक slide से दूसरी slide पर move करते समय दिखाई देने वाला effect है।

11. Slide Show

Presentation को audience के सामने run करना

▶️ Slide Show

Slide Show mode में presentation slides को full-screen या presentation view में display किया जाता है।


इसका उपयोग final presentation देने के लिए किया जाता है।

⌨️ Important Shortcut

F5 = Start Slide Show

12. Master Slide

पूरी presentation का common design control करना

🎨 Master Slide

Master Slide का उपयोग presentation की multiple slides पर common formatting और design elements लागू करने के लिए किया जाता है।


जैसे common logo, background, fonts या footer को कई slides पर एक साथ maintain करना।

⭐ Easy Trick

Master Slide = Common Design / Common Formatting
