  2. Go to Download Result Section.
  3. Enter All Necessary Details Such as Application Number / Registration Number / Password / Date of Birth.
  4. Login through with Required Details.
  5. After entering the details your Result will be displayed.

❓ DSSSB Result 2026 – Important FAQs

Q1. When was DSSSB Result 2026 released?

✅ DSSSB Various Post Result 2026 has been released on 17/09/2026 for various post codes including 808/24 and 817/23.

Q2. How can I download DSSSB Result 2026?

✅ To download DSSSB Result 2026, visit the official website http://dsssb.delhi.gov.in/, go to the Download Result section, enter your Application Number / Registration Number / Date of Birth, and download the result PDF.

Q3. What is Post Code 817/23 in DSSSB?

✅ Post Code 817/23 is for Assistant Teacher (Nursery) Female in MCD, Assistant Teacher (Nursery) in DOE and Assistant Teacher (Nursery) in NDMC.

Q4. What is Post Code 808/24 in DSSSB?

✅ Post Code 808/24 is for the post of TGT Sanskrit Female.

Q5. What should candidates do after DSSSB Result is declared?

✅ Successful candidates should regularly visit the official website of DSSSB and also check their email ID for further updates on Document Verification, e-dossier submission, and other important notifications.

Q6. Where can I check the DSSSB Result / Merit List?

✅ Candidates can check their DSSSB Result / Merit List on the official website http://dsssb.delhi.gov.in/ or through the direct link provided above.
