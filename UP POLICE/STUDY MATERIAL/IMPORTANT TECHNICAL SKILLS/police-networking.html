🌐 Computer Networking — Complete Notes

Computer network दो या दो से अधिक computing devices का ऐसा connection है जिसके माध्यम से devices data, resources और services को share कर सकते हैं। Networking में devices, transmission media, protocols और addresses महत्वपूर्ण भूमिका निभाते हैं।

🌐 Computer Network क्या है?

Computer network connected computers और अन्य devices का group है जो communication links के माध्यम से data और resources share कर सकता है।

Network communication के लिए wired या wireless medium का उपयोग किया जा सकता है। Network में computers, servers, printers, switches, routers, access points और अन्य devices शामिल हो सकते हैं।

🔗 Network के मुख्य Elements

  • Sender और Receiver devices
  • Transmission medium
  • Network devices
  • Protocols
  • Network addresses

💡 Networking के फायदे

  • File sharing
  • Resource sharing
  • Communication
  • Internet access
  • Centralized services
🔥 EXAM ALERT: Networking का मुख्य उद्देश्य connected devices के बीच communication और resources/data sharing को enable करना है।

🖧 Important Network Devices

Network devices अलग-अलग networks और computing devices को connect, forward, control या communicate करने में सहायता करते हैं।

Device Main Function Exam Point
Hub Data को connected ports पर broadly repeat करता है Broadcasts data
Switch LAN में frames को appropriate destination तक forward करता है MAC address आधारित forwarding
Router Different networks के बीच packets forward करता है IP/network routing
Modem Digital/analog signal conversion और network access technology के अनुसार communication Modulator-Demodulator

🎯 Exam Point: Switch = LAN forwarding | Router = Networks connect/routing | Hub = Broadly repeats traffic | Repeater = Signal regeneration
04

🔢 IP Address

IP Address network पर किसी device/interface को identify करने के लिए use किया जाने वाला logical network address है। IP का उपयोग packet delivery और routing में किया जाता है।

4️⃣ IPv4

IPv4 एक 32-bit addressing system है। इसे सामान्यतः four decimal octets के रूप में लिखा जाता है, जैसे 192.168.1.10।

6️⃣ IPv6

IPv6 एक 128-bit addressing system है। इसका उपयोग IPv4 की तुलना में बहुत बड़ा address space उपलब्ध कराने के लिए किया गया है।

Feature IPv4 IPv6
Address Size 32-bit 128-bit
Notation Dotted decimal Hexadecimal groups
Address Space Smaller Very large
💡 याद रखें: IPv4 = 32 bit | IPv6 = 128 bit
05

🏷️ MAC Address और Domain Name

🔧 MAC Address

MAC यानी Media Access Control address network interface से associated hardware-level address है। Ethernet जैसे LAN technologies में MAC address local network communication और frame delivery में महत्वपूर्ण भूमिका निभाता है।

🌍 Domain Name

Domain name human-readable Internet name होता है, जैसे example.com। Users के लिए domain names को याद रखना numeric IP addresses की तुलना में आसान होता है।

Address / Name Nature Purpose
IP Address Logical network address Network identification और routing
MAC Address Link-layer hardware/interface address Local network communication
Domain Name Human-readable name Internet resources को आसानी से identify करना
🔥 EXAM ALERT: IP = Logical Network Address | MAC = Network Interface का link-layer address | Domain = Human-readable Internet name

Protocol communication के लिए defined rules और conventions का set होता है। Different protocols अलग-अलग networking functions perform करते हैं।

Protocol Full Form Common Use
HTTP HyperText Transfer Protocol Web communication
HTTPS HyperText Transfer Protocol Secure Secure web communication
FTP File Transfer Protocol File transfer

POP3 Post Office Protocol Version 3 Email retrieval

📚 OSI Model

OSI यानी Open Systems Interconnection model networking communication को seven conceptual layers में divide करता है। Exams में layers का order और basic functions frequently पूछे जाते हैं।

Layer No. Layer Basic Role
7 Application User-facing network services
6 Presentation Data representation, translation, encryption/compression concepts
5 Session Session establishment और management
4 Transport End-to-end transport
3 Network Logical addressing और routing
2 Data Link Frames और MAC-based local delivery
1 Physical Bits और physical transmission
🧠 OSI Order: Application → Presentation → Session → Transport → Network → Data Link → Physical
🎯 Exam Alert: Layer 3 = Network | Layer 4 = Transport | Layer 2 = Data Link | Layer 1 = Physical
08

🔄 TCP/IP Model और TCP vs UDP

TCP/IP networking में widely used protocol suite है। Internet communication इसके protocols पर आधारित है।

TCP UDP
Connection-oriented Connectionless
Reliable delivery Reliability guarantees नहीं
Sequencing और retransmission mechanisms Lower overhead
Generally more overhead Generally lower overhead

📦 TCP

TCP data delivery को reliable बनाने के लिए acknowledgements, sequencing और retransmission जैसे mechanisms का उपयोग करता है।

⚡ UDP

UDP connectionless transport protocol है। इसमें TCP जैसी built-in reliability mechanisms नहीं होतीं, लेकिन कम protocol overhead के कारण कुछ applications में useful होता है।

🕸️ Network Topologies

Network topology यह बताती है कि network के devices किस प्रकार physically या logically arranged/connected हैं।

Topology Basic Structure Important Point
Bus Common backbone cable Single main communication path
Star Central device के साथ connections Modern LANs में common concept
Ring Circular connection Devices ring form में जुड़े होते हैं
Mesh Multiple interconnections High redundancy possible
Tree Hierarchical arrangement Star + hierarchical structure
Hybrid Combination of topologies Multiple topology types combined
🔥 EXAM POINT: Star topology में central connecting device होता है। Mesh topology में multiple interconnections के कारण redundancy अधिक हो सकती है।

🌍 Internet, Intranet और Extranet

🌐 Internet

Publicly accessible global network of interconnected networks.

🏢 Intranet

Organization के internal use के लिए private network.

🤝 Extranet

Private network का controlled extension जिसमें authorized external users/partners को limited access दिया जा सकता है।

🔐 VPN

Virtual Private Network network communication को private/secure tunnel के माध्यम से carry करने के लिए उपयोग किया जा सकता है।

🎯 याद रखें: Internet = Public/global | Intranet = Internal/private | Extranet = Controlled external access

🚨 Commonly Confused Networking Concepts

Confusion Correct Difference Exam Point
Hub / Switch Hub broadly forwards/repeats traffic; switch forwards frames using MAC information LAN device difference
Switch / Router Switch primarily connects devices within a LAN; router connects/routes between networks MAC vs IP/routing
IP / MAC IP is logical network addressing; MAC is link-layer interface addressing Logical vs link-layer
HTTP / HTTPS HTTPS adds secure encrypted transport using TLS Secure web communication
TCP / UDP TCP provides reliable connection-oriented transport; UDP is connectionless Transport protocols
Internet / Intranet Internet is global/public; intranet is organization-controlled private network Public vs private
LAN / WAN LAN covers a local area; WAN covers larger geographical areas Coverage

Q1. LAN का full form क्या है?

B. Large Area Network
C. Logical Area Network
D. Long Area Node
Correct Answer: A — Local Area Network

Q2. WAN का full form क्या है?
A. Wireless Area Network
B. Wide Area Network
