Database क्या है? | What is Database?

Database related data का एक organized collection है, जिसे इस प्रकार store और manage किया जाता है कि information को आसानी से access, search, update और manage किया जा सके।

Exam Point: Database का मुख्य उद्देश्य data को व्यवस्थित तरीके से store करना और आवश्यकता के अनुसार information को efficiently retrieve करना है।

01

Database की मूल अवधारणा | Database Basics

Database में related information को structured तरीके से store किया जाता है। उदाहरण के लिए किसी school database में students के नाम, roll numbers, classes और marks store किए जा सकते हैं।

Database की आवश्यकता क्यों होती है?

  • Large amount of data को व्यवस्थित रखने के लिए।
  • Data को जल्दी search करने के लिए।
  • Data को update करने के लिए।
  • Data को delete करने के लिए।
  • Multiple users/applications को data access देने के लिए।
  • Data consistency और integrity बनाए रखने में मदद के लिए।
  • Data security और controlled access के लिए।
Exam Booster: Database = Organized collection of related data.
02

DBMS | Database Management System

DBMS एक software system है जो database को create, store, organize, retrieve, update और manage करने की सुविधा देता है।

DBMS के मुख्य कार्य

🗃️ Data Storage

Data को structured form में store और organize करने में मदद करता है।

🔎 Data Retrieval

Required data को search और retrieve करने की सुविधा देता है।

✏️ Data Update

Existing data को modify या update किया जा सकता है।

🔐 Security

Users और permissions के माध्यम से controlled access प्रदान किया जा सकता है।

DBMS Full Form: Database Management System

05

Database Keys | Keys क्या होती हैं?

Keys database में records को uniquely identify करने तथा tables के बीच relationships बनाने में महत्वपूर्ण भूमिका निभाती हैं।

Key Meaning Main Purpose
Primary Key Record की unique identification Duplicate और NULL values को सामान्यतः allow नहीं करता
Foreign Key दूसरी table की key को reference करता है Tables के बीच relationship
Candidate Key Possible unique key Primary key के candidate
Alternate Key Candidate keys में से जो primary नहीं चुनी गई Alternative unique identification
Composite Key Multiple columns से बनी key Combined uniqueness
High Value: Primary Key → Uniquely identifies a record.
Foreign Key → Tables के बीच relationship बनाने में मदद करती है।
06

Primary Key | Primary Key की विशेषताएँ

Primary Key table के प्रत्येक record को uniquely identify करने के लिए use की जाती है।

  • हर record की unique identification करती है।
  • एक table में सामान्यतः एक primary key constraint होती है।
  • Primary key value duplicate नहीं होनी चाहिए।
  • Primary key में NULL value स्वीकार नहीं होती।
  • Primary key single column या multiple columns से बन सकती है।
Example: Student_ID = Primary Key
Confusion Alert: Primary Key और Foreign Key एक जैसी नहीं हैं। Primary Key अपनी table में records को uniquely identify करती है, जबकि Foreign Key दूसरी table की key को reference कर सकती है।
07

Relationships | Tables के बीच संबंध

Relational databases में tables के बीच logical relationships बनाई जा सकती हैं।

Relationship Meaning Example
One-to-One एक record दूसरे table के एक record से जुड़ता है Person ↔ Passport
One-to-Many एक record कई records से जुड़ सकता है Department → Employees
Many-to-Many कई records कई records से related Students ↔ Courses
Exam Point: Relational database में tables के बीच relationships बनाने में keys महत्वपूर्ण भूमिका निभाती हैं।

SQL | Structured Query Language

SQL एक standard language है जिसका उपयोग relational databases में data को query और manage करने के लिए किया जाता है।

SQL Example:
SELECT * FROM Students;

ऊपर की query Students table के सभी columns और records को retrieve करने के लिए उपयोग की जाती है।

SQL Full Form: Structured Query Language

10

SELECT Command | Data Retrieve करना

SELECT SQL का सबसे important command है, जिसका उपयोग database से data retrieve करने के लिए किया जाता है।

SELECT * FROM Students;

यह Students table के सभी columns और rows retrieve करेगा।

Specific Columns

SELECT Name, Marks FROM Students;

यह केवल Name और Marks columns को retrieve करेगा।

WHERE Clause

SELECT * FROM Students WHERE Marks > 80;

WHERE condition के आधार पर required records को filter करने में मदद करता है।

11

INSERT, UPDATE और DELETE

INSERT

INSERT INTO Students (ID, Name, Marks) VALUES (104, 'Ravi', 90);

INSERT का उपयोग नया record add करने के लिए होता है।

UPDATE

UPDATE Students SET Marks = 95 WHERE ID = 104;

UPDATE existing data को modify करता है।

DELETE

DELETE FROM Students WHERE ID = 104;

DELETE condition के अनुसार records को remove करता है।

Important: UPDATE और DELETE के साथ WHERE clause का उपयोग न करने पर बहुत सारे या सभी matching records प्रभावित हो सकते हैं।

SQL Constraints | Data Rules

Constraints database में data पर certain rules लागू करती हैं ताकि data की integrity और validity maintain की जा सके।

Constraint Purpose
PRIMARY KEY Unique identification

NOT NULL NULL value को रोकना
UNIQUE Duplicate values को रोकना
CHECK Condition/rule लागू करना

NULL Value क्या है?

Database में NULL का अर्थ सामान्यतः missing, unknown या unavailable value को represent करना है।

Important: NULL का अर्थ zero या empty string के समान नहीं होता।

Example

SELECT * FROM Students WHERE Phone IS NULL;

NULL values को check करने के लिए SQL में IS NULL या IS NOT NULL का उपयोग किया जाता है।

15

Normalization | Database Organization

Normalization database design की एक technique है जिसका उद्देश्य data redundancy को कम करना और data consistency improve करना है।

मुख्य उद्देश्य

  • Duplicate/repeated data को कम करना।
  • Data inconsistency को कम करना।
  • Database structure को बेहतर बनाना।
  • Update, insert और delete anomalies को कम करना।
Normal Form Basic Idea
1NF Atomic values और repeating groups से बचाव
2NF 1NF + partial dependency को हटाना
3NF 2NF + transitive dependency को हटाना
Exam Point: Normalization → Redundancy कम करने और data organization improve करने की महत्वपूर्ण technique.
16

Data Integrity | Data की शुद्धता

Data integrity का अर्थ है कि database में data accurate, consistent और reliable बना रहे।

🔑 Entity Integrity

Primary key के माध्यम से records की unique identification सुनिश्चित करने से संबंधित।

🔗 Referential Integrity

Foreign key और related tables के बीच valid relationship maintain करने से संबंधित।

Simple Trick: Entity Integrity → Primary Key
Referential Integrity → Foreign Key

RDBMS | Relational Database

RDBMS का अर्थ Relational Database Management System है। इसमें data को tables में organize किया जाता है और tables के बीच relationships establish की जा सकती हैं।

RDBMS = Tables + Relationships + SQL

RDBMS की विशेषताएँ

  • Data tables में store होता है।
  • Rows और columns का उपयोग होता है।
  • Primary और foreign keys का उपयोग किया जा सकता है।
  • SQL द्वारा data query किया जा सकता है।
  • Relationships maintain की जा सकती हैं।
