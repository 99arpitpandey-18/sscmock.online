01

Cyber Awareness क्या है?

Cyber Awareness का अर्थ है Internet, computers, smartphones और digital services का उपयोग करते समय संभावित cyber threats को पहचानना और उनसे सुरक्षित रहने की basic knowledge रखना।

🔐 Cyber Security

Computers, networks, devices, applications और digital information को unauthorized access, misuse, damage या disruption से protect करने की व्यवस्था Cyber Security कहलाती है।

🧠 Cyber Hygiene

Regular security practices जैसे strong passwords, software updates, secure browsing, backup और suspicious links से बचना Cyber Hygiene कहलाता है।

याद रखें: Cyber Awareness = Threat को पहचानना + Safe behaviour अपनाना + Personal/Digital information को protect करना।

Common Cyber Threats — सामान्य साइबर खतरे

Threat Meaning मुख्य पहचान
Phishing Fake message/email/site द्वारा information चोरी करने का प्रयास Suspicious link, fake login, urgent request
Malware Malicious software का general term Device/data को नुकसान या unauthorized activity
Virus ऐसा malicious program जो files/programs से जुड़कर फैल सकता है Host file/program की आवश्यकता हो सकती है
Worm Self-replicating malware Network पर स्वतः फैल सकता है
Trojan Legitimate software जैसा दिखने वाला malicious program User को धोखा देकर install कराया जा सकता है
Ransomware Data/system को inaccessible करके payment मांगने वाला malware Files inaccessible + ransom demand
Spyware User activity को secretly monitor करने वाला software Information चोरी/monitoring
Adware Unwanted advertisements दिखाने वाला software Excessive/unwanted ads
🚨 Exam Alert: Virus और Worm में important difference: Virus आमतौर पर किसी host file/program से जुड़कर फैलता है, जबकि Worm स्वयं replicate होकर network के माध्यम से फैल सकता है।
03

Phishing, Smishing & Social Engineering

🎣 Phishing

Phishing एक social-engineering technique है जिसमें attacker fake email, website या message के माध्यम से user को password, OTP, banking details या अन्य sensitive information देने के लिए deceive करता है।

📱 Smishing

SMS के माध्यम से किया जाने वाला phishing attempt Smishing कहलाता है।

☎️ Vishing

Voice call/phone conversation के माध्यम से sensitive information हासिल करने की कोशिश को Vishing कहा जाता है।

🧠 Social Engineering

Technical vulnerability की बजाय human behaviour, trust या emotions का फायदा उठाकर information प्राप्त करने की technique Social Engineering कहलाती है।

⚠️ Red Flags: “Account अभी बंद हो जाएगा”, “Prize जीत गए”, “OTP बताइए”, “KYC तुरंत update करें” जैसे pressure/urgency वाले messages को verify किए बिना follow न करें।
Memory Trick: Phishing = Email/Web | Smishing = SMS | Vishing = Voice
04

Password, OTP & Authentication

🔑 Strong Password

Strong password ऐसा होना चाहिए जिसे आसानी से guess न किया जा सके। जहाँ service allow करे, वहाँ पर्याप्त लंबा unique password/passphrase use करना और अलग-अलग accounts के लिए अलग credentials रखना बेहतर practice है।

  • हर important account के लिए unique password रखें।
  • नाम, जन्मतिथि या बहुत common words को password न बनाएं।
  • Password को किसी के साथ share न करें।
  • जहाँ उपलब्ध हो, password manager का उपयोग किया जा सकता है।
  • Compromised password को तुरंत बदलें।

🔢 OTP — One Time Password

OTP एक temporary verification code होता है जिसका उपयोग authentication के दौरान किया जाता है। OTP को किसी व्यक्ति के साथ share नहीं करना चाहिए।

🛡️ 2FA / MFA

2FA (Two-Factor Authentication) में identity verify करने के लिए दो अलग authentication factors का उपयोग किया जाता है। MFA में दो से अधिक factors भी हो सकते हैं।

Factor Example
Something you know Password / PIN
Something you have Security key / registered device
Something you are Fingerprint / Face recognition
🎯 Exam Point: Biometric authentication “Something you are” factor का example है।
05

Security Tools — Firewall, Antivirus & Encryption

Tool / Technology मुख्य कार्य
Antivirus Malicious software को detect, prevent या remove करने में मदद करता है।
Firewall Network traffic को defined security rules के आधार पर allow/block करने में मदद करता है।
Encryption Readable data को encoded form में बदलती है ताकि unauthorized व्यक्ति उसे आसानी से न पढ़ सके।
Backup Important data की अलग copy रखकर data loss के प्रभाव को कम करता है।
Software Update Security vulnerabilities और bugs को fix करने में मदद करता है।

🔥 Firewall

Firewall एक security control है जो incoming और outgoing network traffic को predefined rules के अनुसार filter करता है।

🔒 Encryption

Encryption data को ऐसी coded representation में बदलती है जिसे पढ़ने के लिए appropriate decryption key/ प्रक्रिया की आवश्यकता होती है।

Remember: Antivirus → Malware | Firewall → Network Traffic | Encryption → Data Protection | Backup → Recovery
06

Safe Internet & Browser Practices

🌐 Safe Browsing

  • Important websites का address carefully check करें।
  • Unknown links पर बिना verify किए click न करें।
  • Browser और operating system को updated रखें।
  • Public computer पर login करने के बाद logout करें।
  • Unknown files/downloads को open करने से पहले source verify करें।
  • Browser में suspicious pop-ups को blindly follow न करें।

🔒 HTTPS

HTTPS, HTTP का secure version है जिसमें communication को TLS के माध्यम से protect किया जाता है। Browser में HTTPS connection encrypted communication प्रदान करने में मदद करता है।

🎯 Exam Alert: केवल “HTTPS” देखकर website को automatically trustworthy न मानें। Phishing websites भी HTTPS का उपयोग कर सकती हैं। Domain और source को भी verify करना जरूरी है।

📶 Public Wi-Fi Safety

  • Unknown public Wi-Fi पर sensitive activity करते समय सावधानी रखें।
  • Auto-connect feature को आवश्यकता न होने पर disable किया जा सकता है।
  • Shared/public device पर sensitive credentials save न करें।
07

Digital Payment & Online Safety

UPI, cards, net banking और अन्य digital payment systems का उपयोग करते समय basic cyber safety practices follow करना जरूरी है।

💳 Payment Safety

  • PIN/OTP share न करें।
  • Receiver का नाम/details verify करें।
  • Unknown QR code/payment request पर सावधानी रखें।
  • Payment confirmation check करें।

📲 Account Safety

  • Device lock का उपयोग करें।
  • Official apps/stores से applications install करें।
  • Suspicious permissions पर ध्यान दें।
  • Transaction alerts enable रखें।
🚫 Important: OTP, PIN, CVV, password या authentication code को किसी caller/message के कहने पर share नहीं करना चाहिए।
QR Code Trap: QR code scan करना कई situations में payment initiate करने का हिस्सा हो सकता है। किसी unknown व्यक्ति के निर्देश पर बिना details verify किए QR/payment request approve न करें।

Important Cyber Terms — Confusing Concepts

Term Meaning Quick Memory
Cyber Crime Computer/network/digital technology से संबंधित illegal activity Crime in digital environment
Cyber Attack System/network/data को target करने वाला malicious attempt Attack
Data Breach Unauthorized तरीके से protected/sensitive data का access/disclosure Data exposed
Identity Theft किसी व्यक्ति की identity information का unauthorized use Identity misuse
Botnet Compromised devices का network जिसे attacker control कर सकता है Network of bots
Zero-Day ऐसी vulnerability जिसके लिए effective fix/patch अभी उपलब्ध न हो सकता है Unknown/unpatched risk
Spam Unwanted bulk messages Unwanted messages
CAPTCHA Human और automated bots में distinction करने में मदद करने वाला mechanism Human verification

🧠 सबसे ज्यादा confuse होने वाले terms

Virus vs Worm

Virus host file/program से जुड़ सकता है; Worm self-replicate होकर network के माध्यम से फैल सकता है।

Phishing vs Malware

Phishing एक deception/social-engineering technique है, जबकि Malware malicious software का broad category है।

Authentication vs Authorization

Authentication = आप कौन हैं?
Authorization = आपको क्या करने की अनुमति है?

Encryption vs Backup

Encryption = data को protect/readability control करना।
Backup = data की अलग copy रखना।

📝 Practice MCQs — Cyber Awareness

Exam-oriented questions • Answers & explanations included

1. Phishing का मुख्य उद्देश्य क्या होता है?
A) User से sensitive information प्राप्त करना
B) Computer की screen साफ करना
C) Printer की speed बढ़ाना
D) Hard disk को format करना
Correct Answer: A
Phishing में attacker fake communication/website आदि के माध्यम से password, OTP या अन्य sensitive information हासिल करने की कोशिश करता है।
2. SMS के माध्यम से होने वाले phishing attempt को क्या कहा जाता है?
A) Vishing
B) Smishing
C) Spoofing
D) Scanning
Correct Answer: B
Smishing शब्द SMS + Phishing से बना है।
3. Voice call के माध्यम से phishing को क्या कहा जाता है?
A) Smishing
B) Spamming
C) Vishing
D) Pharming
Correct Answer: C
Voice/phone-based phishing को Vishing कहा जाता है।
4. निम्न में से कौन-सा malicious software का उदाहरण है?
A) Keyboard
B) Monitor
C) Scanner
D) Ransomware
Correct Answer: D
Ransomware एक प्रकार का malicious software है जो data/system को inaccessible कर सकता है और ransom demand कर सकता है।
5. Firewall का मुख्य कार्य क्या है?
A) Network traffic को rules के अनुसार filter करना
B) Text document बनाना
C) Image resize करना
D) Keyboard input को बदलना
Correct Answer: A
Firewall network traffic को security rules के आधार पर allow या block करने में मदद करता है।
6. Antivirus का मुख्य उद्देश्य क्या है?
A) Internet speed बढ़ाना
B) Malware को detect/prevent/remove करने में मदद करना
C) Monitor brightness बढ़ाना
D) File size बढ़ाना
Correct Answer: B
Antivirus malicious software को detect, prevent या remove करने में मदद करता है।
7. Biometric authentication किस factor का उदाहरण है?
A) Something you know
B) Something you have
C) Something you are
D) Something you download
Correct Answer: C
Fingerprint और face recognition जैसे biometrics “Something you are” factor के examples हैं।
8. 2FA का full form क्या है?
A) Two File Access
B) Two Firewall Application
C) Technical File Authentication
D) Two-Factor Authentication
Correct Answer: D
2FA का अर्थ Two-Factor Authentication है।
9. OTP का full form क्या है?
A) One Time Password
B) Online Transfer Protocol
C) One Terminal Process
D) Open Transfer Password
Correct Answer: A
OTP का full form One Time Password है।
10. Authentication का अर्थ क्या है?
A) File delete करना
B) Identity verify करना
C) Network disconnect करना
D) Data compress करना
Correct Answer: B
Authentication का उद्देश्य user/entity की identity verify करना है।
11. Authorization किससे संबंधित है?
A) Identity creation
B) Password generation
C) Access permissions
D) Data compression
Correct Answer: C
Authorization यह निर्धारित करता है कि authenticated user को कौन-से resources/actions की अनुमति है।
12. Data को unreadable/encoded form में बदलने की प्रक्रिया क्या कहलाती है?
A) Backup
B) Authentication
C) Formatting
D) Encryption
Correct Answer: D
Encryption readable data को protected encoded form में बदलती है।
13. कौन-सा malware files को inaccessible करके ransom demand कर सकता है?
A) Ransomware
B) Adware
C) Driver
D) Compiler
Correct Answer: A
Ransomware data/system को lock या encrypt करके ransom मांग सकता है।
14. स्वयं replicate होकर network में फैलने वाला malware कौन-सा है?
A) Trojan
B) Worm
C) Adware
D) Spyware
Correct Answer: B
Worm self-replicating malware है और network के माध्यम से तेजी से फैल सकता है।
15. Human behaviour का फायदा उठाकर information हासिल करने वाली technique?
A) Encryption
B) Backup
C) Social Engineering
D) Compression
Correct Answer: C
Social Engineering में attacker human trust, fear, curiosity या urgency जैसे factors का फायदा उठा सकता है।
16. CAPTCHA का मुख्य उद्देश्य क्या है?
A) Hard disk repair करना
B) Network cable test करना
C) File encryption करना
D) Human और automated bots में distinction करना
Correct Answer: D
CAPTCHA automated bots और human users में distinction करने में मदद करता है।
17. Data की अलग copy रखकर recovery में मदद करने वाली practice क्या है?
A) Backup
B) Phishing
C) Spoofing
D) Scanning
Correct Answer: A
Backup data की अतिरिक्त copy रखने की practice है, जो data loss की स्थिति में recovery में मदद कर सकती है।
18. निम्न में से कौन-सा “Something you have” factor का example है?
A) Password
B) Security Key
C) Fingerprint
D) PIN
Correct Answer: B
Security key एक possession factor यानी “Something you have” का example है।
19. Unwanted bulk messages को सामान्यतः क्या कहा जाता है?
A) Encryption
B) Backup
C) Spam
D) Authentication
Correct Answer: C
Unwanted या unsolicited bulk messages को सामान्यतः Spam कहा जाता है।
20. HTTPS में “S” किस concept को indicate करता है?
A) Search
B) System
C) Server
D) Secure
Correct Answer: D
HTTPS का अर्थ HyperText Transfer Protocol Secure है। इसमें TLS के माध्यम से communication को protect किया जाता है।
