Internet क्या है? | What is Internet?

Internet एक global network of interconnected computer networks है, जो दुनिया भर के computers, servers, smartphones और अन्य devices को आपस में communicate करने की सुविधा देता है। इसके माध्यम से हम websites browse कर सकते हैं, email भेज सकते हैं, online classes, video calls, cloud services, digital payments और अन्य online services का उपयोग कर सकते हैं।

Exam Point: Internet को सामान्यतः "network of networks" कहा जाता है क्योंकि यह अनेक छोटे-बड़े networks को आपस में जोड़ता है।

Internet की मूल अवधारणा | Internet Basics

Internet एक single computer या single organization का network नहीं है। यह interconnected networks का विशाल global system है। Devices Internet पर data को छोटे packets में exchange करते हैं।

Internet की मुख्य विशेषताएँ

  • Global connectivity प्रदान करता है।
  • Information sharing को आसान बनाता है।
  • Web browsing की सुविधा देता है।
  • Email और instant messaging जैसी communication services देता है।
  • Online education और e-commerce को support करता है।
  • Cloud computing और online storage का आधार है।
  • Audio/video streaming और video conferencing संभव बनाता है।
Exam Booster: Internet = interconnected computer networks का global system.
02

Internet और WWW में अंतर | Internet vs WWW

Internet और World Wide Web (WWW) को अक्सर एक ही समझ लिया जाता है, लेकिन दोनों अलग concepts हैं।

Point Internet World Wide Web
Meaning Global network infrastructure Internet पर उपलब्ध interconnected web pages/service
Nature Network of networks Internet की एक प्रमुख service
Uses Email, web, file transfer, streaming आदि Websites और web pages access करना
Protocol examples TCP/IP आदि HTTP/HTTPS
Access Internet connection के माध्यम से Web browser के माध्यम से
याद रखें: WWW Internet नहीं है। WWW, Internet पर चलने वाली एक service है।
03

World Wide Web | WWW

World Wide Web एक system है जिसमें interconnected web pages और resources Internet के माध्यम से access किए जाते हैं।

WWW के प्रमुख components

🌐 Web Page

एक individual document/resource जिसे browser में देखा जा सकता है। आमतौर पर HTML का उपयोग web pages बनाने में होता है।

🏠 Website

Related web pages और resources का collection website कहलाता है।

🖥️ Web Server

ऐसा computer/system जो web content को clients तक उपलब्ध कराता है।

🔎 Web Browser

Web pages और online resources को access और display करने वाला software।

Important: WWW के development से Tim Berners-Lee का नाम प्रमुख रूप से जुड़ा है।

URL | Uniform Resource Locator

URL किसी web resource का address/location बताता है। Browser में website access करने के लिए URL address bar में enter किया जाता है।

Example: https://www.example.com/page.html

URL के प्रमुख parts

Part Example Meaning
Scheme/Protocol https Communication protocol
Domain example.com Website/domain name
Path /page.html Specific resource/page
Exam Point: URL = Uniform Resource Locator.

HTTP और HTTPS

HTTP और HTTPS web communication में उपयोग होने वाले important protocols हैं।

Feature HTTP HTTPS
Full Form HyperText Transfer Protocol HyperText Transfer Protocol Secure
Security Encryption नहीं प्रदान करता TLS के माध्यम से encrypted connection प्रदान करता है

08

IP Address | Internet Protocol Address

IP Address network पर किसी device/interface की logical addressing के लिए उपयोग किया जाता है।

IPv4

IPv4 एक 32-bit addressing system है। इसे सामान्यतः चार decimal numbers के रूप में लिखा जाता है।

Example: 192.168.1.10

IPv6

IPv6 एक 128-bit addressing system है और IPv4 की तुलना में बहुत बड़ा address space प्रदान करता है।

Example: 2001:db8::1
Feature IPv4 IPv6
Address Size 32-bit 128-bit
Format Decimal Hexadecimal
Example 192.168.1.1 2001:db8::1

Domain Name और DNS

Domain Name

Domain name किसी website/service का human-readable name होता है।

Example: example.com

DNS — Domain Name System

DNS domain names को corresponding IP addresses में resolve करने में मदद करता है।

Easy Trick: DNS = Domain Name → IP Address

Email | Electronic Mail

Email का अर्थ Electronic Mail है। यह Internet के माध्यम से electronic messages भेजने और प्राप्त करने की service है।

Email Address का सामान्य format

username@domain.com

यहाँ @ symbol username और domain name को अलग करता है।

Email के प्रमुख fields

Field Meaning
To Main recipient
CC Carbon Copy — अन्य recipients को visible copy
BCC Blind Carbon Copy — recipients की addresses अन्य recipients से hidden रहती हैं
Subject Email का विषय/title
Attachment Email के साथ file भेजना
Body Email का मुख्य message

Internet Safety Basics | सुरक्षित Internet उपयोग

Safe Browsing के नियम

  • Unknown links पर बिना जाँच click न करें।
  • Suspicious attachments को open करने से बचें।
  • Websites का domain ध्यान से check करें।
  • Important accounts में strong और unique passwords रखें।
  • जहाँ उपलब्ध हो वहाँ multi-factor authentication का उपयोग करें।
  • Operating system और browser को updated रखें।
  • Public computer पर account use करने के बाद logout करें।
  • Important data का backup रखें।
Golden Rule: OTP, password, PIN और अन्य confidential authentication information किसी अनजान व्यक्ति के साथ share नहीं करनी चाहिए।

20 Important Questions • Answers & Explanations • A/B/C/D Balanced

Q1. Internet को सामान्यतः किस नाम से जाना जाता है?
(A) Network of Networks
(B) Single Computer
(C) Word Processor
(D) Operating System
Answer: (A) Network of Networks
Internet अनेक interconnected networks का global system है।
Q2. WWW का full form क्या है?
(A) World Web Window
(B) World Wide Web
(C) Wide World Website
(D) Web World Wide
Answer: (B) World Wide Web
WWW का full form World Wide Web है।
Q3. निम्न में से कौन-सा Web Browser है?
(A) Google Search
(B) Yahoo Search
(C) Mozilla Firefox
(D) DNS
Answer: (C) Mozilla Firefox
Mozilla Firefox एक web browser है।
Q4. HTTPS का default/common port कौन-सा है?
(A) 21
(B) 80
(C) 25
(D) 443
Answer: (D) 443
HTTPS का commonly used port 443 है।
Q5. URL का full form क्या है?
(A) Uniform Resource Locator
(B) Universal Routing Link
(C) Uniform Routing Location
(D) User Resource Link
Answer: (A) Uniform Resource Locator
URL किसी web resource का address/location बताता है।
Q6. DNS का मुख्य कार्य क्या है?
(A) Email भेजना
(B) Domain name को IP address में resolve करना
(C) File print करना
(D) Image edit करना
Answer: (B) Domain name को IP address में resolve करना

(A) FTP
(B) POP3
(C) IMAP
(D) SMTP

Q10. BCC का उपयोग किसके लिए किया जाता है?
(A) Subject लिखने के लिए

BCC यानी Blind Carbon Copy में recipient list सामान्य recipients को दिखाई नहीं देती।
