01

MS Word क्या है?

Microsoft Word एक word processing software है। इसका उपयोग text-based documents जैसे letters, reports, applications, resumes, notes और अन्य documents बनाने तथा format करने के लिए किया जाता है।

📄 Word Processing

Text को type, edit, format, arrange, print और save करने की प्रक्रिया को word processing कहा जाता है।

💾 Common File Formats

Modern Word documents का common extension .docx है। पुराने Word versions में .doc extension commonly मिलता था।

⭐ MS Word के प्रमुख उपयोग

  • Letters और applications तैयार करना।
  • Reports और project documents बनाना।
  • Text formatting और page layout करना।
  • Tables और lists बनाना।
  • Headers, footers और page numbers लगाना।
  • Spelling और grammar checking करना।
  • Documents को print या PDF में export करना।
  • Mail Merge द्वारा personalized documents तैयार करना।
याद रखें: MS Word = Word Processing Software. यह मुख्यतः text/document creation और formatting के लिए उपयोग किया जाता है।

MS Word Interface — Ribbon & Tabs

Modern versions of Word में commands को Ribbon और अलग-अलग tabs में organize किया जाता है। Exam में tabs और उनके functions को पहचानना बहुत महत्वपूर्ण है।

Tab मुख्य कार्य Important Commands
File Document/file management New, Open, Save, Print, Options
Home Basic editing & formatting Clipboard, Font, Paragraph, Styles
Insert Document में objects/content insert करना Table, Picture, Shapes, Header, Footer
Design Document appearance Themes, Colors, Effects
Layout Page और paragraph layout Margins, Orientation, Size, Columns
References References related tools TOC, Footnotes, Citations
Mailings Mail Merge related tasks Envelopes, Labels, Mail Merge
Review Proofing & collaboration Spelling, Comments, Track Changes
View Document viewing options Zoom, Views, Navigation Pane
🎯 Exam Alert: Home → Formatting, Insert → Objects, Layout → Page setup, References → TOC/Footnotes, Mailings → Mail Merge, Review → Proofing/Track Changes.
03

Text Formatting — Font & Character

Text formatting का अर्थ text के appearance को बदलना है। Word में Font group के माध्यम से text की style, size और appearance को control किया जा सकता है।

Feature Meaning Shortcut
Bold Text को मोटा करना Ctrl+B
Italic Text को तिरछा करना Ctrl+I
Underline Text के नीचे line लगाना Ctrl+U
Font Size Text का आकार बदलना Font Size box
Font Color Text का color बदलना Font Color
Text Highlight Text के background को highlight करना Text Highlight
Change Case Upper/lower/title case बदलना Change Case

🔤 Common Text Formatting

  • Bold — important text को emphasize करने के लिए।
  • Italic — emphasis या special text के लिए।
  • Underline — text के नीचे line।
  • Font Family — text का typeface बदलता है।
  • Font Size — text का आकार बदलता है।
  • Font Color — text का रंग बदलता है।
  • Highlight — text के पीछे background highlight करता है।
Memory Trick: B = Bold, I = Italic, U = Underline. इन तीनों के shortcuts क्रमशः Ctrl+B, Ctrl+I, Ctrl+U हैं।
04

Paragraph Formatting & Alignment

Paragraph formatting पूरे paragraph की positioning और spacing को control करती है। Alignment competitive exams का बहुत common topic है।

Alignment Meaning Shortcut
Left Align Text left side aligned Ctrl+L
Center Text center में Ctrl+E
Right Align Text right side aligned Ctrl+R
Justify Text दोनों margins के साथ align होता है Ctrl+J

📐 Important Paragraph Features

  • Line Spacing — lines के बीच vertical spacing।
  • Paragraph Spacing — paragraphs के बीच spacing।
  • Indentation — paragraph को margin से अंदर/बाहर करना।
  • Bullets — unordered list बनाने के लिए।
  • Numbering — numbered list बनाने के लिए।
  • Multilevel List — hierarchical lists के लिए।
🎯 Exam Alert: Ctrl+L = Left, Ctrl+E = Center, Ctrl+R = Right, Ctrl+J = Justify.

Insert Tools — Tables, Pictures, Header & Footer

Insert tab का उपयोग document में additional content और objects जोड़ने के लिए किया जाता है।

Tool Purpose
Table Rows और columns वाली table insert करना।
Pictures Images insert करना।
Shapes Lines, arrows, shapes आदि insert करना।
Chart Data का graphical representation बनाना।
Header Page के top area में repeated information रखना।
Footer Page के bottom area में repeated information रखना।
Page Number Pages को numbering देना।
Hyperlink Document में clickable link जोड़ना।

📌 Header

Header page के ऊपर वाले area में होता है और document के multiple pages पर repeated information रख सकता है।

📌 Footer

Footer page के नीचे वाले area में होता है। Page number आदि यहाँ रखा जा सकता है।

Quick Recall: Insert → Table / Picture / Shapes / Header / Footer / Page Number.

Page Layout & Document Setup

Feature Meaning
Margins Page के किनारों और content के बीच खाली space।
Orientation Page की direction — Portrait या Landscape।
Size Page का paper size जैसे A4 आदि।
Columns Text को multiple vertical columns में arrange करना।
Page Break नई page से content शुरू करना।
Section Break Document के अलग sections को अलग formatting देने में उपयोगी।

📄 Portrait vs Landscape

↕️ Portrait

Page vertically oriented होता है। सामान्य letters और documents में अक्सर उपयोग किया जाता है।

↔️ Landscape

Page horizontally oriented होता है। Wide tables और presentations जैसे content में उपयोगी हो सकता है।

🎯 Exam Point: Margins, Orientation, Size और Columns जैसे page-layout controls को Word में Layout tab से access किया जाता है।

Editing, Proofing & Review Tools

✂️ Editing Commands

Command Function Shortcut
Cut Selected content को remove करके clipboard में रखना Ctrl+X
Copy Selected content की copy बनाना Ctrl+C
Paste Clipboard content insert करना Ctrl+V
Undo Previous action reverse करना Ctrl+Z
Redo Undone action को फिर लागू करना Ctrl+Y
Select All पूरे document/content को select करना Ctrl+A
Find Document में text खोजना Ctrl+F
Replace Text को दूसरे text से replace करना Ctrl+H

🔎 Proofing Tools

  • Spelling mistakes identify करने में Word मदद कर सकता है।
  • Grammar suggestions उपलब्ध हो सकती हैं।
  • Thesaurus alternative words/synonyms खोजने में मदद करता है।
  • Word Count document में words की संख्या देखने के लिए उपयोगी है।

💬 Review Tab

Review tab में spelling/proofing, comments और Track Changes जैसे collaboration/review tools मिलते हैं।

Memory Trick: X = Cut | C = Copy | V = Paste | Z = Undo | Y = Redo

09

Mail Merge, Styles & Advanced Features

✉️ Mail Merge

Mail Merge का उपयोग एक ही basic document को अलग-अलग recipients की information के साथ multiple personalized documents बनाने के लिए किया जाता है।

📄 Main Document

वह common document जिसमें letter/content का main format होता है।

📊 Data Source

Recipients की information जैसे names और addresses का data source।

Example: एक school/company को एक ही letter 500 अलग-अलग लोगों के नाम और address के साथ भेजना हो तो Mail Merge उपयोगी हो सकता है।

🎨 Styles

Styles predefined formatting combinations होते हैं जिनका उपयोग headings, titles और अन्य text को consistent formatting देने के लिए किया जाता है।

📚 Table of Contents

Heading styles का सही उपयोग करने पर Word में Table of Contents को generate/update करना आसान होता है।

Views, Printing & File Management

Feature Purpose
Print Layout Document को print होने के approximate layout में देखना।
Read Mode Document को reading-focused तरीके से देखने में मदद करता है।
Web Layout Document को web-page style में देखने के लिए।
Zoom Document को बड़ा या छोटा करके देखने के लिए।
Print Document की physical/digital print output प्रक्रिया।

💾 Important File Operations

  • New — नया document बनाना।
  • Open — existing document खोलना।
  • Save — current changes save करना।
  • Save As — document को अलग name/location/format में save करना।
  • Print — document को print करना।
📌 File Extension: Modern Word document → .docx
