01

Keyboard Shortcut क्या है?

Keyboard shortcut दो या दो से अधिक keys का combination होता है जिसे किसी command को mouse/menu के बजाय जल्दी execute करने के लिए इस्तेमाल किया जाता है।

उदाहरण के लिए किसी text को copy करने के लिए menu में जाने की जगह Ctrl + C दबाया जा सकता है।

⌨️ Modifier Keys

  • Ctrl — अनेक commands के shortcuts में उपयोग
  • Alt — menus और system commands
  • Shift — alternate/uppercase selection आदि
  • Windows — Windows system functions

💡 क्यों महत्वपूर्ण हैं?

  • काम करने की speed बढ़ती है।
  • Mouse dependency कम होती है।
  • Office applications में productivity बढ़ती है।
  • Computer awareness exams में प्रश्न पूछे जाते हैं।

🔤 Function Keys — F1 to F12

Function keys keyboard की upper row में स्थित F1 से F12 तक keys होती हैं। इनका exact behavior application और operating system के अनुसार बदल सकता है, लेकिन exams में इनके commonly associated functions पूछे जाते हैं।

Key Common Function Exam Note
F1 Help Help key के रूप में commonly known
F2 Rename selected item Windows File Explorer में important
F3 Search Search-related function
F4 Context dependent Application-specific functions हो सकते हैं
F5 Refresh Browser/Windows में commonly used
F6 Cycle through screen elements Application dependent
F7 Spelling/grammar related function in some Office contexts Office exam questions में important
F8 Boot/startup related options on some systems Context dependent
F9 Application dependent Different software में अलग function
F10 Menu bar activation in many Windows applications Menu access
F11 Full screen in many browsers Browser shortcut
F12 Application dependent; Save As in some Office contexts Context dependent
🎯 सबसे ज्यादा पूछे जाने वाले: F1 = Help, F2 = Rename, F3 = Search, F5 = Refresh, F10 = Menu, F11 = Full Screen.

🧠 Shortcut Keys याद रखने की Smart Technique

✂️ C-X-V Family

C = Copy
X = Cut
V = Paste

↩️ Z-Y Family

Z = Undo
Y = Redo

💾 File Family

S = Save
O = Open
N = New
P = Print

🔎 Search Family

F = Find
H = Replace

Revision Order: पहले C-X-V → फिर Z-Y → फिर S-O-N-P → फिर F-H → फिर Windows shortcuts → अंत में F1-F12.
