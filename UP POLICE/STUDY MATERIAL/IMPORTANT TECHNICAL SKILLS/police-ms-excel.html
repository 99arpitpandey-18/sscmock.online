01

MS Excel क्या है?

Microsoft Excel एक spreadsheet software/application है जिसका उपयोग data entry, calculation, analysis, tables, charts और reports तैयार करने के लिए किया जाता है।

📗 Workbook

Excel की पूरी file को सामान्यतः Workbook कहा जाता है। एक workbook में एक या अधिक worksheets हो सकती हैं।

📄 Worksheet

Worksheet rows और columns से बनी working area होती है जिसमें data, formulas और functions enter किए जाते हैं।

⭐ Excel के प्रमुख उपयोग

  • Data entry और data organization।
  • Mathematical calculations।
  • Tables और reports बनाना।
  • Data sorting और filtering।
  • Charts और graphical presentation।
  • Statistical और financial calculations।
  • Formulas और functions से automatic calculation।
  • Large datasets का basic analysis।
याद रखें: Excel = Spreadsheet Software → Data + Calculation + Analysis + Charts.
02

Rows, Columns, Cells & Range

Excel spreadsheet की सबसे basic structure Rows और Columns से बनती है। Row और Column के intersection को Cell कहा जाता है।

Term Meaning Example
Row Horizontal arrangement 1, 2, 3, 4...
Column Vertical arrangement A, B, C, D...
Cell Row और Column का intersection A1
Active Cell Currently selected cell A1 या कोई selected cell
Cell Range Cells का group A1:C5
Formula Bar Active cell का content/formula देखने/edit करने की जगह =SUM(A1:A5)
Name Box Active cell address दिखाता है और range/cell selection में मदद करता है A1

📍 Cell Address

हर cell की एक unique address होती है जो सामान्यतः column letter और row number से मिलकर बनती है।

Example: A1 → Column A + Row 1
🎯 Exam Alert: A1 में A = Column और 1 = Row होता है। इसीलिए A1 एक Cell Address है।

Formulas — Excel Calculation का Base

Excel में calculation करने के लिए Formula का उपयोग किया जाता है। Excel में सामान्यतः formula = sign से शुरू किया जाता है।

🧮 Basic Formula Examples

Addition: =A1+B1
Subtraction: =A1-B1
Multiplication: =A1*B1
Division: =A1/B1
Percentage: =A1*10%

➕ Arithmetic Operators

Operator Operation Example
+ Addition =A1+B1
- Subtraction =A1-B1
* Multiplication =A1*B1
/ Division =A1/B1
^ Exponent/Power =A1^2
% Percentage =A1*10%
Memory Trick: Excel Formula का सबसे important पहचान चिन्ह → =
04

Important Excel Functions

Function एक predefined formula है जो किसी specific calculation या task को आसान बनाता है।

Function Purpose Example
SUM Numbers का total =SUM(A1:A10)
AVERAGE Arithmetic average =AVERAGE(A1:A10)
MAX सबसे बड़ी value =MAX(A1:A10)
MIN सबसे छोटी value =MIN(A1:A10)
COUNT Numbers वाले cells count करना =COUNT(A1:A10)
COUNTA Non-empty cells count करना =COUNTA(A1:A10)
IF Logical condition के आधार पर result =IF(A1>=40,"Pass","Fail")
ROUND Number को specified digits तक round करना =ROUND(A1,2)

⭐ Most Important Examples

Total: =SUM(B2:B10)
Average: =AVERAGE(B2:B10)
Highest: =MAX(B2:B10)
Lowest: =MIN(B2:B10)
Pass/Fail: =IF(B2>=40,"Pass","Fail")
🔥 Exam Alert: SUM → Total | AVERAGE → Average | MAX → Largest | MIN → Smallest | COUNT → Numeric cells count.
05

Cell References — Relative, Absolute & Mixed

Formula copy करते समय cell reference का behaviour समझना बहुत important है। Excel में मुख्यतः Relative, Absolute और Mixed references होते हैं।

Reference Example Behaviour
Relative A1 Row और column दोनों copy होने पर बदल सकते हैं।
Absolute $A$1 Row और column दोनों fixed रहते हैं।
Mixed $A1 Column fixed, row बदल सकता है।
Mixed A$1 Row fixed, column बदल सकता है।

📌 Dollar Sign $

Excel में $ symbol reference के row या column को fixed करने के लिए उपयोग किया जाता है।

🔒 $A$1

Column A और Row 1 दोनों fixed हैं। इसे Absolute Reference कहा जाता है।

🔓 A1

Row और Column दोनों relative हैं। इसे Relative Reference कहा जाता है।

🎯 Exam Point: $A$1 = Column fixed, A$1 = Row fixed, $A$1 और A$1 Mixed references हैं।

Formatting, Sorting, Filtering & Charts

🎨 Cell Formatting

  • Font type और font size change करना।
  • Bold, Italic और Underline apply करना।
  • Cell background/fill color बदलना।
  • Font color बदलना।
  • Alignment set करना।

  • Borders apply करना।

↕️ Sorting

Sorting का उपयोग data को किसी order में arrange करने के लिए किया जाता है। जैसे A-Z, Z-A, smallest-to-largest या largest-to-smallest।

🔎 Filtering

Filtering का उपयोग dataset में केवल उन records को display करने के लिए किया जाता है जो selected criteria को satisfy करते हैं।

📊 Charts

Chart Type Common Use
Column Chart Categories की values compare करना
Bar Chart Category comparison
Line Chart Time/trend दिखाना
Pie Chart Whole के parts/proportions दिखाना
Area Chart Values और trends को visualise करना
Quick Recall: Sort = Arrange Data | Filter = Show Selected Data | Chart = Visual Representation.

Important Excel Errors

Excel में गलत formula, reference या calculation की वजह से अलग-अलग error messages दिखाई दे सकते हैं।

Error Meaning / Common Cause
#DIV/0! किसी value को zero या blank denominator से divide करने की कोशिश।
#VALUE! Formula में inappropriate data type/value की समस्या।
#REF! Invalid/deleted cell reference।
#NAME? Formula में unrecognized name/function/text की समस्या।
#N/A Required value उपलब्ध नहीं है या result उपलब्ध नहीं मिला।
#NUM! Invalid numeric value या calculation-related numeric problem।
#NULL! कुछ situations में invalid intersection/reference operator से संबंधित error।
⚠️ Exam Alert: #DIV/0! का सबसे common meaning है कि formula किसी zero/blank denominator से division करने की कोशिश कर रहा है।

Important Excel Concepts

📑 Worksheet

Rows और columns से बनी working sheet जिसमें data और formulas enter किए जाते हैं।

📚 Workbook

Excel की पूरी file जिसमें worksheets का collection हो सकता है।

🧮 Formula

User द्वारा बनाया गया calculation expression, सामान्यतः = sign से शुरू।

🔢 Function

Predefined formula जो specific calculation को आसान बनाता है।

📌 Range

एक या अधिक selected cells का group, जैसे A1:C5।

📍 Active Cell

Currently selected cell जिसमें data enter/edit किया जा सकता है।

🧠 Golden Difference:

Formula → User-defined calculation expression
Function → Predefined calculation
Cell → Data रखने की individual location
Range → Cells का group
Worksheet → Rows + Columns वाली sheet
Workbook → Excel file containing worksheet(s)

Excel Data & Formula Quick Master

🧮 Formula vs Function

Formula Function
=A1+B1 =SUM(A1:B1)
=A1*B1 =AVERAGE(A1:B1)
=A1-B1 =MAX(A1:B1)
=A1/B1 =MIN(A1:B1)

📌 Range Examples

A1:A10 → A column में Row 1 से Row 10 तक
A1:C3 → A1 से C3 तक rectangular range
B2:B20 → B column में Row 2 से Row 20 तक

📊 Common Functions Revision

  • SUM() → Total
  • AVERAGE() → Average
  • MAX() → Maximum
  • MIN() → Minimum
  • COUNT() → Numeric cells count
  • COUNTA() → Non-empty cells count
  • IF() → Logical condition
  • ROUND() → Rounding
🏆 Exam Formula: SUM = जोड़ | AVERAGE = औसत | MAX = सबसे बड़ा | MIN = सबसे छोटा | COUNT = Numbers count | IF = Condition.
