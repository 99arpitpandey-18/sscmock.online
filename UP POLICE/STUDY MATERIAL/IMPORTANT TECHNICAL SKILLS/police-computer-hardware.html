🖥️ Computer Hardware क्या है?

Computer hardware computer के वे सभी physical components हैं जिन्हें physically देखा या छुआ जा सकता है। Hardware computer system के physical infrastructure को बनाता है।

Software instructions और programs प्रदान करता है, जबकि hardware उन instructions को execute करने के लिए physical resources उपलब्ध कराता है।

🔩 Hardware Examples

  • CPU
  • Motherboard
  • RAM
  • Hard Disk / SSD
  • Keyboard और Mouse
  • Monitor और Printer

💡 Hardware की मुख्य Categories

  • Processing Devices
  • Memory Devices
  • Storage Devices
  • Input Devices
  • Output Devices
  • Communication Devices
🔥 EXAM ALERT: Hardware = Computer system के physical components जिन्हें देखा और छुआ जा सकता है।
02

🧠 CPU — Central Processing Unit

CPU को computer का मुख्य processing unit माना जाता है। यह instructions को process करता है और computer operations को control तथा coordinate करता है।

CPU Component Full Form Main Function
ALU Arithmetic Logic Unit Arithmetic और logical operations
CU Control Unit Instructions और operations को control करना
Registers — बहुत छोटी और तेज़ internal storage
Cache — Frequently used data/instructions को तेजी से उपलब्ध कराना

➕ ALU — Arithmetic Logic Unit

ALU arithmetic operations जैसे addition, subtraction, multiplication और division तथा logical operations जैसे comparison और Boolean operations करने में भूमिका निभाता है।

🎛️ CU — Control Unit

Control Unit computer के विभिन्न components के बीच instructions और control signals के flow को coordinate करता है।

⚡ Registers

Registers CPU के अंदर मौजूद बहुत तेज़ storage locations होते हैं। इनका उपयोग processing के दौरान temporary data, instructions या addresses रखने के लिए किया जाता है।

🧠 याद रखें: ALU = Calculation + Logic | CU = Control | Registers = Very Fast Temporary Storage
03

💾 Computer Memory

Memory वह स्थान है जहाँ computer data, instructions और processing information को store करता है। Computer memory को broadly primary और secondary storage categories में समझा जाता है।

Memory Type Important Point
RAM Primary / Volatile Power off होने पर सामान्यतः data खो जाता है
ROM Primary / Non-volatile Power off होने पर contents सामान्यतः बने रहते हैं
Cache High-speed memory CPU के frequently needed data/instructions के लिए
Registers CPU internal बहुत तेज़ और छोटी storage locations
Hard Disk Secondary Storage Long-term data storage
SSD Secondary Storage Flash-based storage, no moving disk platters

⚡ RAM — Random Access Memory

RAM computer की working memory है। Programs और data जिन्हें CPU को currently access करना होता है, वे RAM में load हो सकते हैं।

🔒 ROM — Read Only Memory

ROM non-volatile memory का उदाहरण है। इसमें stored information power off होने के बाद भी सामान्यतः बनी रहती है। Modern systems में ROM के अलग implementations और firmware storage technologies का उपयोग हो सकता है।

🚀 Cache Memory

Cache CPU और main memory के बीच frequently accessed data/instructions तक तेजी से access देने में सहायता करती है। Cache सामान्यतः RAM की तुलना में तेज़ और capacity में छोटी होती है।

🎯 EXAM POINT: RAM = Volatile Memory | ROM = Non-volatile Memory | Cache = High-Speed Memory
04

🔧 Motherboard

Motherboard computer का मुख्य printed circuit board (PCB) होता है। यह CPU, memory, storage interfaces, expansion cards और अन्य components के बीच electrical connections उपलब्ध कराता है।

Component Role Exam Point
CPU Socket Processor को connect करता है Processor installation
RAM Slots Memory modules लगाने के लिए DIMM/SODIMM type system dependent
Expansion Slots Expansion cards connect करने के लिए PCIe commonly used
Storage Connectors Storage devices connect करने के लिए SATA/M.2 आदि
Chipset / Platform Controllers System communication और I/O support Platform dependent
Power Connectors Components को power supply Motherboard power
💡 Important: Motherboard को computer का "main circuit board" कहा जाता है क्योंकि अनेक hardware components इसी board से directly या indirectly जुड़े होते हैं।
05

💽 Storage Devices

Storage devices का उपयोग data और programs को long-term basis पर store करने के लिए किया जाता है।

Device Technology Important Feature
HDD Magnetic Rotating platters का उपयोग
SSD Flash / Solid-State Moving mechanical parts नहीं होते
USB Flash Drive Flash Portable storage
Memory Card Flash Small portable storage
Optical Disc Optical Laser-based reading/writing

💿 HDD — Hard Disk Drive

HDD magnetic storage technology का उपयोग करता है और इसमें mechanical moving parts होते हैं, जैसे rotating platters और read/write mechanism।

⚡ SSD — Solid State Drive

SSD flash-based solid-state storage का उपयोग करता है। इसमें HDD की तरह rotating platters नहीं होते और यह सामान्यतः fast access प्रदान करता है।

🔥 EXAM ALERT: HDD = Magnetic + Moving Parts | SSD = Solid-State + No Rotating Platters

⌨️ Input Devices

Input devices वे hardware devices हैं जिनकी सहायता से user computer को data या commands प्रदान करता है।

Device Function Category
Keyboard Text और commands enter करना Input
Mouse Pointing, selecting और navigation Input
Scanner Documents/images को digital form में convert करना Input
Microphone Audio input Input
Webcam Image/video input Input
Joystick Control और gaming input Input
Barcode Reader Barcode read करना Input
Biometric Scanner Fingerprint आदि biometric data read करना Input
🧠 Quick Rule: जिस device से computer को data/command दिया जाता है, वह सामान्यतः Input Device की category में आता है।
07

🖥️ Output Devices

Output devices computer द्वारा processed information को user तक पहुँचाने या प्रदर्शित करने में सहायता करते हैं।

Device Output Important Point
Monitor Visual output Soft copy display
Printer Printed output Hard copy
Speaker Audio output Sound output
Projector Large visual display Screen projection
Headphones Audio output Personal sound output

🖨️ Printers

Printer digital information को physical printed form में output करने के लिए उपयोग किया जाता है। Printers को broadly impact और non-impact categories में classify किया जा सकता है।

📄 Impact Printers

  • Dot Matrix
  • Print head/ribbon based mechanism
  • Printing के दौरान physical impact होता है

🖨️ Non-Impact Printers

  • Inkjet
  • Laser
  • Printing surface पर mechanical impact नहीं होता
🎯 Exam Point: Monitor = Soft Copy | Printer = Hard Copy
08

🔌 Ports & Connectors

Ports computer और external devices के बीच connection और data/power transfer के लिए उपयोग किए जाते हैं।

Port / Connector Common Use Exam Point
USB Data transfer और peripherals Very common interface
HDMI Digital audio/video Display connection
DisplayPort Digital display/audio Modern display interface
Ethernet / RJ-45 Wired networking LAN connection
3.5 mm Audio Jack Audio input/output Headphone/microphone use
VGA Analog video Older display interface
💡 Remember: USB = General Peripheral/Data Interface | HDMI = Digital Audio + Video | RJ-45 = Ethernet Networking
09

🧩 Peripheral Devices

Peripheral devices वे hardware devices हैं जो computer की core processing unit के बाहर connect होकर input, output, storage या communication जैसी additional functionality प्रदान करते हैं।

Peripheral Type Function
Keyboard Input Text/command input
Mouse Input Pointing और selection
Printer Output Hard copy output
Scanner Input Document/image digitization
External HDD Storage Data storage/backup
Webcam Input Video input
Speakers Output Audio output
🧠 Important: एक ही physical device की classification उसके function के आधार पर समझी जा सकती है। उदाहरण के लिए external storage device data store करता है, जबकि printer output देता है।
10

📏 Units of Computer Memory

Computer storage और memory capacity को विभिन्न units में measure किया जाता है। Competitive exams में इनके क्रम और basic relationships पूछे जा सकते हैं।

Unit Common Relationship Meaning
Bit 0 या 1 Smallest basic unit of digital information
Byte 8 bits Common basic storage unit
Kilobyte (KB) 1024 bytes* Memory/storage unit
Megabyte (MB) 1024 KB* Memory/storage unit
Gigabyte (GB) 1024 MB* Memory/storage unit
Terabyte (TB) 1024 GB* Large storage capacity
🎯 Exam Note: Traditional binary-based exam questions में 1 Byte = 8 bits और 1 KB = 1024 Bytes जैसे relationships commonly दिए जाते हैं। Modern storage manufacturers decimal units भी use करते हैं, इसलिए context ध्यान से पढ़ें।
11

⚙️ BIOS, UEFI और Boot Process

Computer start होने पर firmware hardware initialization और operating system boot process की शुरुआत में महत्वपूर्ण भूमिका निभाता है।

🔧 BIOS

  • Basic Input/Output System
  • Traditional system firmware
  • Hardware initialization में भूमिका
  • Boot process में सहायता

🚀 UEFI

  • Modern firmware interface
  • Traditional BIOS के modern replacement के रूप में उपयोग
  • Modern hardware और boot features support करता है
  • Graphical interface भी उपलब्ध हो सकता है
💡 Exam Point: BIOS/UEFI operating system नहीं हैं। ये firmware interfaces हैं जो system startup और hardware initialization/boot process में महत्वपूर्ण भूमिका निभाते हैं।

🚨 Commonly Confused Hardware Concepts

Confusion Correct Difference Exam Point
RAM / ROM RAM generally volatile; ROM non-volatile Power off concept
HDD / SSD HDD magnetic mechanical; SSD solid-state Moving parts
Input / Output Input gives data to computer; Output presents processed information Direction of information
Hardware / Software Hardware physical; Software programs/instructions Physical vs logical
CPU / RAM CPU processes; RAM temporarily holds working data/instructions Processor vs memory
Cache / HDD Cache is high-speed memory; HDD is secondary storage Speed and purpose
Monitor / Printer Monitor gives soft-copy display; Printer produces hard copy Output devices

📝 Practice MCQs

Computer Hardware — Exam Oriented Practice

Q1. Computer का मुख्य processing unit किसे कहा जाता है?
A. CPU
B. Monitor
C. Keyboard
D. Printer
Correct Answer: A — CPU
CPU यानी Central Processing Unit instructions को process करने और computer operations को control/coordinate करने में मुख्य भूमिका निभाता है।
Q2. ALU का मुख्य कार्य क्या है?
A. केवल printing
B. Arithmetic और logical operations
C. केवल data storage
D. Internet connection
Correct Answer: B — Arithmetic और logical operations
ALU arithmetic और logical operations perform करने में CPU की सहायता करता है।
Q3. CU का full form क्या है?
A. Computer Unit
B. Central Utility
C. Control Unit
D. Common Unit
Correct Answer: C — Control Unit
Q4. निम्न में से कौन-सी सामान्यतः volatile memory है?
A. ROM
B. RAM
C. DVD
D. SSD
Correct Answer: B — RAM
RAM की contents सामान्यतः power off होने पर बनी नहीं रहतीं।
Q5. निम्न में से कौन-सी non-volatile memory का उदाहरण है?
A. RAM
B. Cache
C. ROM
D. Register
Correct Answer: C — ROM
Q6. Computer का main circuit board कौन-सा है?
A. Motherboard
B. Keyboard
C. Printer
D. Speaker
Correct Answer: A — Motherboard
Q7. निम्न में से कौन-सा solid-state storage device है?
A. HDD
B. SSD
C. Dot Matrix Printer
D. Scanner
Correct Answer: B — SSD
SSD flash-based solid-state storage technology का उपयोग करता है।
Q8. निम्न में से कौन-सा input device है?
A. Monitor
B. Printer
C. Keyboard
D. Projector
Correct Answer: C — Keyboard
Q9. निम्न में से कौन-सा output device है?
A. Scanner
B. Mouse
C. Keyboard
D. Monitor
Correct Answer: D — Monitor
Q10. Printer द्वारा प्राप्त physical printed output को क्या कहा जाता है?
A. Soft Copy
B. Hard Copy
C. Firmware
D. Cache
Correct Answer: B — Hard Copy
Q11. HDMI का commonly उपयोग किसके लिए किया जाता है?
A. Digital audio/video
B. केवल keyboard input
C. केवल printing
D. केवल scanning
Correct Answer: A — Digital audio/video
Q12. RJ-45 connector सामान्यतः किस networking connection से संबंधित है?
A. Bluetooth
B. Ethernet
C. Infrared
D. NFC
Correct Answer: B — Ethernet
Q13. 1 Byte में कितने bits होते हैं?
A. 4
B. 8
C. 16
D. 32
Correct Answer: B — 8 bits
Q14. निम्न में से कौन-सा impact printer है?
A. Laser Printer
B. Inkjet Printer
C. Dot Matrix Printer
D. Thermal display
Correct Answer: C — Dot Matrix Printer
Dot Matrix printer impact printing mechanism का उदाहरण है।
Q15. निम्न में से किस device में सामान्यतः rotating magnetic platters होते हैं?
A. SSD
B. HDD
C. RAM
D. USB keyboard
Correct Answer: B — HDD
Traditional HDD magnetic rotating platters और mechanical read/write mechanism का उपयोग करता है।
