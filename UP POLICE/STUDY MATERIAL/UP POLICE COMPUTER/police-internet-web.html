Internet, WWW एवं Web Evolution

🔹 Internet क्या है?

Internet, computers और networks का एक global interconnection है जो TCP/IP protocol suite का उपयोग करके आपस में जुड़ते हैं। यह एक "Network of Networks" है। इसकी शुरुआत ARPANET (1969) से हुई, जो US Department of Defense द्वारा विकसित किया गया था।

🔹 WWW (World Wide Web) क्या है?

WWW एक information system है जो internet के ऊपर काम करता है। इसे Tim Berners-Lee ने 1989 में CERN (Switzerland) में विकसित किया था। यह hypertext documents (web pages) को URLs द्वारा identify करता है और HTTP/HTTPS के माध्यम से access करता है।

Internet vs WWW: Internet = Physical infrastructure (cables, routers, servers)। WWW = Service (web pages, websites) जो internet पर चलती है। (Email, FTP, VoIP भी internet पर चलते हैं लेकिन WWW का हिस्सा नहीं हैं)।

🔹 Web Evolution (Web 1.0, 2.0, 3.0)

  • Web 1.0 (Static Web - 1990s): Read-only। Static HTML pages। Content creators कम, consumers ज्यादा। (जैसे: GeoCities, early Yahoo)।
  • Web 2.0 (Social Web - 2000s): Read-Write। User-generated content। Social media (Facebook, YouTube, Wikipedia), Blogs, Podcasts। AJAX, APIs का उदय।
  • Web 3.0 (Semantic/Decentralized Web - 2010s+): Read-Write-Execute। AI, Machine Learning, Blockchain, Decentralized apps (DApps), IoT integration। Data ownership और privacy पर focus।

🔹 Basic Web Terms (Exam Focus)

  • ISP (Internet Service Provider): जो internet access provide करता है (Jio, Airtel, BSNL)।
  • IP Address: Devices की unique logical identity (IPv4/IPv6)।
  • Domain Name: IP का readable form (google.com)। DNS इसे IP में resolve करता है।
  • Web Server: Software (Apache, Nginx, IIS) जो web content store और deliver करता है।
  • Web Client: Browser (Chrome, Firefox) जो content request और render करता है।
🎯 Key Difference: Internet = Highway, WWW = Cars (Services) on that highway. Web 1.0 = Static, Web 2.0 = Social, Web 3.0 = Smart/Decentralized.
02

Web Browsers & Search Engines

🔹 Web Browser क्या है?

Browser एक application software है जो web pages को retrieve, present और traverse करता है। यह HTTP requests भेजता है, HTML/CSS/JS को render करता है।

  • Popular Browsers: Google Chrome (Blink engine), Mozilla Firefox (Gecko engine), Safari (WebKit), Microsoft Edge (Chromium based)।
  • Browser Components: User Interface, Browser Engine, Rendering Engine, Networking, JS Interpreter, Data Storage (Cookies, Cache)।

🔹 Search Engine क्या है?

Search Engine एक web-based tool है जो internet पर information को index करके users को relevant results देता है। Google (86%+ market share), Bing, Yahoo, Baidu प्रमुख हैं।

Working: Crawling (Spider/Bot web pages collect करता है) → Indexing (Database में organize करता है) → Ranking (Algorithms जैसे PageRank, AI के आधार पर results rank करता है)।

Search Operators (Exam में पूछे जाते हैं):
  • "" (Quotes): Exact phrase search (e.g., "Artificial Intelligence")।
  • site: Specific website पर search (e.g., site:bbc.com india)।
  • filetype: Specific file type (e.g., filetype:pdf) ।
  • OR / |: Either of the keywords।
  • - (Minus): Exclude a word (e.g., apple -fruit)।
  • * (Asterisk): Wildcard for missing words।
🎯 Browser Cache: Temporary storage of web pages to speed up loading. Private/Incognito Mode: No history/cookies saved locally.

URL, DNS & Web Technologies

🔹 URL (Uniform Resource Locator) – Structure

URL, web resource (page, image, file) का complete address होता है।

Format: scheme://domain:port/path?query#fragment

  • Scheme/Protocol: http:// या https://
  • Domain: www.example.com
  • Port: :80 (HTTP) या :443 (HTTPS) – optional
  • Path: /folder/page.html
  • Query String: ?key1=value1&key2=value2 (GET parameters)
  • Fragment: #section (internal page anchor)
HTTP Status Codes (Exam में बहुत जरूरी):
  • 1xx (Informational): 100 Continue
  • 2xx (Success): 200 OK, 201 Created
  • 3xx (Redirection): 301 Moved Permanently, 302 Found, 304 Not Modified
  • 4xx (Client Error): 400 Bad Request, 401 Unauthorized, 403 Forbidden, 404 Not Found
  • 5xx (Server Error): 500 Internal Server Error, 502 Bad Gateway, 503 Service Unavailable

🔹 DNS (Domain Name System)

DNS, human-readable domain names (google.com) को machine-readable IP addresses (142.250.183.46) में translate करता है। इसे "Internet की Phonebook" कहते हैं। DNS records: A (IPv4), AAAA (IPv6), CNAME (Alias), MX (Mail Exchange), TXT (Verification)।

🔹 Basic Web Technologies

  • HTML (HyperText Markup Language): Web pages का skeleton/Structure।
  • CSS (Cascading Style Sheets): Presentation/Styling (Color, Layout, Fonts)।
  • JavaScript (JS): Interactivity, Dynamic content, Form validation।
  • HTTP Methods (Verbs): GET (retrieve), POST (send data), PUT (update), DELETE (remove)।
  • Cookies: Small text files stored on client-side to track sessions, preferences, and authentication state.
🎯 Ports & Status Codes: HTTP=80, HTTPS=443. 200=OK, 404=Not Found, 500=Server Error. DNS translates Domain → IP.

Email – Protocols, Clients & Security

🔹 Email (Electronic Mail) क्या है?

Email, internet पर messages और files भेजने/प्राप्त करने की एक विधि है। Email address format: user@domain.com।

🔹 Email Headers & Fields (Exam Focus)

  • From / To: Sender और Recipient।
  • CC (Carbon Copy): Additional recipients (everyone can see)।
  • BCC (Blind Carbon Copy): Hidden recipients (others can't see)।
  • Subject: Email का topic।
  • Attachments: Files (doc, pdf, images) जो email के साथ भेजी जाती हैं (MIME protocol)।

🔹 Email Protocols (Ports & Functions)

ProtocolPortFunction
SMTP (Simple Mail Transfer Protocol)25 (or 587/465 for secure)Sending emails (Push) – Client to Server, Server to Server.
POP3 (Post Office Protocol v3)110 (995 for secure)Receiving emails. Downloads email to device and typically deletes from server. (Offline access).
IMAP (Internet Message Access Protocol)143 (993 for secure)Receiving emails. Syncs with server. Emails remain on server. (Multi-device access).

Email Clients: Outlook, Thunderbird, Apple Mail.
Webmail: Gmail, Yahoo Mail, Outlook.com (Browser-based).

🔹 Email Security & Spam

  • Spam: Unsolicited bulk emails (Junk)।
  • Phishing: Fraudulent emails pretending to be legitimate to steal credentials.
  • SPF / DKIM / DMARC: Authentication protocols to prevent email spoofing.
🎯 Email Protocols: SMTP = Send, POP3 = Download & Delete, IMAP = Sync (Keep on server). BCC = Hidden recipients.

Web Security, E-Commerce & Emerging Tech

🔹 Web Security Basics

  • SSL/TLS (Secure Sockets Layer / Transport Layer Security): Encrypts data between browser and server. HTTPS uses this. Padlock icon in browser indicates secure connection.
  • Digital Certificate / SSL Certificate: Issued by Certificate Authority (CA) like Verisign, Let's Encrypt. Proves website identity.
  • Firewall (Web/Application): Monitors and filters HTTP traffic. Prevents SQL Injection, Cross-Site Scripting (XSS), etc.
  • Malware/Virus: Malicious software. Antivirus protects against it.

🔹 E-Commerce (Electronic Commerce)

Online buying and selling of goods/services.

  • B2B (Business-to-Business): Amazon, Alibaba (Wholesale)।
  • B2C (Business-to-Consumer): Flipkart, Amazon Retail, Myntra।
  • C2C (Consumer-to-Consumer): OLX, eBay, Etsy।

Payment Gateways: PayPal, Razorpay, Stripe। UPI, Net Banking, Cards are common payment methods.

🔹 Cloud Computing & Web 3.0 Trends

  • Cloud Computing: On-demand IT resources over the internet.
    • IaaS (Infrastructure as a Service): AWS, Azure, GCP (Virtual Machines, Storage)।
    • PaaS (Platform as a Service): Google App Engine, Heroku (Platform for dev)।
    • SaaS (Software as a Service): Gmail, Office 365, Salesforce (Ready-to-use software)।
  • IoT (Internet of Things): Physical devices (Smartwatches, Fridges, Sensors) connected to internet.
  • Semantic Web: Web 3.0 का core – AI agents understand data meaning to provide better results.
🎯 Web Safety: SSL/TLS = Encryption (HTTPS). CA = Issues certificates. Cloud: IaaS (Infra), PaaS (Platform), SaaS (Software). E-Commerce: B2B, B2C, C2C.
