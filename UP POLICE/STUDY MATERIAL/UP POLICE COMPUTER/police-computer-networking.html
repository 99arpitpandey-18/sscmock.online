01

Network परिचय, Types एवं Topologies

🔹 Computer Network क्या है?

Computer Network दो या अधिक computing devices (computers, servers, printers, switches) का समूह है जो आपस में communication links (wired/wireless) के माध्यम से जुड़े होते हैं ताकि resources (files, printers, internet) share किए जा सकें। Network का उद्देश्य Resource Sharing, Reliability, Cost Reduction, और Scalability प्रदान करना है।

🔹 Network Types (Geographical Span के आधार पर)

  • PAN (Personal Area Network): अत्यंत छोटा दायरा (कुछ मीटर) – जैसे Bluetooth, USB, Infrared। उदाहरण: Smartwatch से Phone का कनेक्शन।
  • LAN (Local Area Network): एक भवन या ऑफिस तक सीमित (जैसे 100 मीटर से 1-2 km)। High speed (100 Mbps – 10 Gbps), Low cost, जैसे Ethernet, Wi-Fi।
  • MAN (Metropolitan Area Network): एक शहर या महानगर को कवर करता है (5km से 50km तक)। उदाहरण: Cable TV network, शहर का नगर निगम नेटवर्क।
  • WAN (Wide Area Network): बहुत बड़ा भौगोलिक क्षेत्र (देश, महाद्वीप) – जैसे Internet। Leased lines, satellite, fiber optics का उपयोग। Speed LAN से कम होती है।

🔹 Network Topologies (Physical Arrangement)

  • Bus Topology: सभी devices एक single central cable (backbone) से जुड़े होते हैं। सरल और कम खर्चीला, लेकिन backbone फेल होने पर पूरा network ठप। Terminator की आवश्यकता।
  • Star Topology: सभी devices एक central device (Hub/Switch) से जुड़े होते हैं। सबसे लोकप्रिय। एक device फेल होने पर network प्रभावित नहीं होता, लेकिन central device फेल होने पर पूरा network ठप। Easy troubleshooting।
  • Ring Topology: प्रत्येक device अपने पड़ोसी (neighbor) से जुड़ा होता है, डेटा एक दिशा (या दो दिशाओं) में circular path में travel करता है। Token passing technique का उपयोग। Failure होने पर network बाधित हो सकता है (जब तक कि dual-ring न हो)।
  • Mesh Topology: प्रत्येक device हर दूसरे device से directly connected होता है। Highly redundant और reliable, लेकिन बहुत महंगा और complex। उदाहरण: Internet backbone में आंशिक रूप से उपयोग।
  • Tree Topology: Star topologies का hierarchical combination। Parent-child relationship। Scalable, लेकिन root node फेल होने पर network विभाजित हो जाता है।
  • Hybrid Topology: दो या अधिक topologies का मिश्रण (जैसे Star-Ring, Star-Bus)। बड़े organizations में flexible solution।
🎯 Exam Focus: LAN = Local, WAN = Wide, Star = Most common, Bus = Simple but risky, Mesh = Redundant but expensive.
02

Network Devices & OSI Model

🔹 OSI Model (Open Systems Interconnection) – 7 Layers

  • Layer 7 – Application: User के निकटतम। Network services (HTTP, FTP, SMTP, DNS) प्रदान करता है। Data = Message।
  • Layer 6 – Presentation: Data translation, encryption/decryption, compression। (जैसे SSL/TLS, JPEG, MPEG)।
  • Layer 5 – Session: Connection establishment, management, termination (dialogue control)। (जैसे NetBIOS, RPC)।
  • Layer 4 – Transport: End-to-end communication, error recovery, flow control। (TCP – reliable, UDP – unreliable)। Data = Segments।
  • Layer 3 – Network: Logical addressing (IP), routing। Router इस layer पर काम करता है। Data = Packets।
  • Layer 2 – Data Link: Physical addressing (MAC), error detection (CRC), framing। Switch/Bridge इस layer पर काम करता है। Data = Frames।
  • Layer 1 – Physical: Raw bit stream transmission over medium। Cables, Hubs, Repeaters। Data = Bits।

Memory Trick: “All People Seem To Need Data Processing” (Application – Presentation – Session – Transport – Network – Data Link – Physical).

🔹 Important Network Devices (with OSI Layer)

  • NIC (Network Interface Card): Device को network से जोड़ता है। Unique MAC address प्रदान करता है। Layer 2 (Data Link)।
  • Repeater: Signal को regenerate/amplify करता है ताकि distance बढ़ सके। Layer 1 (Physical)।
  • Hub: Multiple devices को जोड़ता है। Broadcast mode में काम करता है। कोई intelligence नहीं। Layer 1 (Physical)।
  • Bridge: दो या अधिक LAN segments को जोड़ता है। MAC addresses पढ़ता है और filtering करता है। Layer 2 (Data Link)।
  • Switch: सबसे लोकप्रिय। MAC address table बनाकर unicast delivery करता है। Collision domain को separate करता है। Layer 2 (Data Link)।
  • Router: विभिन्न networks को आपस में जोड़ता है। IP addressing और routing decisions लेता है। Layer 3 (Network)।
  • Gateway: दो अलग-अलग network architectures (जैसे TCP/IP और IPX/SPX) के बीच translation करता है। Layer 5/7 (Session/Application) पर काम कर सकता है।
  • Modem: Digital signals को analog और analog को digital में convert करता है (Modulation-Demodulation)।
  • Access Point (AP): Wireless devices को wired network से जोड़ता है। Wi-Fi।
🎯 OSI vs Device: Hub/Repeater = Layer 1, Switch/Bridge = Layer 2, Router = Layer 3, Gateway = Layer 5/7.
03

IP Addressing – IPv4, IPv6, Classes, Subnetting

🔹 IPv4 Address

32-bit संख्या, 4 octets में विभाजित (dotted decimal notation) – जैसे 192.168.1.1। प्रत्येक octet 0 से 255 तक। Total possible addresses: 2³² = 4.3 Billion।

IP Address Classes (Classful Addressing):
  • Class A: 0.0.0.0 – 127.255.255.255 | Default Subnet Mask: 255.0.0.0 (/8) | N.H.H.H | Large networks (16 Million hosts) | Loopback: 127.0.0.1
  • Class B: 128.0.0.0 – 191.255.255.255 | Mask: 255.255.0.0 (/16) | N.N.H.H | Medium networks (65,534 hosts)
  • Class C: 192.0.0.0 – 223.255.255.255 | Mask: 255.255.255.0 (/24) | N.N.N.H | Small networks (254 hosts)
  • Class D: 224.0.0.0 – 239.255.255.255 | Multicast (ग्रुप communication)
  • Class E: 240.0.0.0 – 255.255.255.255 | Reserved (Experimental)

🔹 Private IP Addresses (NAT के लिए)

  • Class A Private: 10.0.0.0 – 10.255.255.255 (10.0.0.0/8)
  • Class B Private: 172.16.0.0 – 172.31.255.255 (172.16.0.0/12)
  • Class C Private: 192.168.0.0 – 192.168.255.255 (192.168.0.0/16)

APIPA (Automatic Private IP Addressing): जब DHCP server उपलब्ध न हो तो Windows 169.254.0.0/16 range से IP assign करता है।

Loopback Address: 127.0.0.1 (localhost) – Self-testing के लिए।

🔹 Subnetting और CIDR

Subnetting बड़े network को छोटे-छोटे sub-networks में विभाजित करता है, जिससे IP usage efficient होती है और routing tables छोटी होती हैं। CIDR (Classless Inter-Domain Routing) notation: /X (जैसे /24)।

IPv6 (128-bit)

8 groups of 4 hexadecimal digits (जैसे 2001:0db8:85a3:0000:0000:8a2e:0370:7334)। IPv4 exhaustion को solve करता है। Features: Autoconfiguration, Security (IPSec built-in), Mobility।

🎯 Exam Trick: Class A (0-127), B (128-191), C (192-223). Private: 10.x, 172.16-31.x, 192.168.x. Loopback: 127.0.0.1.

Protocols – TCP/IP, UDP, HTTP, FTP, DNS, DHCP, etc.

🔹 TCP/IP Model vs OSI

TCP/IP model में 4 layers होती हैं: Application (OSI 5-7), Transport (OSI 4), Internet (OSI 3), Network Access (OSI 1-2)।

🔹 Important Protocols & Ports (Exam मे बहुत पूछे जाते हैं)

🔹 TCP vs UDP – Key Difference

  • TCP: Connection established (3-way handshake), reliable, sequencing, flow control। Slow।
  • UDP: No connection, unreliable, no sequencing, faster। Ideal for real-time (VoIP, Gaming, Live streaming)।
🎯 Important Ports: HTTP=80, HTTPS=443, FTP=21, SMTP=25, DNS=53, DHCP=67/68, SSH=22. TCP=Reliable, UDP=Fast.
05

Communication Media & Network Security

🔹 Transmission Media (Guided & Unguided)

  • Guided (Wired):
    • Twisted Pair (UTP/STP): सबसे आम (Ethernet cables – Cat5e, Cat6)। Cheap, but susceptible to interference.
    • Coaxial Cable: TV/Cable Internet। Better shielding than twisted pair.
    • Fiber Optics: Light signals। Very high bandwidth, long distance, immune to EMI।
  • Unguided (Wireless):
    • Radio Waves (Wi-Fi): IEEE 802.11 standards। (802.11a/b/g/n/ac/ax – Wi-Fi 6)।
    • Microwave: Point-to-point।
    • Infrared (IR): Short range (TV remotes)।
    • Satellite: Very long distance (VSAT, GPS)।

🔹 Network Security Basics

  • Firewall: Incoming/outgoing network traffic को rules के आधार पर filter करता है। Software (Windows Defender) या Hardware (Cisco ASA) हो सकता है।
  • VPN (Virtual Private Network): Public internet पर encrypted tunnel बनाकर सुरक्षित communication। Protocols: PPTP, L2TP, IPSec, OpenVPN।
  • Encryption: Data को cipher text में बदलना। Symmetric (AES, DES) और Asymmetric (RSA, ECC)।
  • Authentication: Username/Password, Biometrics, 2FA, Digital Certificates।
  • Common Attacks: Phishing, DoS/DDoS, Man-in-the-Middle (MITM), Spoofing, Sniffing।
🎯 Security Hack: Firewall = Traffic Filter, VPN = Encrypted Tunnel, HTTPS = Secure Web, SSH = Secure Remote Access.
