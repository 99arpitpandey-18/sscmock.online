Cyber Security – Introduction & CIA Triad

🔹 Cyber Security क्या है?

Cyber Security (Information Security), computers, networks, programs और data को unauthorized access, damage, theft, या disruption से protect करने की practice है। यह confidentiality, integrity, और availability (CIA Triad) सुनिश्चित करता है।

🔹 CIA Triad (बहुत महत्वपूर्ण)

  • Confidentiality (गोपनीयता): Data केवल authorized users के लिए accessible होना चाहिए।
    Methods: Encryption, Passwords, Access Controls, Authentication.
  • Integrity (अखंडता): Data accurate और unaltered होना चाहिए (unauthorized modification से बचना)।
    Methods: Hashing (MD5, SHA), Digital Signatures, Checksums.
  • Availability (उपलब्धता): Data authorized users के लिए हमेशा accessible होना चाहिए।
    Methods: Redundancy, Backups, Disaster Recovery, DDoS Protection.

🔹 Types of Threats & Attackers

  • Hacker (Black Hat): Malicious intent के साथ systems को break करता है।
  • White Hat (Ethical Hacker): Security weaknesses को find करने के लिए authorized penetration testing करता है।
  • Grey Hat: बिना permission के systems में break करता है लेकिन बुरा intent नहीं (sometimes reports vulnerabilities)।
  • Script Kiddie: Pre-written scripts/tools का use करता है, actual knowledge कम होती है।
  • Insider Threat: Organization के भीतर का employee/contractor जो data को intentionally या unintentionally compromise करता है।

🔹 Common Cyber Attacks (Overview)

  • Malware: Malicious software (Virus, Worm, Trojan, Ransomware) – Chapter 2 में detail.
  • Phishing: Fake emails/messages से credentials चुराना – Chapter 3 में detail.
  • Man-in-the-Middle (MITM): Attacker दो parties के communication को intercept करता है।
  • Denial of Service (DoS/DDoS): Service को overload करके unavailable बनाना।
  • SQL Injection: Malicious SQL queries को database में inject करना।
  • Cross-Site Scripting (XSS): Malicious scripts को web pages में inject करना।
🎯 CIA Triad Trick: Confidentiality = Only authorized (Privacy), Integrity = Accurate & Unchanged, Availability = Always accessible (Uptime).

Malware – Types, Propagation & Prevention

🔹 Malware (Malicious Software) क्या है?

Malware, software है जिसे systems को damage, disrupt, या unauthorized access करने के लिए designed किया गया है।

🔹 Types of Malware (Detailed)

  • Virus: एक executable code जो अन्य files/programs में attach होकर फैलता है। Host program की आवश्यकता होती है। User action (जैसे infected attachment open करना) से activate होता है।
  • Worm: Self-replicating malware जो बिना host program के network के through फैलता है (जैसे Mydoom, Conficker)।
  • Trojan Horse: Legitimate software के रूप में disguise होता है। User इसे install करता है, तो पीछे से malicious activity करता है (backdoor create, data steal)।
  • Ransomware: User के files को encrypt करता है और decrypt करने के लिए ransom (payment) मांगता है (जैसे WannaCry, Locky, Cerber)।
  • Spyware: User की activities (keystrokes, browsing, credentials) को चुपचाप monitor और collect करता है। (जैसे Keyloggers)।
  • Adware: Unwanted advertisements को display करता है। अक्सर free software के साथ आता है।
  • Rootkit: System के deep level (kernel) को modify करता है, जिससे detection मुश्किल हो जाती है। Attacker को administrator access देता है।
  • Botnet: Infected computers (bots) का network जिसे attacker remotely control करता है (DDoS attacks, spam sending)।

🔹 Malware Propagation (Spread) Methods

  • Email Attachments: Infected files as attachments (विशेष रूप से .exe, .scr, .docm with macros)।
  • Malicious Websites: Drive-by downloads – बिना user के जाने malware download हो जाता है।
  • Removable Media: USB drives, external HDD।
  • Network Shares: Infected files over shared folders/network drives।
  • Exploit Kits: Vulnerabilities (outdated software) का advantage लेना (जैसे exploit kits for browsers)।

🔹 Antivirus / Anti-malware (Protection)

  • Signature-based Detection: Known malware patterns/signatures से match करके detect करता है। (Regular updates जरूरी)।
  • Heuristic/Behavioral Detection: Suspicious behavior (जैसे file encryption, system file modification) को monitor करके detect करता है।
  • Sandboxing: Suspicious files को isolated environment में run करके observe करता है।
  • Examples: Windows Defender, McAfee, Norton, Kaspersky, Bitdefender.
🎯 Malware Memory Trick: Virus = Attaches to host, Worm = Self-spreading, Trojan = Disguised, Ransomware = Encrypts & demands money, Spyware = Secretly spies.

Phishing & Social Engineering – Attacks & Prevention

🔹 Phishing क्या है?

Phishing, एक social engineering attack है जिसमें attacker, legitimate organization (जैसे bank, company) का impersonation करके email, SMS, या website के through user से sensitive information (passwords, credit card details, OTP) चुराता है।

🔹 Types of Phishing

  • Email Phishing: Fake emails जो real organizations (जैसे bank, PayPal) की तरह दिखते हैं। Urgent action (जैसे 'your account will be locked') को create करके user को click करने/link पर जाने के लिए दबाव डालते हैं।
  • Spear Phishing: Targeted phishing – specific individual/organization को target करता है। Personal information का use करके highly believable बनाया जाता है।
  • Whaling (CEO Fraud): High-profile targets (CEOs, CFOs) को target करता है। Executive को impersonate करके urgent financial transactions request करता है।
  • Vishing (Voice Phishing): Phone calls के through phishing। Attacker खुद को bank/authority representative बताकर OTP/card details मांगता है।
  • Smishing (SMS Phishing): Text messages (SMS) के through phishing। Fake links या phone numbers भेजकर victim को deceive करता है।
  • Clone Phishing: Legitimate email का exact copy बनाकर (clone) उसमें malicious link/attachment डालकर भेजता है।

🔹 Red Flags (Phishing पहचानने के तरीके)

  • 🔴 Suspicious sender email address (spelling mistakes – e.g., bank@paypa1.com)।
  • 🔴 Urgent/Threatening language ("Your account will be closed!").
  • 🔴 Generic greetings ("Dear Customer" instead of your name).
  • 🔴 Suspicious links (hover करके URL check करें – domain misspelling).
  • 🔴 Unexpected attachments (.exe, .zip, .scr).
  • 🔴 Requests for sensitive information (password, OTP, CVV).

🔹 Social Engineering (Psychological Manipulation)

Social engineering, human behavior को manipulate करके confidential information obtain करने की technique है।

  • Pretexting: Attacker एक fake story (pretext) बनाता है (जैसे "I'm from IT support, your account has a problem").
  • Baiting: Victim को lure करता है (जैसे infected USB drive with 'Salary Details' label).
  • Tailgating: Physical security को bypass करना – authorized person के पीछे secure area में घुसना।
  • Quid Pro Quo: कुछ देने का झांसा (जैसे free software download) – लेकिन वास्तव में malware।
🎯 Phishing Hack: Always check the sender's email address and hover over links before clicking. Never share OTP or passwords via phone/email.

Password Security & Authentication

🔹 Password Security Basics

Password, user authentication का सबसे common method है। Strong password brute-force attacks और credential stuffing से सुरक्षा प्रदान करता है।

🔹 Strong Password Guidelines (Exam में आते हैं)

  • Length: कम से कम 12 characters (8 minimum)।
  • Complexity: Uppercase (A-Z), Lowercase (a-z), Digits (0-9), Special Characters (!@#$%^&*) का combination।
  • Avoid: Common words (password, 123456), personal info (name, birthdate), keyboard patterns (qwerty, 12345678)।
  • Use Passphrases: Random words की sentence (e.g., "BlueSky!Mango#Tree") – long और easy to remember।
  • Unique for each account: एक ही password कई sites पर use न करें (credential stuffing attacks से बचने के लिए)।

🔹 Password Attacks & Protection

  • Brute Force Attack: सभी possible combinations को try करना। Protection: Strong complex passwords, account lockout after failed attempts, CAPTCHA.
  • Dictionary Attack: Common words/dictionary का use करना। Protection: Random password, special characters.
  • Password Spraying: कई accounts पर common passwords (e.g., Winter2024) को try करना। Protection: Policy against common passwords, MFA.
  • Credential Stuffing: एक breach से leaked credentials को अन्य sites पर try करना। Protection: Unique passwords per site, MFA.

🔹 Authentication Methods (MFA, Biometrics)

  • Single-Factor Authentication (SFA): Only password (1 factor)।
  • Two-Factor Authentication (2FA / Multi-Factor Authentication - MFA): Two or more factors:
    • Something you know: Password, PIN.
    • Something you have: OTP on mobile, Smart Card, Hardware Token.
    • Something you are: Biometrics (Fingerprint, Iris, Face Recognition).
  • Biometric Authentication: Physical/behavioral characteristics – Fingerprint, Face ID, Voice Recognition, Iris Scan, Behavioral (keystroke dynamics). Advantages: Convenient, Harder to fake. Disadvantages: Can't change if compromised, Privacy concerns.
  • Password Managers: Software (जैसे LastPass, Bitwarden, KeePass) जो complex, unique passwords को securely store और autofill करते हैं।

🔹 OTP (One-Time Password)

OTP, एक temporary password है जो एक single session/transaction के लिए valid होता है। Types: Time-based (TOTP – valid for 30-60 sec), Event-based (HOTP – counter based). OTP usually SMS/Email/Apps (Google Authenticator) के through received होता है।

🎯 Password Rules to Remember: Length > 12, Use mix of characters, Unique per site, Enable MFA always. Biometrics = "Who you are".

Digital Privacy, Safe Computing & Legal Aspects

🔹 Digital Privacy क्या है?

Digital Privacy, personal information को unauthorized access, collection, और sharing से protect करने की practice है। इसमें data protection, consent, और control शामिल हैं।

🔹 Privacy Concerns & Threats

  • Data Breach: Confidential data (credentials, financial info) का unauthorized exposure।
  • Tracking (Cookies, Pixel, Fingerprinting): Websites users की browsing behavior को track करते हैं (targeted ads)।
  • Social Media Privacy: Oversharing personal information (location, daily routine) – risks: stalking, identity theft, social engineering।
  • Public Wi-Fi Risks: Unencrypted networks पर data interception (MITM attacks)। Protection: VPN, avoid accessing sensitive accounts, disable file sharing.

🔹 Safe Computing Practices (Exam में आते हैं)

  • Keep Software Updated: OS, applications, antivirus को regularly update करें (patches vulnerabilities)।
  • Use Antivirus/Firewall: Real-time protection और network traffic filtering।
  • Be Cautious of Links/Attachments: Unknown sources से emails/SMS में दिए गए links/attachments को open न करें।
  • Use HTTPS: Websites पर 'https://' और padlock icon check करें (encryption)।
  • Backup Regularly: Important data को 3-2-1 strategy से backup करें (3 copies, 2 media, 1 offsite)।
  • Use VPN on Public Networks: Public Wi-Fi पर encrypted tunnel (VPN) mandatory।
  • App Permissions: Mobile apps को unnecessary permissions (Contacts, Location, Camera) न दें।

🔹 Legal Aspects (India & Global)

  • IT Act 2000 (India): Cyber crimes (hacking, data theft, phishing) को criminalize करता है। Section 66 – Computer-related offences, Section 66C – Identity theft, Section 66D – Cheating by impersonation using computer resource.
  • GDPR (General Data Protection Regulation - EU): European Union का data protection law – strict privacy rules, user consent mandatory, right to be forgotten.
  • DPDP Act (Digital Personal Data Protection Act 2023 - India): India का नया data protection law – consent-based data collection, data fiduciary obligations, penalties for breaches.
  • Cybercrime Reporting: India में cyber crime report करने के लिए National Cyber Crime Reporting Portal (cybercrime.gov.in) और toll-free helpline 1930.
🎯 Safe Computing: Update Software, Use Antivirus, Think Before You Click, Use HTTPS, VPN on Public Wi-Fi, Regular Backups.
