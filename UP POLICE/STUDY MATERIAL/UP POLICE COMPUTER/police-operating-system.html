ऑपरेटिंग सिस्टम – परिचय एवं अवधारणाएँ

🔹 ऑपरेटिंग सिस्टम (OS) क्या है?

ऑपरेटिंग सिस्टम एक सिस्टम सॉफ्टवेयर है जो कंप्यूटर हार्डवेयर और उपयोगकर्ता (एप्लिकेशन) के बीच इंटरफेस का कार्य करता है। यह सभी हार्डवेयर संसाधनों (CPU, मेमोरी, स्टोरेज, I/O डिवाइस) का प्रबंधन करता है और एप्लिकेशन सॉफ्टवेयर को चलाने का प्लेटफॉर्म प्रदान करता है।

मुख्य कार्य: प्रोसेस प्रबंधन, मेमोरी प्रबंधन, फाइल प्रबंधन, डिवाइस प्रबंधन, सुरक्षा एवं पहुँच नियंत्रण, नेटवर्किंग।

🔹 OS के प्रकार

  • बैच OS (Batch OS): एक समय में एक कार्य, कोई उपयोगकर्ता संपर्क नहीं – पुराने सिस्टम
  • टाइम-शेयरिंग OS: कई उपयोगकर्ता एक साथ, प्रत्येक को CPU का थोड़ा समय – Unix, Linux
  • रियल-टाइम OS (RTOS): तात्कालिक प्रतिक्रिया – एयरोस्पेस, मिसाइल, चिकित्सा उपकरण (VxWorks)
  • डिस्ट्रिब्यूटेड OS: कई मशीनों पर फैला हुआ – नेटवर्क प्रबंधन
  • नेटवर्क OS: नेटवर्क संसाधन प्रबंधन – Windows Server, Linux Server
  • मोबाइल OS: Android, iOS, Windows Phone
  • एम्बेडेड OS: छोटे उपकरणों के लिए – IoT, स्मार्टवॉच

🔹 OS के घटक (Components)

  • कर्नेल (Kernel): OS का मूल भाग, हार्डवेयर को नियंत्रित करता है – माइक्रोकर्नेल, मोनोलिथिक, हाइब्रिड
  • शेल (Shell): उपयोगकर्ता और कर्नेल के बीच इंटरफेस – CLI (CMD, PowerShell), GUI (Windows Explorer)
  • फाइल सिस्टम: फाइलों को संग्रहीत और व्यवस्थित करता है – NTFS, FAT32, EXT4, APFS
  • डिवाइस ड्राइवर: हार्डवेयर को नियंत्रित करने के लिए सॉफ्टवेयर
  • सिस्टम यूटिलिटीज: Disk Cleanup, Defragmenter, Task Manager, System Restore

🔹 OS के उद्देश्य (Objectives of Operating System)

ऑपरेटिंग सिस्टम का उद्देश्य केवल कंप्यूटर को चालू रखना नहीं है, बल्कि उपलब्ध हार्डवेयर और सॉफ्टवेयर संसाधनों का व्यवस्थित, सुरक्षित और कुशल उपयोग कराना है। परीक्षा में OS के objectives से प्रश्न अक्सर सीधे पूछे जाते हैं।

  • Convenience: उपयोगकर्ता के लिए कंप्यूटर का उपयोग आसान बनाना।
  • Efficiency: CPU, मेमोरी, स्टोरेज और I/O संसाधनों का बेहतर उपयोग।
  • Resource Management: अलग-अलग programs/processes के बीच संसाधनों का आवंटन।
  • Protection & Security: अनधिकृत access को रोकना और users/processes को नियंत्रित करना।
  • Accounting: संसाधनों के उपयोग की निगरानी और रिकॉर्ड रखना।

🔹 OS के प्रमुख कार्य — Exam Focus

1. Process Management: processes बनाना, CPU देना, scheduling करना और समाप्त करना। 2. Memory Management: कौन-सा भाग किस process को दिया गया है, इसका रिकॉर्ड रखना। 3. File Management: files/directories बनाना, पढ़ना, लिखना, हटाना और permissions संभालना। 4. Device Management: input/output devices तथा device drivers का प्रबंधन। 5. Security: authentication और access control। 6. Networking: network communication और shared resources का समर्थन।

🔹 Kernel के प्रकार

  • Monolithic Kernel: OS की अनेक core services kernel space में चलती हैं।
  • Microkernel: kernel में केवल आवश्यक core functions रखे जाते हैं; कई services user space में रहती हैं।
  • Hybrid Kernel: monolithic और microkernel approaches की कुछ विशेषताओं का मिश्रण।

याद रखें: Kernel और Shell एक ही चीज नहीं हैं। Kernel OS का core है, जबकि Shell user और OS के बीच command/interface layer देता है।

🔹 User Mode और Kernel Mode

आधुनिक OS में सामान्य applications को सीमित privileges के साथ User Mode में चलाया जाता है। OS का privileged core Kernel Mode में चलता है। जब application को किसी protected OS service की आवश्यकता होती है, तो वह system call के माध्यम से kernel से सेवा मांग सकती है। यह व्यवस्था system stability और security के लिए महत्वपूर्ण है।

🔹 System Call क्या है?

System call वह mechanism है जिसके द्वारा user-level program OS से कोई service मांगता है, जैसे file खोलना, process बनाना, memory लेना या I/O करना। Exam में इसे “OS service के लिए program द्वारा किया गया अनुरोध” याद रखें।

🔹 Booting, BIOS/UEFI और Boot Loader

Booting वह प्रक्रिया है जिसमें computer start होने के बाद firmware hardware को initialize करता है और bootable software को खोजकर OS को memory में load करने की प्रक्रिया शुरू करता है। पुराने systems में BIOS और आधुनिक systems में UEFI का उपयोग सामान्य है। Boot loader OS kernel को load करने में सहायता करता है।

🔹 Memory Management की मूल बातें

  • RAM: वर्तमान में चल रहे programs और data के लिए मुख्य volatile memory।
  • Virtual Memory: disk/SSD के कुछ हिस्से को memory management में backing storage के रूप में उपयोग कर RAM की सीमित क्षमता से बड़े logical address space को support करना।
  • Paging: logical/virtual memory को fixed-size pages और physical memory को frames में बाँटने की technique।
  • Swapping: processes/data को RAM और secondary storage के बीच स्थानांतरित करने की प्रक्रिया।
🎯 परीक्षा में सबसे महत्वपूर्ण: OS = System Software, Kernel = Core, Shell = Interface, Scheduler = CPU allocation, File System = File organization, System Call = OS service request, Booting = OS loading/start-up process.

Windows – Microsoft Windows OS

🔹 Microsoft Windows क्या है?

Microsoft Windows एक ग्राफ़िकल यूज़र इंटरफेस (GUI) आधारित ऑपरेटिंग सिस्टम है, जो Microsoft Corporation द्वारा विकसित किया गया है। यह दुनिया का सबसे लोकप्रिय डेस्कटॉप OS है।

🔹 Windows का इतिहास

  • Windows 1.0 (1985): पहला GUI संस्करण, MS-DOS पर आधारित
  • Windows 3.0 (1990): बेहतर GUI, प्रोग्राम मैनेजर
  • Windows 95 (1995): स्टार्ट मेनू, टास्कबार, प्लग एंड प्ले
  • Windows XP (2001): स्थिरता और लोकप्रियता का शिखर, NT कर्नेल
  • Windows 7 (2009): सुधरा हुआ इंटरफेस, Aero
  • Windows 8 (2012): मॉडर्न UI (स्टार्ट स्क्रीन), टाइल्स
  • Windows 10 (2015): स्टार्ट मेनू वापस, कॉर्टाना, एज ब्राउज़र
  • Windows 11 (2021): नया डिज़ाइन, विजेट्स, एंड्रॉइड ऐप्स सपोर्ट

🔹 Windows की मुख्य विशेषताएँ

  • GUI (Graphical User Interface): आइकन, विंडो, मेनू, माउस – उपयोग में आसान
  • फाइल एक्सप्लोरर: फाइलों और फोल्डरों का प्रबंधन (कॉपी, मूव, डिलीट, रीनाम)
  • टास्क मैनेजर: प्रोसेस, प्रदर्शन, सेवाओं की निगरानी
  • कंट्रोल पैनल / सेटिंग्स: सिस्टम कॉन्फ़िगरेशन, उपयोगकर्ता खाते, नेटवर्क
  • स्टार्ट मेनू: एप्लिकेशन, सेटिंग्स, पॉवर विकल्पों तक पहुँच
  • सिस्टम ट्रे (Notification Area): घड़ी, वॉल्यूम, नेटवर्क, बैटरी, एंटीवायरस
  • सुरक्षा: Windows Defender (एंटीवायरस), फायरवॉल, BitLocker (एन्क्रिप्शन), Windows Update

🔹 Windows Architecture और उपयोग

Windows एक proprietary operating-system family है जिसमें graphical interface, process/thread management, memory management, file systems, device drivers, networking और security जैसी सुविधाएँ शामिल हैं। Windows के अलग-अलग editions और releases में features अलग हो सकते हैं, इसलिए परीक्षा में version-specific प्रश्न को wording के अनुसार पढ़ना जरूरी है।

🔹 Windows के महत्वपूर्ण Desktop Components

  • Desktop: मुख्य कार्यक्षेत्र जहाँ icons और windows दिखाई देते हैं।
  • Taskbar: running/pinned applications, Start और system/notification area तक पहुँच।
  • Start Menu: applications, search और system options तक पहुँच।
  • File Explorer: files, folders, drives और locations को manage करने के लिए।
  • Settings: आधुनिक Windows में system configuration का प्रमुख स्थान।
  • Task Manager: processes, performance, startup आदि की निगरानी।

🔹 Windows Security — परीक्षा उपयोगी बिंदु

Windows security ecosystem में antivirus/malware protection, firewall, updates, user-account controls और कुछ editions में drive encryption जैसी सुविधाएँ शामिल हो सकती हैं। BitLocker drive encryption से संबंधित है, जबकि Microsoft Defender security/antimalware protection से जुड़ा है।

🔹 Windows में Troubleshooting Tools

  • Task Manager: unresponsive app/process और resource usage देखने में उपयोगी।
  • Device Manager: hardware devices और उनके drivers की जानकारी/प्रबंधन।
  • Event Viewer: system/application/security logs देखने के लिए।
  • System Restore: उपलब्ध restore point के आधार पर system state को पहले की स्थिति में ले जाने में सहायता।
  • Safe Mode: सीमित drivers/services के साथ troubleshooting के लिए।
  • System Configuration (msconfig): boot और service configuration के लिए।
🎯 Shortcut Trick: Explorer = Files, Task Manager = Processes/Performance, Device Manager = Hardware/Drivers, Event Viewer = Logs, BitLocker = Encryption, Defender = Security protection.
03

Files & Folders – फाइलें और फोल्डर

🔹 फाइल (File) क्या है?

फाइल डेटा का एक संग्रह है जो किसी विशिष्ट प्रारूप (format) में संग्रहीत होता है। हर फाइल का एक नाम और एक्सटेंशन होता है (जैसे – document.txt, image.jpg, video.mp4)।

🔹 फाइल एक्सटेंशन (File Extensions)

  • .txt: सादा पाठ (Text) फ़ाइल
  • .docx / .doc: MS Word दस्तावेज़
  • .xlsx / .xls: MS Excel स्प्रेडशीट
  • .pptx / .ppt: MS PowerPoint प्रेजेंटेशन
  • .jpg / .jpeg, .png, .gif: छवि (Image) फ़ाइलें
  • .mp3, .wav: ऑडियो फ़ाइलें
  • .mp4, .avi, .mkv: वीडियो फ़ाइलें
  • .exe: निष्पादन योग्य (Executable) फ़ाइल – प्रोग्राम
  • .pdf: पोर्टेबल दस्तावेज़ प्रारूप (Portable Document Format)
  • .zip, .rar, .7z: संपीड़ित (Compressed) फ़ाइलें
  • .html, .htm: वेब पेज फ़ाइल
  • .ini: कॉन्फ़िगरेशन फ़ाइल
  • .log: लॉग फ़ाइल (घटना रिकॉर्ड)

🔹 फोल्डर (Folder) क्या है?

फोल्डर (डायरेक्टरी) फाइलों और अन्य फोल्डरों को व्यवस्थित करने के लिए एक कंटेनर है। यह डेटा को संगठित रखता है।

  • रूट डायरेक्टरी: C:\, D:\ – ड्राइव की मूल डायरेक्टरी
  • सब-डायरेक्टरी: किसी डायरेक्टरी के अंदर स्थित डायरेक्टरी
  • पेरेंट डायरेक्टरी: वह डायरेक्टरी जिसमें सब-डायरेक्टरी स्थित है

🔹 फाइल सिस्टम (File Systems)

  • NTFS (New Technology File System): Windows का मानक फाइल सिस्टम – बड़ी फाइलें, सुरक्षा, एन्क्रिप्शन
  • FAT32 (File Allocation Table 32): पुराना, पोर्टेबल डिवाइस (USB, SD Card) – 4GB से बड़ी फाइल नहीं
  • exFAT (Extended FAT): फ्लैश ड्राइव, बड़ी फाइलों के लिए
  • EXT4: Linux का फाइल सिस्टम
  • APFS / HFS+: macOS का फाइल सिस्टम

🔹 फाइल विशेषताएँ (Attributes)

  • Read-Only (केवल पढ़ने योग्य): फाइल को संपादित नहीं किया जा सकता
  • Hidden (छिपी हुई): डिफ़ॉल्ट रूप से दिखाई नहीं देती
  • Archive (संग्रह): बैकअप के लिए चिह्नित
  • System (सिस्टम): OS फ़ाइलें

🔹 File, Folder, Directory और Path — अंतर

File वास्तविक data/information का संग्रह है। Folder/Directory files और subfolders को organize करने का container है। Path किसी file या folder तक पहुँचने का स्थान बताता है। उदाहरण: C:\Users\Student\Documents\notes.txt में drive, folders और file location मिलकर path बनाते हैं।

🔹 Absolute Path और Relative Path

  • Absolute Path: root/drive से शुरू होकर पूरे location को बताता है।
  • Relative Path: वर्तमान working location के संदर्भ में स्थान बताता है।
  • Root Directory: किसी drive/file-system hierarchy का मूल स्तर।
  • Parent Directory: वर्तमान folder के ऊपर वाला directory level।
  • Subdirectory: किसी directory के अंदर स्थित directory।

🔹 File Naming और Extension

File name और extension मिलकर file की पहचान और सामान्य प्रकार बताने में मदद करते हैं। उदाहरण: report.docx में report नाम और .docx extension है। Extension को बदलने से हमेशा file का वास्तविक internal format नहीं बदलता—इसलिए केवल extension rename करना conversion के बराबर नहीं है।

🔹 File Attributes और Permissions

Read-only attribute editing को सीमित करने के लिए उपयोग हो सकता है; Hidden सामान्य view में file को छिपा सकता है; Archive traditional backup workflows में file को backup consideration के लिए mark कर सकता है; System system-related files से जुड़ा attribute है। File permissions अलग concept हैं और यह निर्धारित कर सकती हैं कि कौन user read/write/execute जैसी actions कर सकता है।

🔹 Compression और Backup

.zip, .rar, .7z जैसे formats compressed archives के लिए उपयोग होते हैं। Compression का उद्देश्य data को compact representation में रखना है। Backup का उद्देश्य original data की अतिरिक्त copy रखना है। Compression और backup एक ही concept नहीं हैं।

🎯 Exam Trap: “Extension” file type का संकेत देता है; “Path” location बताता है; “Folder” organization करता है; “File System” storage structure को manage करता है।
04

Processes – प्रोसेस और थ्रेड

🔹 प्रोसेस (Process) क्या है?

प्रोसेस एक निष्पादन योग्य प्रोग्राम की चल रही उदाहरण है। इसमें प्रोग्राम कोड, डेटा, स्टैक, और रजिस्टर शामिल हैं।

🔹 प्रोसेस की अवस्थाएँ (Process States)

  • New (नया): प्रोसेस बन रहा है
  • Ready (तैयार): प्रोसेस CPU का इंतज़ार कर रहा है
  • Running (चालू): प्रोसेस CPU पर चल रहा है
  • Waiting (प्रतीक्षा): I/O या किसी घटना का इंतज़ार
  • Terminated (समाप्त): प्रोसेस समाप्त हो गया

🔹 प्रोसेस शेड्यूलिंग (Scheduling)

  • FCFS (First Come First Serve): जो पहले आया, पहले मिला – सरल लेकिन अकुशल
  • SJF (Shortest Job First): कम समय वाला कार्य पहले – इष्टतम
  • Round Robin: समय-स्लाइस (टाइम क्वांटम) आधारित – निष्पक्ष
  • Priority Scheduling: प्राथमिकता (priority) आधारित – उच्च प्राथमिकता पहले

🔹 थ्रेड (Thread)

  • थ्रेड: प्रोसेस के भीतर कार्य की सबसे छोटी इकाई
  • सिंगल-थ्रेडेड: एक प्रोसेस में एक थ्रेड
  • मल्टी-थ्रेडेड: एक प्रोसेस में कई थ्रेड – समानांतर निष्पादन
  • थ्रेड्स प्रोसेस के संसाधनों (मेमोरी, फाइलें) को साझा करते हैं

🔹 प्रोसेस संचार (IPC – Inter Process Communication)

  • पाइप (Pipe): एक प्रोसेस से दूसरे में डेटा भेजना
  • मेसेज क्यू (Message Queue): संदेशों की कतार
  • शेयर्ड मेमोरी (Shared Memory): दो प्रोसेस एक ही मेमोरी का उपयोग करें
  • सेमाफोर (Semaphore): सिंक्रोनाइज़ेशन के लिए

🔹 Program, Process और Thread में अंतर

Program instructions का stored set है। जब program execution में आता है तो उसकी running instance को process कहा जाता है। Process के अंदर execution की छोटी units को threads कहा जाता है। एक process में एक या अधिक threads हो सकते हैं।

🔹 Process Control Block (PCB)

PCB OS द्वारा process की management information रखने के लिए प्रयुक्त data structure है। इसमें सामान्यतः PID, process state, program counter, CPU registers, scheduling information, memory-management information और accounting information जैसी जानकारी हो सकती है।

🔹 Process State Transition

Stateअर्थ
NewProcess create हो रहा है
ReadyCPU मिलने की प्रतीक्षा
RunningCPU पर execution
Waiting/BlockedI/O या event की प्रतीक्षा
TerminatedExecution समाप्त

एक running process I/O request के कारण waiting में जा सकता है; I/O पूरा होने पर वह ready queue में लौट सकता है। Scheduler ready processes में से CPU के लिए selection करता है।

🔹 CPU Scheduling के महत्वपूर्ण Concepts

  • FCFS: arrival order के आधार पर; सरल, पर convoy effect हो सकता है।
  • SJF: shortest CPU burst को preference; औसत waiting time के संदर्भ में optimal हो सकता है जब burst lengths ज्ञात हों।
  • Round Robin: प्रत्येक ready process को time quantum देकर fairness बढ़ाता है।
  • Priority Scheduling: priority के आधार पर selection; starvation की समस्या हो सकती है।
  • Preemptive: OS चल रहे process से CPU वापस ले सकता है।
  • Non-preemptive: process स्वयं CPU छोड़े या block/terminate हो तब switch होता है।

🔹 Context Switching

CPU को एक process/thread से दूसरे को देने पर पुराने execution context को save और नए context को restore करना पड़ता है। इस प्रक्रिया को context switch कहते हैं। इसमें CPU registers और program counter जैसी state information महत्वपूर्ण होती है। Context switching useful है, लेकिन इसका अपना overhead भी होता है।

🔹 IPC और Synchronization

  • Pipe: processes के बीच data stream का माध्यम।
  • Message Queue: messages को queue के रूप में exchange करना।
  • Shared Memory: processes के बीच shared memory region।
  • Semaphore: synchronization/resource coordination में उपयोगी primitive।
  • Mutex: critical section/resource पर mutual exclusion के लिए commonly used lock mechanism।

🔹 Deadlock

Deadlock में processes एक-दूसरे के resources/events का इंतजार करते रह सकते हैं और आगे नहीं बढ़ते। Classical deadlock conditions हैं: Mutual Exclusion, Hold and Wait, No Preemption, Circular Wait। इन चारों का साथ होना deadlock के लिए आवश्यक conditions से संबंधित है।

🎯 याद रखें: PCB = Process information, PID = Process identity, Ready = CPU wait, Waiting = I/O/event wait, RR = Time Quantum, Context Switch = CPU execution context बदलना.

Commands & Utilities – कमांड्स और सिस्टम उपयोगिताएँ

🔹 कमांड-लाइन इंटरफेस (CLI)

CLI एक पाठ-आधारित इंटरफेस है जहाँ उपयोगकर्ता कमांड टाइप करके OS के साथ संचार करता है। Windows में CMD (Command Prompt) और PowerShell प्रमुख CLI उपकरण हैं।

🔹 महत्वपूर्ण Windows CMD कमांड्स

  • dir: फाइलों और फोल्डरों को सूचीबद्ध करता है
  • cd: निर्देशिका (डायरेक्टरी) बदलता है
  • mkdir (md): नई डायरेक्टरी बनाता है
  • rmdir (rd): डायरेक्टरी हटाता है
  • del / erase: फाइलें हटाता है
  • copy: फाइलें कॉपी करता है
  • move: फाइलें स्थानांतरित करता है
  • ren / rename: फाइलों का नाम बदलता है
  • type: फाइल की सामग्री दिखाता है
  • cls: स्क्रीन साफ़ करता है
  • exit: CMD बंद करता है
  • ipconfig: नेटवर्क कॉन्फ़िगरेशन दिखाता है
  • ping: नेटवर्क कनेक्टिविटी परीक्षण
  • tasklist: चल रहे प्रोसेसों की सूची
  • taskkill: प्रोसेस को समाप्त करता है
  • shutdown: सिस्टम बंद/रीस्टार्ट करता है
  • systeminfo: सिस्टम की विस्तृत जानकारी
  • chkdsk: डिस्क त्रुटि जाँच
  • sfc: सिस्टम फ़ाइलों की जाँच
  • netstat: नेटवर्क स्टेटिस्टिक्स
  • tracert: नेटवर्क मार्ग ट्रेस
  • nslookup: DNS जाँच
  • attrib: फाइल विशेषताएँ दिखाना/बदलना
  • echo: टेक्स्ट प्रदर्शित करना
  • path: खोज पथ दिखाना/बदलना
  • tree: डायरेक्टरी वृक्ष दिखाना
  • find: फाइल में टेक्स्ट खोजना
  • robocopy: मजबूत फाइल कॉपी

🔹 सिस्टम उपयोगिताएँ (System Utilities)

  • टास्क मैनेजर (Task Manager): प्रोसेस, प्रदर्शन, सेवाएँ, स्टार्टअप
  • कंट्रोल पैनल / सेटिंग्स: सिस्टम कॉन्फ़िगरेशन
  • डिस्क क्लीनअप (Disk Cleanup): अनावश्यक फाइलें हटाना
  • डिफ़्रैगमेंटर (Defragmenter): हार्ड डिस्क को व्यवस्थित करना
  • सिस्टम रिस्टोर (System Restore): सिस्टम को पुरानी स्थिति में लाना
  • इवेंट व्यूअर (Event Viewer): सिस्टम लॉग देखना
  • डिवाइस मैनेजर (Device Manager): हार्डवेयर प्रबंधन
  • सिस्टम कॉन्फ़िगरेशन (msconfig): बूट विकल्प, सेवाएँ

🔹 CMD में Command Structure

Windows Command Prompt में सामान्यतः command के बाद options/switches और arguments दिए जा सकते हैं। उदाहरण के लिए dir /p में dir command है और /p एक switch है। अलग-अलग commands के switches अलग हो सकते हैं, इसलिए exam में command के साथ दिया गया option ध्यान से पढ़ें।

🔹 System और Diagnostic Commands

  • tasklist: running processes की list।
  • taskkill: process terminate करना।
  • systeminfo: system की विस्तृत configuration information।
  • chkdsk: disk/file-system related errors की जाँच।
  • sfc: protected Windows system files की जाँच/repair workflow में उपयोग।
  • shutdown: shutdown, restart आदि के लिए options देता है।
  • echo: text/command echoing के लिए।
  • cls: Command Prompt screen clear करना।
  • exit: command interpreter से बाहर निकलना।

🔹 GUI Utilities और CLI में अंतर

GUI में icons, windows, menus और pointer जैसे graphical elements के माध्यम से interaction होता है। CLI में commands text के रूप में दी जाती हैं। दोनों का उद्देश्य system से interaction कराना है, लेकिन तरीका अलग है।
