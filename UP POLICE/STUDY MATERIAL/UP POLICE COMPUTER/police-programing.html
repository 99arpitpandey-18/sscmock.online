Programming Fundamentals – Introduction & Environment

🔹 Programming क्या है?

Programming, कंप्यूटर को निर्देश (instructions) देने की कला है ताकि वह एक विशिष्ट कार्य (task) को perform कर सके। ये निर्देश एक programming language (जैसे C, C++, Python, Java) में लिखे जाते हैं।

🔹 Programming Language के Types (Exam Focus)

  • Low-Level Language (Machine/Assembly): Machine code (0/1) या mnemonics का उपयोग। Fast, लेकिन समझना मुश्किल।
  • High-Level Language (HLL): Human-readable syntax (English-like)। Examples: C, Python, Java।
  • Compiler vs Interpreter:
    • Compiler: पूरे program को एक साथ machine code में translate करता है (जैसे C, C++)। Faster execution, debugging मुश्किल हो सकती है।
    • Interpreter: Line-by-line translate और execute करता है (जैसे Python, JavaScript)। Slower execution, debugging आसान होती है।

🔹 Problem Solving Approach (IPO Model)

  • Input: Problem को solve करने के लिए data लेना (कीबोर्ड, file, sensor)।
  • Process: Input data को logic/algorithms के according process करना (computations, comparisons)।
  • Output: Result को display/print करना (screen, file, printer)।

Flowchart Symbols: Flowchart program की logic को visually represent करता है।
Start/End (Oval), Process (Rectangle), Decision (Diamond), Input/Output (Parallelogram), Flow Lines (Arrows)।

🎯 Exam Trick: Compiler = Whole code translate, Interpreter = Line by line. High-Level = Human readable, Low-Level = Machine readable.

Algorithms – Definition, Complexity & Searching

🔹 Algorithm क्या है?

Algorithm, किसी समस्या (problem) को solve करने के लिए step-by-step, logical, finite instructions का set है।

Characteristics:

  • Finiteness: Algorithm हमेशा finite steps में terminate होना चाहिए (infinite loop नहीं)।
  • Definiteness: प्रत्येक step स्पष्ट (unambiguous) होना चाहिए।
  • Input: Zero या more inputs ले सकता है।
  • Output: At least one output produce करना चाहिए।
  • Effectiveness: Steps such हों कि उन्हें manual या machine से execute किया जा सके।

🔹 Algorithm Complexity (Big O Notation – Exam में जरूरी)

Complexity, algorithm की efficiency को measure करती है (Time और Space)।

  • O(1) – Constant Time: Operation time independent of input size (e.g., Array indexing) – Best.
  • O(log n) – Logarithmic Time: Input बढ़ने पर time slowly बढ़ता है (e.g., Binary Search) – Very Efficient.
  • O(n) – Linear Time: Time input size के साथ linearly बढ़ता है (e.g., Linear Search, Loops) – Good.
  • O(n²) – Quadratic Time: Time input size के square के साथ बढ़ता है (e.g., Nested Loops, Bubble Sort) – Slow for large data.

🔹 Searching Algorithms (Basic)

  • Linear Search: Array को start से end तक traverse करके element को find करता है। Time Complexity: O(n)। (Unsorted डेटा के लिए use)।
  • Binary Search: Sorted array में middle element से compare करके search करता है। Time Complexity: O(log n)। (Sorted डेटा के लिए fast)।
Sorting Algorithms (Basic Concepts):
  • Bubble Sort: Adjacent elements को compare और swap करता है। Worst-case: O(n²)।
  • Selection Sort: Minimum element को चुनकर correct position पर रखता है। Worst-case: O(n²)।
  • Insertion Sort: Sorted array में element को correct position पर insert करता है। Best-case: O(n)।
🎯 Complexity Tricks: O(1) = Fastest, O(log n) = Binary Search, O(n) = Linear Search/Loop, O(n²) = Nested Loops.
03

Programming Logic – Conditions, Loops & Flow Control

🔹 Boolean Logic (True/False)

Programming में decisions Boolean logic पर आधारित होते हैं। Truth Table exam में पूछी जाती है:

  • AND (&&): True only if both conditions are True.
  • OR (||): True if at least one condition is True.
  • NOT (!): Reverses the boolean value (True → False).

🔹 Conditional Statements (Decision Making)

  • if-else: Condition true होने पर if block execute, false होने पर else block।
  • else-if ladder: Multiple conditions को check करता है (जैसे grade checking)।
  • switch-case: Variable की value के आधार पर multiple branches में से एक को select करता है। (C, C++, Java, C# में use, Python में नहीं)।

🔹 Loops (Iteration)

  • for Loop: जब iterations की संख्या known हो (e.g., for(i=0; i<10; i++))।
  • while Loop: जब iterations की संख्या unknown हो और condition पर depend हो (Entry-controlled)।
  • do-while Loop: पहले execute करता है, फिर condition check करता है (Exit-controlled)। कम से कम एक बार execute होता है।

Nested Loops: Loop के अंदर loop। Time Complexity अक्सर O(n²) होती है।

🎯 Logical Mnemonics: && = AND (बच्चे दोनों हों तो True), || = OR (कोई एक हो तो True). Switch = Multiple choices, For = Fixed iterations, While = Condition based.

Variables, Data Types & Memory Management

🔹 Variable क्या है?

Variable, मेमोरी का एक named storage location है जो value को store करता है और जिसे program में बदला जा सकता है। इसे declare करते समय Data Type specify करना पड़ता है (जो memory allocate करता है)।

  • Naming Rules: Letters, digits, underscore (_) से शुरू हो सकता है (digit से नहीं)। Space और special symbols (!@#) नहीं। Keywords (जैसे int, if) नहीं हो सकते। (Case-sensitive – 'age' और 'Age' अलग हैं)।

🔹 Data Types (Primitive & Derived)

  • Integer (int): Whole numbers (e.g., 5, -10, 0)। Size: 4 bytes (usually)।
  • Float (float/double): Decimal numbers (e.g., 3.14, -0.5)। Size: 4/8 bytes।
  • Character (char): Single character (e.g., 'A', 'b')। Size: 1 byte (ASCII)।
  • Boolean (bool): True or False। (C में int 0/1, C++/Java में bool)।
  • String: Character का sequence (e.g., "Hello") – Non-primitive.

Type Conversion: Implicit (Automatic – int to float) और Explicit (Casting – float to int using (int)3.14 → 3)।

🔹 Variable Scope (Local vs Global)

  • Local Variable: Function/block के अंदर declare। उसी block में access।
  • Global Variable: Function के बाहर declare। पूरे program में access।
  • Static Variable: अपनी value को function calls के बीच retain करता है।

Constant: जिस variable की value program में change नहीं होती (const in C++, final in Java)।

🎯 Memory Sizes (Common): char=1 byte, int=4 bytes, float=4 bytes, double=8 bytes. Variable name cannot start with a number.

Operators – Arithmetic, Relational, Logical & Bitwise

🔹 Operators क्या हैं?

Operators, वे symbols हैं जो operands (variables/values) पर operations perform करते हैं।

🔹 Types of Operators

  • Arithmetic Operators: + (Add), - (Subtract), * (Multiply), / (Divide), % (Modulo – Remainder)
    Example: 10 % 3 = 1.
  • Relational (Comparison) Operators: == (Equal), != (Not Equal), >, <, >=, <=. Result हमेशा Boolean (True/False) होता है।
  • Logical Operators: && (AND), || (OR), ! (NOT). Conditional expressions में use।
    Short-circuit Evaluation: && में अगर पहला False तो दूसरा evaluate नहीं होता। || में अगर पहला True तो दूसरा evaluate नहीं होता।
  • Assignment Operators: = (Assign), += (Add and Assign), -=, *=, /=, %=।
    Example: x += 5 → x = x + 5.
  • Increment/Decrement Operators: ++ (Increment by 1), -- (Decrement by 1)।
    Postfix (x++): पहले use करो फिर बढ़ाओ। Prefix (++x): पहले बढ़ाओ फिर use करो।
  • Bitwise Operators (Exam में पूछे जाते हैं): & (AND), | (OR), ^ (XOR), ~ (NOT), << (Left Shift – multiply by 2), >> (Right Shift – divide by 2)।

🔹 Operator Precedence (PEMDAS/BODMAS)

Operators को evaluation का एक निश्चित क्रम होता है (Higher precedence पहले evaluate होता है):

  • 1. ( ) – Parentheses (Highest)
  • 2. ++, -- (Post/Pre)
  • 3. *, /, % (Multiplicative)
  • 4. +, - (Additive)
  • 5. <, >, <=, >= (Relational)
  • 6. ==, != (Equality)
  • 7. && (Logical AND)
  • 8. || (Logical OR) – Lowest

Example: 5 + 2 * 3 = 11 (क्योंकि * पहले evaluate होता है)।

🎯 Operators Quick Revision: % = Modulo (Remainder). ++x = Pre-increment (पहले बढ़ाओ). x++ = Post-increment (बाद में बढ़ाओ). & = Bitwise AND, && = Logical AND.
